# 📖 데일리 성찰 저널 (React Native) 제품 요구사항 명세서

제품명: 데일리 성찰 저널 (가칭: Reflectly)
버전: 1.0 (MVP)
작성일: 2025년 11월 29일
플랫폼: iOS 및 Android (React Native)

## 1. 제품 비전 및 목표 (Product Vision & Goals)

### 1.1. 비전

사용자에게 매일 **의미 있는 질문**을 제공하고, 답변 기록을 통해 자신의 감정 패턴과 성장의 흐름을 **안전하고 시각적으로** 되돌아볼 수 있게 돕는 가장 단순하고 몰입감 있는 모바일 저널링 경험을 제공한다.

### 1.2. $\text{MVP}$ 목표

- **일일 루틴 확립:** 사용자가 저널링을 습관화하도록 유도하는 **알림 및** $\text{UI}$ **흐름** 검증.
- **프라이버시 확보:** **강력한 로컬 데이터베이스**를 사용한 기록의 안전한 저장 및 관리.
- **시각화 기초:** 단순 감정 기록을 시각화하여 유의미한 피드백을 제공.

## 2. 대상 사용자 및 핵심 가치 (Target User & Value)

- **대상 사용자:** * 꾸준한 자기 성찰을 원하지만, 복잡한 저널링 앱에 부담을 느끼는 사용자.
    - 자신의 감정이나 생각을 외부에 노출하고 싶지 않은 프라이버시 중시 사용자.
- **핵심 가치:**
    1. **프롬프트 기반 몰입:** '무엇을 써야 할지' 고민할 필요 없이, 질문에 답하며 쉽게 기록 시작.
    2. **데이터 보안: 모든 기록은 사용자 기기의 로컬 데이터베이스에만 저장되어 최고의 프라이버시를 보장.**
    3. **빠른 회고:** 과거 기록을 빠르고 직관적으로 검색 및 회고.

## 3. 핵심 기능 (Core Features - MVP Scope)

### 3.1. 일일 저널링 플로우 (Daily Journaling Flow)

| ID                       | 요구사항                                                            | 세부사항 (React Native 구현 시 고려사항)                               |
| ------------------------ | --------------------------------------------------------------- | ----------------------------------------------------------- |
| $\text{F1.1}$ 일일 프롬프트 제공 | 매일 새로운, 고정된 3개의 성찰 질문을 중앙 화면에 표시. (질문 목록은 앱에 내장)                | 날짜를 기준으로 질문을 결정하는 알고리즘 필요 (앱 내장).                           |
| $\text{F1.2}$ 감정 태그 선택   | 저널링 시작 또는 완료 시, 오늘의 감정을 단순한 이모지/태그 ($\text{5}$가지 이하)로 선택하도록 유도. | 선택된 감정은 데이터에 저장되어 시각화에 사용됨.                                 |
| $\text{F1.3}$ 자동 저장      | 답변을 작성하는 도중 앱이 종료되거나 이탈해도 내용이 임시 저장되어야 함.                       | $\text{AsyncStorage}$를 사용하여 임시 저장 기능 구현. 제출 시 로컬 DB에 최종 저장. |
| $\text{F1.4}$ 완료 상태      | 당일 저널링 완료 시, 입력 필드를 비활성화하고 완료 메시지를 표시. 다음 저널링은 다음 날 자정 이후에만 가능. | 명확한 $\text{Haptic Feedback}$과 애니메이션으로 '완료' 성취감을 부여.         |

| ID                          | 요구사항                                                                                                | 세부사항 (React Native 구현 시 고려사항)                                                                 |

## 4. 사용자 경험 (UX) 및 디자인 요구사항

- **톤앤매너:** 차분하고 편안한 색상 팔레트 (예: 파스텔 계열). '안전한 성찰 공간'이라는 느낌을 주어야 함.
- **타이포그래피:** 가독성을 최우선으로 하며, 장문의 저널링에 적합한 폰트 크기와 줄 간격 적용.
- **단순 내비게이션:** '오늘의 저널', '기록 보관함', '설정' 세 가지 탭으로만 구성하여 사용자가 길을 잃지 않도록 단순화.
- **입력 환경:** 키보드가 올라올 때 $\text{UI}$ 요소가 가려지지 않도록 **키보드 대응** 최적화 필수.

## 5. $\text{MVP}$ 제외 기능 (Out of Scope for MVP)

- $\text{Markdown}$ 또는 $\text{Rich Text}$ 포맷팅. (순수한 텍스트만 지원)
- **검색 기능** (태그나 키워드 기반의 검색).
- **기록 내보내기** ($\text{Export}$) 기능 ($\text{PDF/JSON}$).
- **복수의 질문 세트** (모든 사용자는 동일한 3개의 질문을 받음).
- **클라우드 동기화 및 백업 (**$\text{Firebase}$ **또는** $\text{iCloud}$ **연동).** (데이터는 오직 로컬 $\text{DB}$에만 저장)
