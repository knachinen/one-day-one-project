# Reflectly 검증 가이드

이 문서는 Reflectly 앱의 주요 기능을 수동으로 검증하기 위한 절차를 안내합니다.

## 1. 초기 설정 및 실행

### 1.1 앱 실행
- 터미널에서 `npm run ios` 또는 `npm run android`를 실행하여 앱을 시작합니다.
- 앱이 실행되면 스플래시 스크린이 표시된 후 "오늘의 저널" 화면으로 진입하는지 확인합니다.

## 2. 일일 저널링 플로우 검증

### 2.1 오늘의 질문 확인
- "오늘의 저널" 탭에서 날짜와 함께 3개의 질문이 표시되는지 확인합니다.
- 질문이 `prompts.json`에서 날짜 기반으로 올바르게 선택되었는지 확인합니다.

### 2.2 감정 선택
- 상단의 감정 이모지 5개 중 하나를 선택합니다.
- 선택 시 시각적 피드백(배경색 변경 등)이 나타나는지 확인합니다.

### 2.3 답변 작성 및 자동 저장
- 각 질문에 대한 답변을 입력합니다.
- 입력 도중 앱을 강제로 종료하고 다시 실행합니다.
- 이전에 입력한 내용과 선택한 감정이 복구되는지 확인합니다 (자동 저장 기능).

### 2.4 저널 제출
- 모든 질문에 답변하고 감정을 선택한 후 "오늘 하루 기록하기" 버튼을 누릅니다.
- 완료 모달이 표시되고 Haptic Feedback(진동)이 발생하는지 확인합니다.
- 모달을 닫으면 화면이 "완료" 상태로 변경되고, 입력 필드가 비활성화되는지 확인합니다.

## 3. 기록 보관함 검증

### 3.1 목록 조회
- 하단 탭에서 "기록"을 선택합니다.
- 방금 작성한 저널이 목록 최상단에 표시되는지 확인합니다.
- 날짜, 감정 이모지, 답변 미리보기가 올바르게 표시되는지 확인합니다.

### 3.2 상세 조회
- 목록에서 저널 카드를 탭합니다.
- 상세 화면으로 이동하며, 전체 질문과 답변, 감정이 올바르게 표시되는지 확인합니다.
- 뒤로 가기 버튼을 눌러 목록으로 돌아오는지 확인합니다.

## 4. 감정 추이 시각화 검증

### 4.1 차트 확인
- 하단 탭에서 "회고"를 선택합니다.
- 꺾은선 그래프가 표시되는지 확인합니다.
- 방금 선택한 감정이 그래프에 반영되었는지 확인합니다.

### 4.2 기간 변경
- "최근 7일"과 "최근 30일" 토글을 전환해봅니다.
- 그래프의 X축 레이블과 데이터 포인트가 변경되는지 확인합니다.

### 4.3 통계 확인
- 하단의 감정 통계에서 각 감정별 횟수가 올바르게 집계되었는지 확인합니다.

## 5. 설정 및 알림 검증

### 5.1 알림 설정
- 하단 탭에서 "설정"을 선택합니다.
- "일일 알림 받기" 스위치를 켭니다. (권한 요청 팝업이 뜨면 허용)
- 알림 시간을 변경하고 "저장" 버튼을 누릅니다.
- 저장이 완료되었다는 알림창이 뜨는지 확인합니다.

### 5.2 알림 수신 (시뮬레이션)
- 설정한 시간이 되었을 때(또는 시간을 임박하게 설정하여) 알림이 오는지 확인합니다.
- **참고:** 시뮬레이터에서는 푸시 알림 동작이 제한적일 수 있습니다. 실기기 테스트를 권장합니다.

## 6. 데이터베이스 검증

### 6.1 데이터 지속성
- 앱을 완전히 종료하고 다시 실행합니다.
- "기록" 탭과 "회고" 탭의 데이터가 그대로 유지되는지 확인합니다.
