# [Option B] Next.js 기반 아티스트 포트폴리오 단계별 구현 계획서

본 계획서는 **Next.js(App Router)**를 중심으로 **Three.js**를 통합하여 SEO와 고성능 인터랙션을 동시에 달성하는 것을 목표로 합니다. 각 단계는 그 자체로 실행 가능하며 명확한 결과물을 가집니다.

## 단계 1: 프로젝트 기반 구축 및 디자인 시스템 (Base)

**목표:** 개발 환경을 설정하고 공통 시각 요소를 정의하여 시각적 일관성 확보.

- **주요 과업:**
    
    - Next.js 14/15 (App Router) 초기화 및 TypeScript 설정.
        
    - Tailwind CSS 설정: 디자인 명세서의 `Deep Space Black`, `Cyber Cyan` 등 컬러 팔레트 및 `Orbitron`, `Pretendard` 폰트 적용.
        
    - Global Layout 구현: `Navbar`, `Footer`, `RootLayout` 구성.
        
    - Dark Mode 테마 고정 및 기본 SEO 메타데이터(Title, OpenGraph) 설정.
        
- **독립적 실행 결과:** 정적 헤더/푸터가 포함된 검은색 배경의 기본 웹페이지 대시보드.
    

## 단계 2: 정적 구조 및 라우팅 구현 (Structure)

**목표:** 콘텐츠 구조를 잡고 페이지 간 전환 흐름을 구축.

- **주요 과업:**
    
    - 메인 페이지(Home), 작품 목록(Works), 자기소개(About), 문의(Contact) 페이지 라우팅 생성.
        
    - 더미 데이터를 활용한 갤러리 그리드 레이아웃(2-Column) 배치.
        
    - `framer-motion`을 이용한 페이지 진입 시 페이드 인 애니메이션 적용.
        
    - 모바일 대응 햄버거 메뉴 및 반응형 레이아웃 검증.
        
- **독립적 실행 결과:** 모든 메뉴가 작동하며 더미 이미지가 배치된 반응형 정적 사이트.
    

## 단계 3: 3D 캔버스 및 인터랙티브 히어로 (3D Feature)

**목표:** 랜딩 페이지의 핵심인 3D 인터랙션 요소 통합.

- **주요 과업:**
    
    - Next.js 클라이언트 컴포넌트로 `Canvas` 환경 구축 (Three.js/R3F).
        
    - 디자인 명세서의 '인터랙티브 파티클' 배경 구현: 마우스 위치에 따라 입자가 반응하는 로직 추가.
        
    - `Hero Section`에 3D 캔버스 배경 삽입 및 `One-Sentence Identity` 타이핑 애니메이션 결합.
        
    - 포털(Portal) 개념을 활용한 3D 요소와 HTML UI의 레이어링 최적화.
        
- **독립적 실행 결과:** 마우스에 반응하는 3D 배경이 포함된 몰입형 랜딩 페이지.
    

## 단계 4: 동적 콘텐츠 아카이빙 (Data & Detail)

**목표:** 실제 작품 데이터를 관리하고 상세 페이지의 서사를 강화.

- **주요 과업:**
    
    - 작품 데이터를 위한 JSON 파일 또는 로컬 Markdown(MDX) 시스템 구축.
        
    - 다이나믹 라우팅(`[id]/page.tsx`)을 통한 작품 상세 페이지 자동 생성.
        
    - 상세 페이지 내 'Process' 섹션: 이미지 슬라이더 및 코드 스니펫 뷰어 구현.
        
    - Next.js `Image` 컴포넌트를 활용한 WebP 최적화 및 레이지 로딩 적용.
        
- **독립적 실행 결과:** 데이터 추가만으로 페이지가 자동 생성되는 콘텐츠 관리 시스템 완비.
    

## 단계 5: 모션 폴리싱 및 배포 (Polish & Launch)

**목표:** 디테일한 사용자 경험 최적화 및 최종 배포.

- **주요 과업:**
    
    - `GSAP ScrollTrigger`를 활용한 스크롤 연동 애니메이션(이미지 순차 노출 등) 추가.
        
    - 커스텀 마우스 커서 및 마이크로 인터랙션(Glow 효과 등) 최종 적용.
        
    - Lighthouse 성능 측정 및 이미지/스크립트 로딩 최적화 (LCP 2.5초 이내).
        
    - Vercel 플랫폼을 이용한 자동 배포 및 도메인 연결.
        
- **독립적 실행 결과:** 글로벌 서빙이 가능한 고성능 미래지향적 아티스트 포트폴리오 웹사이트.
