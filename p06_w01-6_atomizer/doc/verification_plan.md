# Atomizer MVP 검증 계획

## 1. 핵심 플로우 검증 (Core Flow Verification)

### 시나리오 1: 신규 사용자 온보딩 및 첫 목표 설정
1. **앱 실행**: 초기 화면이 `GoalInputScreen`인지 확인
2. **목표 입력**: "책 읽기" 입력 후 저장
3. **검증**:
   - `Goal` 데이터가 Realm에 생성되었는지 확인
   - `current_goal_id`가 AsyncStorage에 저장되었는지 확인
   - 화면이 `ActionCreateScreen`으로 전환되었는지 확인

### 시나리오 2: 원자 행동 생성
1. **행동 입력**: "책 펴기" 입력
2. **시간 설정**: 1분 후로 설정
3. **저장**: "시작하기" 버튼 탭
4. **검증**:
   - `Action` 데이터가 Realm에 생성되고 `Goal`에 연결되었는지 확인
   - `current_action_id`가 AsyncStorage에 저장되었는지 확인
   - 로컬 알림이 스케줄링되었는지 확인 (Notifee)
   - 화면이 `MainScreen`으로 전환되었는지 확인

### 시나리오 3: 타이머 실행 및 완료
1. **타이머 시작**: "10초 시작!" 버튼 탭
2. **진행**: 10초 카운트다운 확인 (UI 업데이트)
3. **완료**: 0초 도달 시 자동 완료 처리
4. **검증**:
   - 햅틱 피드백 발생 확인
   - `Action` 상태가 `completed`로 변경되었는지 확인
   - `current_action_id`가 AsyncStorage에서 제거되었는지 확인
   - 완료 알림창 표시 확인
   - 확인 버튼 탭 시 다시 `ActionCreateScreen`으로 돌아가는지 확인

## 2. 코드 품질 검증 (Static Analysis)

### 린트 및 타입 체크
- `eslint` 실행하여 잠재적 오류 확인
- `tsc` 실행하여 타입 불일치 확인

### 컴포넌트 연결성 확인
- `AppNavigator`의 라우팅 로직이 모든 케이스를 커버하는지 확인
- `useData` 훅이 Realm 스키마와 일치하는지 확인

## 3. 수동 테스트 체크리스트 (Manual Testing Checklist)

- [ ] **UI/UX**:

  - [ ] 키보드가 입력 필드를 가리지 않는가?
- [ ] **데이터**:
