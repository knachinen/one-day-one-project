# ⚛️ Atomizer (React Native) 제품 요구사항 명세서

버전: 1.0 (MVP, iOS/Android)
작성일: 2025년 11월 29일
플랫폼: iOS 및 Android (React Native)

## 1. 제품 비전 및 목표 (Product Vision & Goals)

### 1.1. 비전

사용자에게 거대한 작업에 대한 심리적 장벽을 제거하고, **10초 실행**이라는 원자적 행동을 통해 **'시작하는 습관'**을 형성시키는 가장 빠르고 안전한 모바일 $\text{To-Do}$ 앱을 제공한다.

### 1.2. $\text{MVP}$ 목표

- **핵심 플로우 검증:** '큰 목표 입력 → 원자 행동 분해 → 10초 타이머 실행 → 완료' 플로우의 완벽한 작동 확인.
- **네이티브 알림 구현:** 원자 행동 실행 시간에 맞춰 안정적인 **로컬 푸시 알림** 기능 구현.
- **사용자 경험(UX) 집중:** 불필요한 기능 없이, 단순함과 빠른 반응 속도를 통해 사용자가 10초 행동에 집중하도록 유도.

## 2. 대상 사용자 및 핵심 가치 (Target User & Value)

- **대상 사용자:** 실행력 부족으로 중요한 일을 미루는 경향이 있는 학생 및 직장인.
- **핵심 가치:**
    1. **시작의 저항 해소:** 10초 규칙을 강제하여 일을 **'생각'**이 아닌 **'행동'**으로 전환.
    2. **프라이버시 우선:** $\text{Firebase}$를 사용하되, 사용자 $\text{ID}$ 기반 로컬/개인 데이터 저장 구조 유지.

## 3. 핵심 기능 (Core Features - MVP Scope)

### 3.1. 원자 분해 플로우 (Atomic Decomposition Flow)

| ID | 요구사항 | 세부사항 (React Native 구현 시 고려사항) |
|--|--|--|
| $\text{F1.1}$ 목표 입력 | 앱 실행 시 가장 먼저 '큰 목표'를 입력받는 $\text{UI}$ 제공. | 목표가 입력된 후에는 목표 수정 불가 (새 목표를 만들 때만 가능). |
| $\text{F1.2}$ 원자 행동 생성 | 현재 목표를 달성하기 위한 다음 10초 행동을 입력받는 모달/화면 제공. | 텍스트 입력 필드 외에 다른 옵션(날짜, 반복)은 $\text{MVP}$에서 제외하여 단순화. |
| $\text{F1.3}$ 행동 완료 | 원자 행동을 완료 처리하는 버튼 또는 10초 타이머 완료 기능 구현. | $\text{Haptic Feedback}$ (햅틱 피드백)을 사용하여 완료 시 즉각적인 성취감 제공. |

### 3.2. 10초 실행 및 네이티브 알림 (Execution & Notifications)

| ID | 요구사항 | 세부사항 (React Native 구현 시 고려사항) |
|--|--|--|
| $\text{F2.1}$ 10초 타이머 $\text{UI}$ | 현재 실행할 원자 행동 중앙에 10초 카운트다운 타이머를 시각적으로 명확하게 표시. | 타이머 실행 시 화면을 **'집중 모드'**로 전환하여 다른 요소 최소화. |
| $\text{F2.2}$ 로컬 푸시 알림 | 사용자가 설정한 '리마인드 시간'에 맞춰 네이티브 로컬 알림 발송. | react-native-push-notification 또는 유사 모듈을 사용하여 $\text{iOS/Android}$ 모두에 안정적인 알림 구현. |
| $\text{F2.3}$ 알림 액션 | 알림을 탭하면 앱이 즉시 열리고, 현재 실행해야 할 원자 행동 화면으로 직접 이동해야 함. | 알림 페이로드 처리를 통해 딥 링크(Deep Link) 기능 구현. |

### 3.3. 데이터 및 저장 (Data & Persistence)

| ID | 요구사항 | 세부사항 (React Native 구현 시 고려사항) |
|--|--|--|
| $\text{F3.1}$ 백엔드 | $\text{Firebase Auth}$ (익명/커스텀 토큰) 및 $\text{Firestore}$를 사용하여 데이터 저장 및 동기화. | 데이터 구조: BigGoal (String), Action (String), Status (Pending/Completed), UserID (UID) |
| $\text{F3.2}$ 오프라인 우선 | $\text{React Native}$ $\text{AsyncStorage}$와 $\text{Firestore}$의 오프라인 캐싱 기능을 활용하여 인터넷 연결이 끊겨도 작동하도록 설계. | 오프라인 상태에서 완료된 작업은 연결 복구 시 $\text{Firestore}$에 자동 동기화되어야 함. |

## 4. 사용자 경험 (UX) 및 디자인 요구사항

- **미니멀 디자인:** $\text{UI}$는 간결하고 방해 요소가 없어야 함. 핵심은 행동과 타이머에 집중.
- **단일** $\text{Focus}$**:** 앱 실행 시, 완료되지 않은 **현재 원자 행동**에 시선이 바로 가도록 디자인.
- **키보드 최적화:** 새로운 원자 행동을 입력할 때 키보드가 자동으로 올라오도록 하여 입력의 속도를 높여야 함.
- **색상:** 시작, 진행, 완료 상태를 명확하게 구분하는 단순한 색상 팔레트 사용 (예: 시작 유도 - 인디고, 완료 - 그린).

## 5. $\text{MVP}$ 제외 기능 (Out of Scope for MVP)

- 복잡한 반복 패턴 (매주 특정 요일 등). (단순 일회성 알림만 지원)
- 위치 기반 알림 (지오펜싱).
- 사용자 간 공유 또는 협업 기능.
- 통계 및 분석 대시보드.
- 텍스트 외 첨부 파일 (이미지, 음성 등).
