# 📎 Paperclip (미니멀리스트 텍스트 아카이빙 앱)

버전: 1.0 (MVP)

작성일: 2025년 11월 28일

작성자: Gemini

## 1. 제품 비전 및 목표 (Product Vision & Goals)

### 1.1. 비전

복잡한 문서 구조나 포맷팅 없이, 사용자의 **순간적인 생각의 파편과 외부 텍스트 조각**을 가장 빠르고 안전하게 캡처하고 검색할 수 있는 미니멀리스트 텍스트 저장소를 제공한다.

### 1.2. $\text{MVP}$ 목표

- 핵심 기능인 **'초고속 텍스트 캡처'**와 **'즉각 검색'**이 완벽하게 작동하는지 검증.
- 사용자의 민감한 기록에 대한 **프라이버시 중심의 가치** 검증.
- 출시 후 3개월 내 주간 활성 사용자(WAU) 1,000명 확보.

## 2. 대상 사용자 (Target User)

- **전문가 (지식 노동자):** 아이디어나 코드 조각, 외부 자료의 인용문을 빠르게 캡처하고 분류하려는 개발자, 작가, 기획자.
- **프라이버시 중시 사용자:** 클라우드 서버에 민감한 개인 메모를 저장하는 것을 꺼려하며, 자신의 기기에 데이터를 보관하고 싶어 하는 사용자.

## 3. 핵심 기능 (Core Features - MVP Scope)

### 3.1. 텍스트 캡처 및 저장 (Capture & Save)

- $\text{F1.1}$ **초고속 메모 작성:** 앱 실행 시 즉시 텍스트 입력 창이 활성화되어 지연 없이 새로운 메모를 작성할 수 있어야 함. (Links 2.0의 빠른 공유 시트 철학 적용)
- $\text{F1.2}$ **공유 시트 캡처:** 다른 $\text{App}$ (웹 브라우저, $\text{Slack}$, 메신저)에서 텍스트를 선택 후 공유 시트를 통해 $\text{Paperclip}$에 저장할 수 있어야 함. 이 경우 원본 $\text{URL}$ 및 출처가 함께 저장되어야 함.
- $\text{F1.3}$ **저장 완료 피드백:** 캡처 완료 시 미니멀하고 즉각적인 시각적/촉각적 피드백 제공.

### 3.2. 관리 및 정리 (Management & Organization)

- $\text{F2.1}$ **단일 목록** $\text{UI}$**:** 모든 메모는 단일 스크롤 목록(최신순 정렬)으로 표시되어야 함. 복잡한 폴더 구조는 $\text{MVP}$에서 제외.
- $\text{F2.2}$ **태그 부여:** 메모 저장 시 또는 저장 후 빠르게 하나 이상의 태그를 부여할 수 있어야 함. 태그는 단순 텍스트로만 구성.
- $\text{F2.3}$ **아카이빙:** 메모를 활성 목록에서 보관함으로 이동시키는 '아카이브' 기능 제공. 삭제 기능은 미제공 (보관함 이동으로 대체).

### 3.3. 검색 (Instant Search)

- $\text{F3.1}$ **통합 검색:** 메모의 내용과 부여된 태그를 모두 아울러 **즉각적으로** 결과를 보여주는 검색 기능 구현. (검색어 입력 즉시 필터링 시작)
- $\text{F3.2}$ **태그 필터링:** 특정 태그를 눌러 해당 태그가 포함된 메모만 필터링하여 볼 수 있어야 함.

### 3.4. 데이터 및 프라이버시 (Data & Privacy)

- $\text{F4.1}$ **로컬 저장소 우선:** 모든 메모 데이터는 사용자 기기의 로컬 저장소에 우선 저장.
- $\text{F4.2}$ $\text{iCloud}$ **동기화:** 계정 생성 과정 없이, $\text{Apple}$ $\text{ID}$ 기반의 $\text{iCloud}$를 통해 다중 $\text{Apple}$ 기기 간 동기화 구현.
- $\text{F4.3}$ **생체 인식 잠금:** 앱 실행 시 생체 인식 $(\text{Face ID/Touch ID})$을 통한 잠금 기능 제공.

## 4. 사용자 흐름 (User Flow - 핵심 시나리오)

|          |                      |                                                                                                                                                                                           |                                                           |
| -------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| **순서** | **시나리오**         | **동작**                                                                                                                                                                                  | **결과**                                                  |
| **1.**   | **새 메모 작성**     | 사용자, 앱 실행 $\rightarrow$ 메인 화면 상단 $+\text{ 버튼}$ 터치 $\rightarrow$ 입력 창에 텍스트 입력 후 $\text{Done}$ 버튼 터치 $\rightarrow$ 태그 입력 $(\text{Optional})$.             | 메모가 목록 최상단에 추가됨. 즉시 $\text{iCloud}$ 동기화. |
| **2.**   | **외부 텍스트 캡처** | 사용자, 사파리에서 텍스트 선택 $\rightarrow$ 공유 시트 열기 $\rightarrow$ $\text{Paperclip}$ 아이콘 선택 $\rightarrow$ $\text{Paperclip}$ 팝업에서 태그 입력 $(\text{Optional})$ 후 저장. | 해당 텍스트와 $\text{URL}$이 메모로 저장됨.               |
| **3.**   | **메모 검색**        | 사용자, 메인 화면 상단 검색 바 터치 $\rightarrow$ 검색어 입력 $(\text{예: ‘아이디어’})$.                                                                                                  | 입력 즉시 관련 메모들이 실시간으로 필터링되어 표시됨.     |

## 5. 비기능적 요구사항 (Non-Functional Requirements)

- **성능:** 메모 저장 및 검색 속도는 1초를 초과해서는 안 되며, 특히 검색 기능은 즉각적인 반응성을 보여야 함.
- **보안:** $\text{iCloud}$ 동기화 시 데이터 암호화 필수.
- $\text{UI/UX}$**:** 미니멀리즘 디자인 원칙을 따르며, 불필요한 색상 및 애니메이션 배제.

## 6. $\text{MVP}$ 제외 기능 (Out of Scope for MVP - Phase 2)

- 복잡한 폴더 구조 또는 다단계 계층 분류.
- 텍스트 외 파일 첨부 (이미지, 음성 등).
- 웹/데스크톱 버전 $(\text{iOS/macOS}$ 앱에 집중).
- 메모 편집 기록 $(\text{Version History})$.
- 고급 포맷팅 $(\text{Markdown}, \text{Rich Text})$.
