# Paperclip - 미니멀리스트 텍스트 아카이빙 앱 구현 계획

PRD와 목업 이미지를 기반으로 한 Android용 텍스트 아카이빙 앱 개발 계획입니다.

## 프로젝트 개요

**목표:** 순간적인 생각과 외부 텍스트 조각을 빠르게 캡처하고 검색할 수 있는 미니멀리스트 텍스트 저장소 구현

**기술 스택:**
- React Native + Expo (크로스 플랫폼 개발)
- TypeScript (타입 안정성)
- AsyncStorage (로컬 저장소)
- React Navigation (화면 네비게이션)

> [!IMPORTANT]
> 이 프로젝트는 MVP 범위로 진행되며, 핵심 기능인 '초고속 텍스트 캡처'와 '즉각 검색'에 집중합니다.

## 주요 변경 사항

### 핵심 애플리케이션 구조

#### 프로젝트 설정
- `package.json`: 프로젝트 의존성 및 스크립트 정의
- `tsconfig.json`: TypeScript 컴파일러 설정
- `app.json`: Expo 앱 설정 (앱 이름, 아이콘, 스플래시 스크린 등)
- `babel.config.js`: Babel 설정 (react-native-reanimated 플러그인 포함)

### 데이터 모델 및 타입

#### `src/types/index.ts`
핵심 데이터 타입 정의
- `Memo`: 메모 데이터 구조 (id, content, tags, createdAt, isArchived)
- `Tag`: 태그 데이터 구조

### 데이터 레이어

#### `src/services/storage.ts`
로컬 저장소 관리 서비스
- AsyncStorage를 사용한 메모 CRUD 작업
- 메모 목록 조회 (최신순 정렬)
- 아카이브 처리
- 태그 관리

#### `src/services/search.ts`
검색 기능 구현
- 메모 내용 및 태그 통합 검색
- 실시간 필터링 로직
- 태그별 필터링

### UI 컴포넌트

#### `src/components/MemoItem.tsx`
메모 목록 아이템 컴포넌트
- 메모 내용 미리보기 (첫 2줄)
- 태그 표시
- 생성 시간 표시
- 터치 시 상세 화면 이동

#### `src/components/TagChip.tsx`
태그 칩 컴포넌트
- 미니멀한 태그 디자인
- 클릭 시 필터링 기능

#### `src/components/SearchBar.tsx`
검색 바 컴포넌트
- 실시간 검색 입력
- 검색어 클리어 버튼

### 화면

#### `src/screens/MemoListScreen.tsx`
메인 메모 목록 화면
- 상단 검색 바
- + 버튼 (새 메모 작성)
- 메모 목록 (FlatList)
- 실시간 검색 필터링
- Pull-to-refresh
- SafeAreaView 적용 (Android 상태바 대응)

#### `src/screens/CreateMemoScreen.tsx`
메모 작성 화면
- 자동 포커스 텍스트 입력
- 태그 입력 (선택 사항)
- Done 버튼
- SafeAreaView 적용

#### `src/screens/MemoDetailScreen.tsx`
메모 상세 화면
- 전체 메모 내용 표시
- 태그 표시
- 아카이브 버튼
- SafeAreaView 적용

#### `src/screens/ArchiveScreen.tsx`
아카이브 화면
- 아카이브된 메모 목록
- 복원 기능
- SafeAreaView 적용

### 네비게이션

#### `src/navigation/AppNavigator.tsx`
앱 네비게이션 구조
- Stack Navigator (메모 목록 → 상세 → 작성)
- Tab Navigator (활성 메모 / 아카이브)

### 테마 및 스타일링

#### `src/theme/index.ts`
미니멀리즘 디자인 테마
- 색상 팔레트 (흑백 기반, 최소한의 강조색)
- 타이포그래피
- 간격 시스템

### 앱 진입점

#### `App.tsx`
앱 진입점
- 네비게이션 설정
- 폰트 로딩 (Inter)
- 스플래시 스크린 관리

## 검증 계획

### 자동화된 테스트
```bash
# 프로젝트 초기화 및 의존성 설치
npm install

# 개발 서버 실행
npx expo start

# Android에서 실행
npx expo start --android

# TypeScript 타입 체크
npx tsc --noEmit
```

### 수동 검증

#### 1. 핵심 기능 테스트
- [x] **초고속 메모 작성**: 앱 실행 → + 버튼 → 텍스트 입력 → 저장 (1초 이내 완료)
- [x] **실시간 검색**: 검색 바에 텍스트 입력 시 즉각 필터링 확인
- [x] **태그 필터링**: 태그 클릭 시 해당 태그 메모만 표시
- [x] **아카이브**: 메모 터치 → 아카이브 → 아카이브 탭에서 확인

#### 2. UI/UX 검증
- [x] 미니멀한 디자인 (불필요한 색상/애니메이션 없음)
- [x] 반응 속도 (모든 작업 1초 이내)
- [x] Android 상태바 겹침 문제 해결 (SafeAreaView 적용)

#### 3. 데이터 영속성
- [x] 앱 종료 후 재실행 시 메모 유지 확인

#### 4. 성능 테스트
- [x] 검색 디바운싱 적용 (300ms)
- [x] FlatList 최적화

## 디버깅 과정

개발 중 다음과 같은 문제들을 해결했습니다:

1. **진입점 충돌**: Expo Router와 커스텀 `App.tsx` 충돌 → `App.tsx` 표준화
2. **설정 파일 누락**: `babel.config.js` 생성 및 `react-native-reanimated` 플러그인 추가
3. **코드 아티팩트**: 마크다운 코드 블록 마커(```) 제거
4. **레이아웃 문제**: Android 상태바 겹침 → SafeAreaView 적용

## Phase 2 고려사항 (MVP 이후)

다음 기능들은 MVP 범위를 벗어나며, 사용자 피드백 후 구현 여부 결정:

1. **클라우드 동기화**: Google Drive API 또는 Firebase 연동
2. **공유 기능**: Android Share Intent 구현
3. **생체 인식 잠금**: 선택적 보안 기능
4. **iOS/macOS 앱**: React Native iOS 또는 별도 SwiftUI 앱
5. **고급 검색**: 정규식, 날짜 범위 필터
6. **메모 편집**: 현재는 읽기 전용, 편집 기능 추가
7. **위젯**: Android 홈 화면 위젯으로 빠른 메모 작성
