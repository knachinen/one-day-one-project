# MVP 메모장 실행 가이드

## 개요
React Native (Expo)와 TypeScript로 제작된 심플한 MVP 메모장 애플리케이션입니다.
글래스모피즘 효과가 적용된 다크/라이트 모드 디자인을 특징으로 하며, AsyncStorage를 사용하여 데이터를 영구 저장합니다.

## 실행 방법

1.  **프로젝트 디렉토리로 이동:**
    ```bash
    cd p03_w01-3_notepad
    ```

2.  **개발 서버 시작:**
    ```bash
    npx expo start
    ```
    *캐시 문제가 발생할 경우 `npx expo start -c`를 사용하세요.*

3.  **디바이스/에뮬레이터에서 실행:**
    -   **iOS 시뮬레이터:** 터미널에서 `i`를 누르세요.
    -   **Android 에뮬레이터:** 터미널에서 `a`를 누르세요.
    -   **실물 디바이스:** Expo Go 앱으로 QR 코드를 스캔하세요.

## 주요 기능
-   **메모 작성:** 우측 하단의 "+" 버튼을 눌러 새 메모를 작성합니다.
-   **메모 수정:** 목록에서 메모를 탭하여 내용을 수정합니다.
-   **메모 삭제:** 메모의 "×" 버튼을 누르면 확인 알림 후 삭제됩니다.
-   **테마 변경:** 상단의 해/달 아이콘을 눌러 다크 모드와 라이트 모드를 전환합니다.
-   **데이터 저장:** 메모와 테마 설정은 앱을 재시작해도 유지됩니다.

## 파일 구조
-   `App.tsx`: 메인 진입점 및 상태 관리.
-   `src/components/NoteList.tsx`: 메모 목록 표시.
-   `src/components/NoteEditor.tsx`: 메모 작성/수정 에디터.
-   `src/utils/storage.ts`: AsyncStorage 데이터 저장 처리.
-   `src/styles/theme.ts`: 테마 색상 및 공통 스타일 정의.
