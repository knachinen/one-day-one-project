# 메모앱 랜딩페이지 단계별 구현 계획

본 문서는 메모앱 랜딩페이지를 **최소 단위 → 점진적 고도화** 방식으로 구현하기 위한 단계별 실행 계획이다. 각 단계는 **독립적으로 실행·배포 가능**하며, 이전 단계에 의존하지 않고도 가치가 전달되도록 설계한다.

---

## 단계 설계 원칙

- 각 단계는 **배포 가능한 상태**여야 함
    
- 기능·디자인·기술 리스크를 **조기에 분산**
    
- "보여지는 가치" 기준으로 우선순위 설정
    
- 애니메이션/고급 기능은 **후속 단계로 분리**
    

---

## Phase 0. 프로젝트 기반 세팅 (Foundation)

> 목적: 이후 모든 단계의 기술적 토대 확보

### 구현 범위

- Next.js 프로젝트 생성
    
- 기본 레이아웃 구성
    
- 공통 설정 정리
    

### 작업 항목

- Next.js(App Router) 초기화
    
- Tailwind CSS 설치
    
- ESLint / Prettier 설정
    
- 기본 폰트(Pretendard) 적용
    
- `/app/layout.tsx` 구성
    

### 산출물

- 빈 페이지가 아닌 기본 랜딩 뼈대
    
- 로컬/프리뷰 배포 가능 상태
    

➡️ **단독 배포 가능**

## Phase 1. 정적 히어로 섹션 (No Animation)

> 목적: 핵심 메시지 전달 MVP

### 구현 범위

- 히어로 영역 정적 UI
    
- CTA 버튼 노출
    

### 작업 항목

- 헤드라인 텍스트 배치
    
- 서브 카피 추가
    
- Primary / Secondary CTA 버튼
    
- 반응형 타이포그래피 적용
    

### 제외 항목

- 애니메이션
    
- 플로팅 카드
    

### 성공 기준

- 첫 화면에서 서비스 가치 인지 가능
    
- 모바일/데스크탑 레이아웃 정상
    

➡️ **마케팅 랜딩 최소 MVP**

> 목적: 인터랙션 감각 부여

- Fade / Slide 애니메이션
    

### 작업 항목

- CTA 버튼 hover 효과
