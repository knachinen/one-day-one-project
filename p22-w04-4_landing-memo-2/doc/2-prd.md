# 메모앱 랜딩페이지 제품 요구사항 명세서 (PRD)

## 문서 정보

- **프로젝트명**: 메모앱 랜딩페이지
- **버전**: 1.0
- **작성일**: 2024년 12월
- **문서 목적**: 개발팀과 디자인팀이 참고할 상세 기능 명세 및 구현 가이드

---

## 1. 프로젝트 개요

### 1.1 배경 및 목적

빠르고 직관적인 메모 경험을 제공하는 앱의 핵심 가치를 전달하고, 사용자가 직접 체험해볼 수 있는 인터랙티브 랜딩페이지를 구축하여 전환율을 극대화한다.

### 1.2 목표 지표 (KPI)

- CTA 클릭률: 15% 이상
- 체험 완료율: 60% 이상
- 스크롤 도달률 (섹션 5까지): 70% 이상
- 전환율 (가입/다운로드): 8% 이상
- 페이지 이탈률: 40% 이하

### 1.3 타겟 사용자

**Primary**

- 직장인 (25-40세): 회의록, 업무 메모, 아이디어 관리
- 대학생/대학원생 (19-28세): 강의 노트, 과제 정리, 스터디

**Secondary**

- 프리랜서/크리에이터: 프로젝트 아이디어, 콘텐츠 기획
- 개인 생산성에 관심 있는 일반 사용자

### 1.4 핵심 메시지

"생각이 떠오르는 순간, 바로 메모"

## 2. 기술 스택 및 아키텍처

### 2.1 프론트엔드

- **프레임워크**: React 18+ (또는 Next.js 14+)
- **스타일링**: Tailwind CSS
- **애니메이션 라이브러리**:
    - Framer Motion (컴포넌트 기반 애니메이션)
    - GSAP (복잡한 스크롤 기반 애니메이션)
- **아이콘**: Lucide React
- **타이핑 효과**: react-type-animation

### 2.2 성능 요구사항

- **초기 로딩 시간**: 3초 이내 (First Contentful Paint)
- **Lighthouse 점수**:
    - Performance: 90점 이상
    - Accessibility: 95점 이상
    - Best Practices: 95점 이상
    - SEO: 100점
- **이미지 최적화**: WebP 포맷, lazy loading 적용
- **애니메이션 최적화**: GPU 가속 속성(transform, opacity) 우선 사용

### 2.3 반응형 브레이크포인트

- Mobile: 320px - 767px
- Tablet: 768px - 1023px
- Desktop: 1024px - 1439px
- Large Desktop: 1440px 이상

## 3. 섹션별 상세 요구사항

### 3.1 히어로 섹션 (Hero Section)

#### 3.1.1 레이아웃 구성

```
[배경 그라데이션 애니메이션]
  ├─ 네비게이션 바 (로고, 메뉴, CTA 버튼)
  ├─ 메인 헤드라인 (타이핑 애니메이션)
  ├─ 서브 헤드라인
  ├─ CTA 버튼 그룹 (다운로드, 무료 체험)
  └─ 떠다니는 메모 카드 (3-5개)
```

#### 3.1.2 기능 요구사항

**FR-H-001: 타이핑 애니메이션**

- **설명**: 메인 헤드라인에서 사용 시나리오가 순환하며 표시
- **텍스트 목록**:
    - "회의록 작성"
    - "아이디어 정리"
    - "일일 저널"
    - "강의 노트"
    - "프로젝트 기획"
- **타이핑 속도**: 80ms/문자
- **대기 시간**: 2초 (각 문구 완성 후)
- **삭제 속도**: 50ms/문자
- **반복**: 무한 루프

**FR-H-002: 떠다니는 메모 카드**

- **카드 수**: 5개
- **카드 내용**: 실제 메모 예시 (짧은 텍스트, 체크리스트, 링크 등)
- **인터랙션**:
    - 마우스 커서를 따라 parallax 효과 (거리 기반)
    - 각 카드는 독립적인 부유 애니메이션 (진폭, 속도 다름)
    - 호버 시 카드 확대 (scale: 1.05) + 그림자 강화
- **모바일**: 터치 시 간단한 wiggle 애니메이션

**FR-H-003: 배경 그라데이션**

- **컬러**: 라벤더(#C7B3E5) → 민트(#A7E6D7) → 피치(#FFD4B8)
- **애니메이션**:
    - 그라데이션 위치가 느리게 이동 (20초 주기)
    - 부드러운 ease-in-out
- **다크모드**:
    - 다크 퍼플(#2D1B4E) → 다크 틸(#1B4E42) → 다크 오렌지(#4E2D1B)

**FR-H-004: CTA 버튼**

- **버튼 1**: "무료로 시작하기" (Primary)
- **버튼 2**: "앱 다운로드" (Secondary)
- **호버 효과**:
    - 펄스 애니메이션 (scale: 1 → 1.02 → 1, 1초 주기)
    - 그림자 확장
    - 배경색 약간 밝아짐
- **클릭 효과**: 리플 애니메이션 (클릭 지점에서 원형 확산)

**FR-H-005: 스크롤 인디케이터**

- **위치**: 화면 하단 중앙
- **디자인**: 아래 화살표 + "스크롤하여 더 보기" 텍스트
- **애니메이션**:
    - 위아래 bounce 애니메이션
    - 스크롤 시작하면 페이드아웃
- **클릭 액션**: 다음 섹션으로 부드럽게 스크롤

#### 3.1.3 애니메이션 타이밍

```
페이지 로드 후:
0ms    : 배경 그라데이션 시작
100ms  : 로고 페이드인
200ms  : 메인 헤드라인 슬라이드업 + 페이드인
400ms  : 서브 헤드라인 슬라이드업 + 페이드인
600ms  : CTA 버튼 그룹 슬라이드업 + 페이드인
800ms  : 떠다니는 메모 카드 순차 등장 (각 100ms 간격)
1500ms : 타이핑 애니메이션 시작
```

### 3.2 핵심 기능 소개 섹션 (Features Section)

#### 3.2.1 레이아웃 구성

```
[섹션 헤더]
  ├─ 타이틀: "메모가 달라집니다"
  ├─ 서브타이틀: "복잡하지 않지만 강력한 기능들"
  
[기능 네비게이션 탭]
  ├─ 빠른 기록
  ├─ 자동 정리
  ├─ 스마트 검색
  └─ 실시간 동기화
  
[프리뷰 영역]
  ├─ 앱 UI 목업 (좌측 60%)
  └─ 상세 설명 (우측 40%)
```

#### 3.2.2 기능 요구사항

**FR-F-001: 기능 목록**

|기능명|설명|아이콘|프리뷰 내용|
|---|---|---|---|
|빠른 기록|생각나는 순간 즉시 메모, 최소 클릭으로 작성 시작|Zap|빈 화면에서 타이핑 시작하는 애니메이션|
|자동 정리|AI가 태그와 카테고리를 제안, 자동 분류|Sparkles|메모에 자동으로 태그가 붙는 애니메이션|
|스마트 검색|내용, 태그, 날짜로 즉시 찾기|Search|검색어 입력 시 결과 하이라이트|
|실시간 동기화|모든 기기에서 항상 최신 상태 유지|RefreshCw|여러 디바이스에 동시 반영되는 애니메이션|

**FR-F-002: 탭 전환 인터랙션**

- **클릭 시**:
    - 선택된 탭 언더라인 이동 (슬라이드 애니메이션, 300ms)
    - 프리뷰 영역 페이드아웃 → 콘텐츠 교체 → 페이드인 (총 600ms)
    - 앱 UI 목업은 왼쪽에서 슬라이드인
- **키보드 네비게이션**: 좌우 화살표로 탭 이동 가능

**FR-F-003: 스크롤 트리거 애니메이션**

- **진입 조건**: 섹션이 뷰포트 30% 진입 시
- **스태거 애니메이션**: 각 탭이 100ms 간격으로 슬라이드업 + 페이드인
- **아이콘 애니메이션**: SVG path drawing 효과 (1초)
- **1회 실행**: 한번 재생 후 정적 상태 유지

**FR-F-004: 3D 틸트 효과**

- **적용 대상**: 기능 카드 (마우스 호버 시)
- **틸트 각도**: 최대 ±10도
- **부드러움**: 마우스 이동에 따라 실시간 계산
- **모바일**: 비활성화

**FR-F-005: 마이크로 인터랙션 데모**

- **빠른 기록**: 커서 깜박임 → 타이핑 → 저장 체크마크
- **자동 정리**: 메모 내용 분석 → 태그 팝업 → 자동 적용
- **스마트 검색**: 검색어 입력 → 실시간 필터링 → 결과 하이라이트
- **실시간 동기화**: 한 디바이스에서 수정 → 다른 디바이스에 즉시 반영

#### 3.2.3 반응형 동작

- **Desktop**: 좌우 2단 레이아웃
- **Tablet**: 상하 레이아웃, 프리뷰 영역 축소
- **Mobile**:
    - 탭 대신 수평 스와이프 캐러셀
    - 프리뷰 영역은 간략화된 애니메이션만 표시

### 3.3 사용 시나리오 섹션 (Use Cases Section)

#### 3.3.1 레이아웃 구성

```
[섹션 헤더]
  ├─ 타이틀: "당신의 일상에 딱 맞는 메모"
  └─ 서브타이틀: "다양한 상황에서 활용해보세요"

[필터 버튼]
  ├─ 전체
  ├─ 학생
  ├─ 직장인
  └─ 크리에이터

[시나리오 카드 그리드]
  └─ 수평 스크롤 가능한 카드 레이아웃 (3-4개 표시)
```

#### 3.3.2 기능 요구사항

**FR-U-001: 시나리오 목록**

|시나리오|타겟|설명|일러스트|
|---|---|---|---|
|회의 중 빠른 메모|직장인|회의 내용을 실시간으로 기록하고 액션 아이템 체크리스트 생성|회의실 장면|
|강의 노트 정리|학생|수업 내용을 체계적으로 정리하고 시험 대비 복습|교실/책상 장면|
|아이디어 스케치|크리에이터|떠오르는 아이디어를 빠르게 기록하고 태그로 분류|스케치북 장면|
|여행 계획 수립|전체|여행지, 일정, 예산을 한곳에 정리|지도/비행기 장면|
|레시피 저장|전체|좋아하는 레시피를 사진과 함께 보관|주방 장면|
|독서 노트|학생/크리에이터|책을 읽으며 인상 깊은 구절과 생각 기록|책/카페 장면|

**FR-U-002: 필터링 기능**

- **동작**: 필터 버튼 클릭 시 해당 카테고리 카드만 표시
- **애니메이션**:
    - 필터 아웃되는 카드: scale-down + fade-out (300ms)
    - 필터 인되는 카드: scale-up + fade-in (300ms, 100ms 스태거)
- **"전체" 선택**: 모든 카드 표시
- **활성 상태**: 선택된 필터 버튼 강조 표시

**FR-U-003: 카드 인터랙션**

- **호버 효과**:
    - 카드 살짝 상승 (translateY: -8px)
    - 그림자 강화
    - 일러스트 약간 확대 (scale: 1.05)
- **클릭 액션**: 모달 팝업으로 상세 내용 표시
    - 모달 배경: 블러 처리된 오버레이
    - 모달 콘텐츠:
        - 큰 일러스트
        - 상세 설명 (3-4문장)
        - 주요 기능 하이라이트
        - "지금 시작하기" CTA 버튼

**FR-U-004: 수평 스크롤**

- **Desktop**:
    - 마우스 휠로 수평 스크롤 (shift + 휠 불필요)
    - 좌우 화살표 네비게이션 버튼
    - 드래그로 스크롤 가능
- **Mobile**:
    - 터치 스와이프
    - 스냅 스크롤 (각 카드에 스냅)
- **스크롤 인디케이터**: 하단에 진행 바 표시

**FR-U-005: Parallax 효과**

- **배경 일러스트**: 카드 이동 시 배경이 더 느리게 이동
- **전경 요소**: 카드 이동 시 전경 요소가 더 빠르게 이동
- **깊이감**: 3단계 레이어 (배경 - 카드 - 전경)

#### 3.3.3 모달 명세

**모달 구조**

```html
<모달 오버레이 (backdrop-blur)>
  <모달 컨테이너 (glassmorphism)>
    <닫기 버튼 (우상단 X)>
    <일러스트 영역>
    <콘텐츠 영역>
      ├─ 시나리오 제목
      ├─ 타겟 배지
      ├─ 상세 설명
      ├─ 주요 기능 리스트
      └─ CTA 버튼
  </모달 컨테이너>
</모달 오버레이>
```

**모달 애니메이션**

- **열기**:
    - 오버레이 페이드인 (200ms)
    - 모달 scale-up (0.95 → 1) + 페이드인 (300ms)
- **닫기**:
    - 모달 scale-down (1 → 0.95) + 페이드아웃 (200ms)
    - 오버레이 페이드아웃 (300ms)
- **닫기 트리거**:
    - X 버튼 클릭
    - 오버레이 클릭
    - ESC 키

### 3.4 신뢰 요소 섹션 (Social Proof Section)

#### 3.4.1 레이아웃 구성

```
[섹션 헤더]
  ├─ 타이틀: "이미 많은 분들이 사용하고 있어요"
  
[통계 카드 그리드 (3개)]
  ├─ 누적 메모 수: 10,000,000+
  ├─ 활성 사용자: 500,000+
  └─ 평균 평점: 4.8/5.0

[후기 캐러셀]
  ├─ 좌측 화살표
  ├─ 후기 카드 (3개 동시 표시)
  ├─ 우측 화살표
  └─ 인디케이터 점
```

#### 3.4.2 기능 요구사항

**FR-S-001: 통계 카운터 애니메이션**

- **트리거**: 섹션이 뷰포트 50% 진입 시
- **애니메이션**:
    - 0부터 목표 숫자까지 카운트업 (1.5초)
    - Ease-out 이징 함수
    - 큰 숫자는 쉼표로 구분
- **스태거**: 각 통계 카드 200ms 간격으로 시작
- **1회 실행**: 다시 스크롤해도 재실행 안 됨

**FR-S-002: 후기 카드 데이터 구조**

```javascript
{
  id: string,
  name: string,
  role: string, // "대학생", "마케터", "개발자" 등
  avatar: string, // URL 또는 이니셜
  rating: number, // 1-5
  comment: string, // 2-3문장
  date: string // "2024년 11월"
}
```

**FR-S-003: 캐러셀 기능**

- **자동 재생**:
    - 5초마다 다음 슬라이드로 이동
    - 무한 루프
- **마우스 호버 시**: 자동 재생 일시정지
- **수동 네비게이션**:
    - 좌우 화살표 버튼
    - 인디케이터 점 클릭
    - 키보드 좌우 화살표
    - 터치 스와이프 (모바일)
- **전환 애니메이션**:
    - 현재 카드: 페이드아웃 + 왼쪽으로 슬라이드
    - 다음 카드: 오른쪽에서 슬라이드인 + 페이드인
    - 총 500ms

**FR-S-004: 별점 애니메이션**

- **트리거**: 카드가 뷰포트에 진입할 때마다
- **애니메이션**:
    - 각 별이 순차적으로 나타남 (각 100ms 간격)
    - 별이 작게 시작해서 커지며 회전 (scale + rotate)
    - 노란색 fill 애니메이션
- **총 시간**: 500ms

**FR-S-005: 아바타 표시**

- **이미지 있을 경우**: 원형 프로필 사진
- **이미지 없을 경우**:
    - 이름 이니셜 (최대 2글자)
    - 랜덤 배경색 (사용자별 고정)
- **크기**: 48px × 48px
- **등장 애니메이션**: 카드 전환 시 살짝 bounce

#### 3.4.3 반응형 동작

- **Desktop**: 후기 카드 3개 동시 표시
- **Tablet**: 후기 카드 2개 동시 표시
- **Mobile**: 후기 카드 1개만 표시

### 3.5 CTA 섹션 (Call-to-Action Section)

#### 3.5.1 레이아웃 구성

```
[배경 (그라데이션 + 파티클)]
  
[콘텐츠 컨테이너]
  ├─ 메인 헤드라인: "지금 바로 시작하세요"
  ├─ 서브 헤드라인: "가입 후 30초면 첫 메모를 작성할 수 있어요"
  
  [입력 폼]
    ├─ 이메일 입력 필드
    ├─ 제출 버튼: "무료로 시작하기"
    └─ 약관 동의 텍스트 (작은 글씨)
  
  [대체 액션]
    └─ "앱 다운로드" 버튼 (iOS/Android 뱃지)
```

#### 3.5.2 기능 요구사항

**FR-C-001: 이메일 입력 필드**

- **플레이스홀더**: "이메일 주소를 입력하세요"
- **유효성 검사**:
    - 실시간 검증 (이메일 형식)
    - 오류 시 필드 하단에 빨간색 메시지 표시
    - 성공 시 초록색 체크마크 아이콘 표시
- **포커스 효과**:
    - 필드 확대 (scale: 1.02)
    - 테두리 색상 변경 (그라데이션)
    - 그림자 강화
- **접근성**:
    - label 연결
    - aria-label 제공
    - 오류 메시지 aria-live

**FR-C-002: 제출 버튼**

- **기본 상태**: "무료로 시작하기" 텍스트
- **로딩 상태**:
    - 스피너 아이콘 회전
    - "처리 중..." 텍스트
    - 버튼 비활성화
- **성공 상태**:
    - 체크마크 아이콘
    - "완료!" 텍스트
    - 초록색 배경
    - 1초 후 confetti 효과
- **오류 상태**:
    - X 아이콘
    - "다시 시도" 텍스트
    - 빨간색 배경

**FR-C-003: 제출 플로우**

```
1. 사용자가 이메일 입력
2. 유효성 검사 통과
3. "무료로 시작하기" 버튼 클릭
4. 버튼 → 로딩 상태 (1-2초 시뮬레이션)
5. API 호출 (실제 구현 시)
6. 성공 응답
7. 버튼 → 성공 상태
8. Confetti 효과 발생
9. 2초 후 감사 메시지 토스트 표시
10. 또는 가입 완료 페이지로 리디렉션
```

**FR-C-004: Confetti 효과**

- **트리거**: 제출 성공 시
- **파티클**:
    - 수량: 100-150개
    - 색상: 브랜드 컬러 팔레트
    - 크기: 랜덤 (4-12px)
    - 형태: 원형, 사각형 혼합
- **애니메이션**:
    - 화면 상단에서 하단으로 낙하
    - 좌우로 흔들림 (sine wave)
    - 회전 효과
    - 중력 시뮬레이션
- **지속 시간**: 3초
- **성능**: requestAnimationFrame 사용

**FR-C-005: 배경 파티클**

- **지속적 애니메이션**:
    - 작은 점들이 천천히 부유
    - 마우스 커서 근처로 끌려오는 효과
- **수량**: 30-50개
- **색상**: 반투명 흰색 (opacity: 0.3-0.6)
- **성능 고려**: Canvas API 사용

**FR-C-006: 앱 다운로드 버튼**

- **플랫폼 감지**:
    - iOS → App Store 뱃지
    - Android → Google Play 뱃지

- **호버 효과**:

    - 또는 다운로드 모달 팝업

### 4.4 접근성 (Accessibility)

**FR-A-001: 키보드 네비게이션**

- **Tab 키**: 모든 인터랙티브 요소 순차 이동
- **Shift+Tab**: 역순 이동
- **Enter/Space**: 버튼 활성화
- **Escape**: 모달/메뉴 닫기
- **화살표 키**: 캐러셀/탭 네비게이션

**FR-A-002: 포커스 인디케이터**

- **스타일**:
    - 2px 실선 테두리
    - 브랜드 Primary 색상
    - 4px offset
- **애니메이션**: 페이드인 (200ms)

**FR-A-003: ARIA 속성**

- 모든 인터랙티브 요소에 적절한 role
- aria-label 제공 (아이콘 버튼 등)
- aria-expanded (드롭다운, 아코디언)
- aria-live (동적 콘텐츠)
- aria-current (현재 페이지/섹션)

**FR-A-004: 시맨틱 HTML**

- 적절한 heading 계층 (h1 → h2 → h3)
- nav, main, section, article 태그 활용
- button vs a 태그 올바른 사용

**FR-A-005: 색상 대비**

- **WCAG AA 기준 준수**:
    - 일반 텍스트: 4.5:1 이상
    - 큰 텍스트: 3:1 이상
- **검증**: Contrast Checker 도구로 확인

**FR-A-006: 애니메이션 제어**

- **prefers-reduced-motion 지원**:
    - 사용자가 "애니메이션 줄이기" 설정 시
    - 모든 애니메이션 비활성화 또는 최소화
    - 즉시 전환으로 대체
- **구현**:
    
    ```css
    @media (prefers-reduced-motion: reduce) {  * {    animation-duration: 0.01ms !important;    transition-duration: 0.01ms !important;  }}
    ```

### 4.5 성능 최적화

**FR-O-001: 이미지 최적화**

- **포맷**: WebP (fallback: JPG/PNG)
- **반응형 이미지**: srcset 활용
- **Lazy Loading**:
    - 뷰포트 밖 이미지 지연 로딩
    - loading="lazy" 속성
- **압축**: TinyPNG 또는 ImageOptim 사용
- **크기**:
    - Hero 이미지: 최대 200KB
    - 아이콘: SVG 우선
    - 썸네일: 최대 50KB

**FR-O-002: 코드 스플리팅**

- **라우트 기반**: 각 섹션 lazy import
- **컴포넌트 기반**: 무거운 컴포넌트 동적 로딩
- **라이브러리**:
    - Framer Motion: 사용하는 컴포넌트만 import
    - Lodash: 개별 함수만 import

**FR-O-003: 폰트 최적화**

- **서브셋**: 한글+영문+숫자만 포함
- **Preload**: 주요 폰트 미리 로드
- **Font Display**: swap 사용
- **WOFF2 포맷**: 최신 브라우저 지원

**FR-O-004: 애니메이션 최적화**

- **GPU 가속**:
    - transform, opacity 우선 사용
    - will-change 속성 (신중하게)
- **requestAnimationFrame**:
    - 스크롤 리스너 최적화
    - 파티클 애니메이션
- **Throttle/Debounce**:
    - 스크롤 이벤트: throttle (100ms)
    - 리사이즈 이벤트: debounce (250ms)

**FR-O-005: 캐싱 전략**

- **Service Worker**:
    - 정적 리소스 캐싱
    - 오프라인 지원 (선택)
- **CDN**:
    - 이미지, 폰트 CDN 제공
    - Cloudflare, AWS CloudFront 등
- **브라우저 캐시**:
    - 긴 만료 시간 설정
    - 버전 관리 (쿼리 파라미터)

## 부록

### A. 용어 정의

- **Glassmorphism**: 반투명 배경 + 블러 효과로 유리 질감을 표현하는 디자인 트렌드
- **Stagger Animation**: 여러 요소가 시간차를 두고 순차적으로 애니메이션되는 기법
- **Parallax**: 전경과 배경이 다른 속도로 움직여 깊이감을 주는 효과
- **Confetti**: 축하 효과로 화면에 색종이 조각이 흩날리는 애니메이션
- **GPU 가속**: 그래픽 처리 장치를 활용해 애니메이션 성능을 향상시키는 기술
