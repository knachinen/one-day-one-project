# PRD Grok ver.

### 인스타그램 유사 이미지·짧은 글 공유 커뮤니티 웹서비스

제품 요구사항 명세서 (PRD)  
(2025년 기준 최신 트렌드 반영 버전)

#### 1. 프로젝트 개요

- 서비스명: (예시) “Vivid” (임시)
- 목적: 사진·짧은 동영상·짧은 텍스트를 중심으로 한 모바일 퍼스트 소셜 미디어 플랫폼
- 타겟 사용자: 13~35세 (주 타겟 18~30세)
- 핵심 가치 제안
  - 빠르고 직관적인 콘텐츠 업로드 및 소비
  - 고품질 비주얼 피드
  - 알고리즘 기반 “탐색” 탭으로 새로운 크리에이터 발견
  - 스토리, 릴스, 피드 3축 콘텐츠 전략

#### 3. 상세 기능 요구사항

3.1. 회원가입·로그인

- 13세 이상만 가입 가능 (COPPA 준수)
- 이메일 인증 또는 휴대폰 OTP 필수
- 2단계 인증 옵션 제공

  3.2. 게시물 (피드)

- 이미지: 최대 10장 (정방향 1:1, 세로 4:5, 가로 1.91:1 지원)
- 동영상: 최대 60초, 1080p, H.265 권장
- 필터 30종 이상 기본 제공 + AR 효과
- 캡션 최대 2,200자, 해시태그, @멘션, 위치 태그
- 접근 권한: 전체 공개 / 팔로워만 / 나만 보기

  3.3. 스토리

- 15초 단위 사진/동영상
- 텍스트, 스티커, GIF, 음악, 폴(투표), 질문, 퀴즈, 카운트다운
- 하이라이트 무제한 저장 가능
- 답장 시 DM으로 자동 연결

  3.4. 릴스 (Reels)

- 15~90초 세로 영상 전용
- TikTok과 동일한 편집 도구 (속도 조절, 타이머, 정렬, 듀엣, 스티치)
- 인기 음원 라이브러리 10만 곡 이상
- 별도 탐색 알고리즘 운영 (초기 노출은 팔로워 비율 30% 이하)

  3.5. 알고리즘 피드

- 시그널: 좋아요, 댓글, 저장, 공유, 시청 완료율, 팔로우 여부, 과거 관심사
- A/B 테스트를 위한 3개 이상 피드 버전 동시 운영 가능해야 함

  3.6. 알림

- 실시간 푸시 + 앱 내 알림 센터
- 알림 종류별 온/오프 세부 설정 가능

#### 4. 비기능 요구사항

- 동시 접속자 100만 명 기준 99.9% 가용성
- 이미지·동영상 CDN 전 세계 분산
- 첫 로딩 3초 이내 (Cold start 5초 이내)
- iOS 15+, Android 90% 이상 Android 기기 지원
- 다국어: 한국어, 영어, 일본어, 스페인어, 인도네시아어 (MVP 5개 언어)
- 접근성: VoiceOver, TalkBack, 색약 모드, 고대비 테마

#### 5. 데이터 및 개인정보 보호

- GDPR, CCPA, 한국 개인정보보호법 완전 준수
- 게시물 삭제 시 30일 내 모든 CDN·백업에서 완전 삭제
- 데이터 다운로드 기능 (EU 요구사항)

#### 6. 기술 스택 제안 (참고용)

- 프론트: React Native (Expo) 또는 Flutter
- 백엔드: Node.js (NestJS) 또는 Kotlin Spring Boot
- DB: PostgreSQL + Redis + Elasticsearch
- 스토리지: AWS S3 + CloudFront 또는 Cloudflare R2
- 동영상 처리: FFmpeg + MediaConvert, 썸네일 자동 생성
- 푸시: Firebase Cloud Messaging + 자체 APNs 대체 예정

#### 7. 론칭 로드맵 (예시)

- MVP (0~6개월): 기본 피드 + 스토리 + 프로필 + DM
- Phase 1 (6~12개월): 릴스 완성 + 탐색 탭 고도화 + 알림 완성
- Phase 2 (12~18개월): 라이브 + 쇼핑 + 인사이트 + 광고 시스템

#### 8. 성공 지표 (KPI)

- DAU/MAU ≥ 30%
- 평균 세션 시간 ≥ 25분
- 게시물 1개당 평균 인터랙션(좋아요+댓글+공유) 12회 이상
- 90일 리텐션 ≥ 40%

#### 6. 기술 스택 제안 (2025년 최신 트렌드 업데이트)

2025년 소셜 미디어 앱 개발 트렌드를 반영하여 리서치 결과(웹 검색 기반: 소셜 앱 스택 가이드, 프론트엔드 프레임워크 비교, 백엔드 스케일링 기술 등)를 바탕으로 업데이트하였습니다. 주요 변화:

- 프론트엔드: Flutter의 성능 및 크로스플랫폼 효율성 강조 (React Native와 병행).
- 백엔드: Node.js 유지하되, Go 언어 추가로 고성능 실시간 처리 강화.
- DB: 그래프 DB(Neo4j) 도입으로 소셜 그래프(팔로우/추천) 최적화.
- 스토리지 및 동영상: AWS 중심 유지, AI 기반 비디오 트랜스코딩 고려.
- 푸시: FCM 표준화, 멀티채널(웹/모바일) 지원 강화.

- **프론트엔드**: Flutter (권장) 또는 React Native (Expo)

  - 이유: 2025년 모바일 소셜 앱에서 Flutter가 UI 일관성과 60fps 성능으로 선호됨 (React Native는 JS 생태계 강점). 크로스플랫폼 개발 속도 2배 향상.

- **백엔드**: Node.js (NestJS) 또는 Go (Gin/Echo)

  - 이유: Node.js는 실시간 채팅/DM에 적합하나, 2025년 스케일링 트렌드로 Go가 고부하(100만+ 동시 사용자)에서 효율적 (메모리 사용 30% 감소).

- **DB**: PostgreSQL (관계형 데이터) + MongoDB (NoSQL 피드/콘텐츠) + Redis (캐싱/세션) + Neo4j (그래프 DB for 소셜 연결) + Elasticsearch (검색)

  - 이유: Instagram-like 앱에서 그래프 DB가 추천/팔로우 쿼리 속도 5배 향상. MongoDB는 유연한 미디어 메타데이터 저장에 최적.

- **스토리지**: AWS S3 + CloudFront (CDN) 또는 Cloudflare R2

  - 이유: 2025년 클라우드 스토리지 트렌드에서 S3의 글로벌 엣지 캐싱이 지연 50ms 이내 보장. R2는 비용 절감 옵션.

- **동영상 처리**: FFmpeg + AWS Elemental MediaConvert (AI 기반 트랜스코딩), 썸네일 자동 생성 (Sharp 라이브러리 통합)

  - 이유: 2025년 숏폼 비디오(릴스) 증가로 AI 업스케일링 지원. MediaConvert가 4K/HEVC 처리 속도 40% 향상.

- **푸시 알림**: Firebase Cloud Messaging (FCM) + APNs (iOS) + Web Push API (PWA 지원)
  - 이유: 2025년 푸시 통계에서 FCM이 90% 채택률, 멀티플랫폼(모바일/웹) 통합으로 리텐션 300% 증가.

추가 고려: AI/ML 통합 (TensorFlow.js for 추천 알고리즘) 및 서버리스 아키텍처 (AWS Lambda)로 비용 최적화. 전체 스택은 MERN/Go 기반 하이브리드로, MVP 개발 기간 20% 단축 예상.
