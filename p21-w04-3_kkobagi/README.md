# 🌸 Kkobagi (꼬바기) - 습관 추적기

## 🌟 프로젝트 개요

Kkobagi (꼬바기)는 "꾸준히" 또는 "규칙적으로"를 의미하는 한국어에서 영감을 받은 습관 추적 애플리케이션입니다. 사용자 친화적인 인터페이스를 통해 일일 진행 상황을 추적하고 좋은 습관을 형성하며 유지할 수 있도록 돕습니다. 사용자의 습관 달성률을 시각적으로 나타내는 캐릭터, 습관 달성도에 따라 성장하는 습관 나무, 주간 진행 상황을 한눈에 볼 수 있는 차트 등 흥미로운 기능을 제공합니다.

## ✨ 주요 기능

-   **대시보드:** 일일 달성률, 환영/격려 메시지, 오늘의 습관 목록, 습관 나무 및 주간 달성률을 포함하는 직관적인 3단 레이아웃.
-   **꼬바기 캐릭터:** 일일 습관 달성률에 따라 변화하는 캐릭터가 사용자에게 동기를 부여하고 긍정적인 메시지를 전달합니다.
-   **습관 카드:** 각 습관은 전용 아이콘, 이름, 연속 달성 일수 및 완료 여부를 표시하는 카드로 제공됩니다.
-   **습관 나무:** 사용자의 습관 달성 수준에 따라 성장하는 시각적인 나무를 통해 꾸준함의 가치를 느낄 수 있습니다.
-   **주간 달성률 차트:** 파이 차트와 요약 정보를 통해 이번 주 습관 달성률을 시각적으로 보여줍니다.
-   **쉬운 습관 관리:** 새로운 습관 추가 및 히스토리 확인을 위한 명확한 내비게이션 버튼을 제공합니다.

## 🚀 설치 및 실행

프로젝트를 로컬 환경에서 설정하고 실행하려면 다음 단계를 따르세요.

### 1. 전제 조건

-   [Node.js](https://nodejs.org/) (버전 18 이상 권장)
-   [npm](https://www.npmjs.com/) 또는 [Yarn](https://yarnpkg.com/)

### 2. 의존성 설치

프로젝트 저장소를 클론한 후, 프로젝트 디렉토리로 이동하여 필요한 의존성을 설치합니다:

```bash
git clone [YOUR_REPOSITORY_URL]
cd kkobagi
npm install
# 또는 yarn install
```

### 3. 개발 서버 실행

개발 모드로 애플리케이션을 실행합니다:

```bash
npm run dev
# 또는 yarn dev
```

애플리케이션은 `http://localhost:3000`에서 실행됩니다.

### 4. 프로덕션 빌드

프로덕션 배포를 위한 빌드 파일을 생성합니다:

```bash
npm run build
# 또는 yarn build
```

### 5. 프로덕션 서버 시작

빌드된 애플리케이션을 프로덕션 모드로 실행합니다:

```bash
npm run start
# 또는 yarn start
```

## 🧹 린팅

코드 품질을 유지하기 위해 린터를 실행합니다:

```bash
npm run lint
# 또는 yarn lint
```

## 📏 개발 컨벤션

-   **ESLint:** 코드 린팅을 위해 `eslint-config-next`를 확장하여 사용합니다.
-   **Prettier:** `.prettierrc.json` 파일을 통해 사용자 정의 형식 설정을 사용하여 코드 형식을 지정합니다.
-   **Zustand:** 애플리케이션의 상태는 Zustand를 사용하여 관리되며, 로컬 스토리지에 유지됩니다.
-   **모듈화:** 컴포넌트, 훅, 스토어, 타입 등은 각각의 디렉토리에 명확하게 분리되어 관리됩니다.
