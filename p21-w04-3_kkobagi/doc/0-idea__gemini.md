
## 🏆 프로젝트 상세 기획: 습관 형성 챌린지 (Habit Builder)

선택하신 **'습관 형성 챌린지'** 프로젝트는 일반인이 흥미를 느끼기 쉽고, 데이터베이스 사용법과 세련된 데이터 시각화(바이브 코딩)를 동시에 학습할 수 있는 매우 효과적인 아이디어입니다.

아래는 이 프로젝트의 목표, 주요 기능, 그리고 기술 스택 및 학습 커리큘럼입니다.

---

### 1. 프로젝트 목표 및 주요 기능

|**분류**|**상세 목표**|**필수 구현 기능**|
|---|---|---|
|**바이브 코딩 & UX**|미니멀리즘과 데이터 시각화를 결합한 **세련된 대시보드** 구축.|**사용자 친화적인 습관 달력** 및 **달성률 차트** 표시.|
|**DB 활용 & Backend**|**날짜 기반 데이터** 처리 및 **복잡한 연속 달성 로직** 구현.|습관 등록/수정/삭제 (CRUD), **특정 날짜의 달성 여부 기록**, 연속 달성 일수(Streak) 계산.|
|**AI 활용 (교육)**|AI 도구를 활용하여 연속 달성 계산 로직(알고리즘) 및 데이터 시각화 컴포넌트 코드를 빠르게 구현.|개발 과정 전반에서 AI 도구(Copilot, ChatGPT 등)를 코딩 보조 도구로 활용.|

### 2. 기술 스택 (Habit Builder 최적화)

|**영역**|**추천 기술 스택**|**상세 활용 방안**|
|---|---|---|
|**프런트엔드 (UI/UX)**|**React (Next.js)** + **Tailwind CSS** + **Chart.js 또는 Recharts**|Tailwind로 깔끔한 디자인 구현. `Chart.js` 또는 `Recharts`를 사용하여 DB 데이터를 멋진 그래프로 변환하는 시각화 학습.|
|**백엔드 (Logic)**|**Node.js (Express)**|비동기 처리 및 API 구축에 대중적이며, 특히 날짜/시간 데이터 처리 로직 구현에 적합.|
|**데이터베이스 (DB)**|**PostgreSQL (또는 MySQL)**|습관 정보, 사용자 정보, 일별 달성 기록 등 **정형화된 데이터** 관리에 강하며, 연속성 로직을 위한 **복잡한 쿼리(SQL)** 작성 연습에 최적.|

### 3. DB 설계 및 학습 포인트 강화

이 프로젝트는 다음과 같은 DB 테이블 설계와 백엔드 로직 구현을 통해 난이도 있는 학습을 유도할 수 있습니다.

#### ① 테이블 설계 (예시)

|**테이블 명**|**주요 필드**|**DB 학습 포인트**|
|---|---|---|
|`Users`|`user_id`, `email`, `password`|기본적인 사용자 관리 및 인증 로직 구현.|
|`Habits`|`habit_id`, `user_id (FK)`, `name`, `frequency`, `start_date`|습관 정보 저장. `frequency` 필드로 **반복 주기(매일, 주 3회 등)**를 설정하여 로직 복잡도 증가.|
|`HabitRecords`|`record_id`, `habit_id (FK)`, `date`, `is_completed`|**날짜(`date`)**와 **참/거짓(`is_completed`)** 데이터를 활용하여 일별 달성 여부를 기록하고 조회하는 핵심 테이블.|

#### ② 핵심 로직 학습 목표

- **CRUD 구현:**    
    - 새 습관 등록 (`Habits` 테이블에 Insert).        
    - 특정 날짜의 달성 여부 토글(Toggle) (`HabitRecords` 테이블에 Upsert).        
- **연속 달성(Streak) 계산 로직:**    
    - `HabitRecords` 테이블에서 현재 날짜를 기준으로 **가장 최근 기록까지 거슬러 올라가며** 연속으로 `is_completed`가 True인 일수를 계산하는 **복잡한 SQL 쿼리 또는 백엔드 로직** 구현. (가장 난이도 높은 학습 목표)        
- **데이터 시각화 데이터 추출:**    
    - 지난 30일간의 일별 달성률 데이터를 DB에서 조회하여, 프런트엔드 차트 컴포넌트가 이해할 수 있는 **JSON 형식**으로 가공하여 API 응답을 만드는 연습.        

### 4. 바이브 코딩 (디자인/UX 집중)

세련되고 감각적인 UX를 위해 다음 디자인 요소에 집중하도록 교육합니다.

1. **미니멀한 대시보드:** 복잡한 정보 대신, **오늘의 습관**과 **핵심 통계(Streak)** 만 상단에 배치하고, Tailwind CSS의 색상 및 그림자 유틸리티를 활용해 깔끔한 카드로 표현합니다.    
2. **색상 피드백:** 습관의 달성 여부(성공/실패)를 명확하게 구분하는 **대비되는 색상(예: 파스텔 그린 vs. 소프트 레드)** 을 사용하여 시각적인 피드백을 제공합니다.    
3. **애니메이션 차트:** 데이터를 조회하면 `Chart.js` 또는 `Recharts`를 통해 **부드러운 애니메이션 효과**와 함께 주간/월간 달성률 막대 차트를 보여주어 '바이브'를 높입니다.
