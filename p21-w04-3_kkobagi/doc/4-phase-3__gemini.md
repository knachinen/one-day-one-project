## 📈 Phase 3 상세 구현 명세서: 회고 및 데이터 인사이트

**목표:** 사용자에게 축적된 데이터를 바탕으로 깊이 있는 **분석 인사이트**를 제공하고, **데이터 내보내기** 및 **고도화된 알림** 기능을 통해 플랫폼의 완결성을 높입니다.

**기술 스택:** Next.js, Recharts (트렌드 분석), Browser Notification API, PapaParse (CSV 추출)

---

### 🟢 세부 단계 3.1: 습관별 상세 통계 및 트렌드 분석

| 세부 단계 목표 | 개별 습관의 성과를 정량적으로 분석하고 시각화하여 사용자의 자기 객관화를 돕습니다. |
| :--- | :--- |
| **구현 항목** | **습관 상세 페이지**, **트렌드 라인 차트 (FR-012)** |
| **세부 명세** | 1. **상세 대시보드:** 특정 습관 클릭 시 총 성공 횟수, 평균 달성률, 최장 스트릭 등 요약 지표 표시. |
| | 2. **트렌드 시각화:** **Recharts**를 사용하여 최근 7일 및 30일간의 달성률 변화를 보여주는 **라인 차트** 구현. |
| | 3. **데이터 처리:** LocalStorage의 `HabitRecord`를 날짜별로 그룹화하여 차트용 JSON 데이터로 변환하는 유틸리티 함수 작성. |
| **검증 방법** | 1. 개별 습관 카드를 클릭했을 때 해당 습관에 특화된 통계 수치가 정확히 노출되는지 확인합니다. |
| | 2. 지난 7일간의 체크 기록을 임의로 생성했을 때 라인 차트가 기록에 맞게 꺾은선으로 그려지는지 확인합니다. |

---

### 🟡 세부 단계 3.2: 꼬바기의 주간/월간 회고 메시지

| 세부 단계 목표 | 단순한 수치를 넘어 꼬바기의 목소리로 성과를 칭찬하거나 위로하며 감성적 완결성을 제공합니다. |
| :--- | :--- |
| **구현 항목** | **데이터 기반 회고 로직 (FR-012)**, **회고 UI 피드백** |
| **세부 명세** | 1. **회고 엔진:** 지난 7일간의 달성률을 분석하여 상태값(최상, 보통, 저조)을 도출합니다. |
| | 2. **맞춤형 UX Writing:** 상태값에 따라 꼬바기의 목소리로 작성된 회고 메시지 노출. |
| | | *예시: (달성률 90%↑) "이번 주 정말 완벽해요! 꼬바기가 다 뿌듯하네요!"* |
| | | *예시: (달성률 30%↓) "잠깐 쉬어도 괜찮아요. 내일 꼬바기랑 다시 시작해요!"* |
| **검증 방법** | 1. 주간 평균 달성률이 높을 때와 낮을 때, 꼬바기가 출력하는 텍스트와 표정이 의도대로 바뀌는지 확인합니다. |

---

### 🟠 세부 단계 3.3: 브라우저 알림 및 스누즈(Snooze) 기능

| 세부 단계 목표 | 서비스에 접속하지 않아도 습관을 잊지 않도록 푸시 알림을 통해 행동을 유도합니다. |
| :--- | :--- |
| **구현 항목** | **브라우저 알림 API 연동 (FR-013)**, **알림 스누즈 로직** |
| **세부 명세** | 1. **알림 권한 요청:** 사용자의 승인을 받아 브라우저 알림(Web Notification) 권한을 획득합니다. |
| | 2. **스케줄링 구현:** 설정된 `notification_time`에 맞춰 알림을 발송합니다 (가입 없는 프로토타입 버전에서는 브라우저가 열려 있을 때 작동하는 `setTimeout` 기반으로 구현). |
| | 3. **스누즈 기능:** 알림 클릭 시 '10분 후 다시 알림' 등의 스누즈 옵션을 제공합니다. |
| **검증 방법** | 1. 습관 설정에서 알림 시간을 현재 시간 1분 후로 설정하고, 정해진 시간에 브라우저 알림이 오는지 확인합니다. |
| | 2. 스누즈 버튼 클릭 시 정확히 10분(또는 테스트용 짧은 시간) 뒤에 알림이 재발송되는지 확인합니다. |

### 🔴 세부 단계 3.4: 데이터 내보내기 및 관리

| 세부 단계 목표 | 브라우저에 저장된 소중한 기록을 파일로 소장하거나 안전하게 보관할 수 있게 합니다. |
| :--- | :--- |
| **구현 항목** | **CSV 내보내기 (FR-016)**, **전체 데이터 초기화** |
| **세부 명세** | 1. **CSV 변환:** LocalStorage의 모든 `HabitRecord`와 `Streak` 데이터를 CSV 형식으로 파싱합니다 (PapaParse 라이브러리 활용 가능). |
| | 2. **다운로드 트리거:** 사용자가 버튼 클릭 시 `habit_records_20251217.csv`와 같은 파일명으로 즉시 다운로드됩니다. |
| | 3. **데이터 초기화:** 사용자의 모든 LocalStorage 기록을 삭제하기 전 마지막 확인 팝업을 띄우는 기능을 구현합니다. |
| **검증 방법** | 1. '내보내기' 버튼 클릭 시 다운로드된 CSV 파일에 본인의 습관 이름과 체크 날짜들이 정확히 포함되어 있는지 엑셀로 확인합니다. |
| | 2. 초기화 실행 후 대시보드와 통계 페이지의 모든 데이터가 사라지는지 확인합니다. |
