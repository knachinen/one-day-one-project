## 1. 통합 기획 문서 아웃라인 (Consolidated Outline)

### I. 서비스 개요 및 목표 (Service Overview & Goals)

- **제품명/브랜딩**: MVP Studio (ChatGPT) 또는 SoloMVP Forge (Grok).
- **제품 비전 및 목적**: 린 스타트업 방법론을 기반으로 아이디어 검증 → MVP 정의 → 실행 계획까지 자동화된 기획을 완성하도록 지원.
- **문제 정의**: 1인 기업가의 기획 경험 부족, MVP 범위 설정 실패, 문서화에 시간 과다 소비 해결.
- **핵심 가치 제안 (USP)**:
    - 복잡한 기획 과정을 질문 기반 템플릿으로 자동 안내하고 구조화된 사고를 유도.
    - 결과물을 개발에 바로 사용할 수 있는 최종 기획 산출물(PDF/PRD/MD)로 자동 생성.
- **타겟 사용자**: 1인 기업가(솔로프레너), 사이드 프로젝트 개발자, 노코드 빌더, 비기술 창업자.

### II. 핵심 기능 및 워크플로우 (Core Features & Workflow)

- **린 기획 단계별 흐름 (Workflow)**:
    - **Claude 방식 (5단계)**: 문제 발견 → 솔루션 정의 → MVP 범위 설정 → 검증 계획 → 실행 로드맵.
    - **ChatGPT 방식 (10가지 템플릿 구성)**: 문제 정의, 고객, 가설, 가치 제안, 경쟁 분석, MVP 정의, 검증 계획, 지표 정의, 개발 범위, 실행 로드맵.
- **템플릿 구성 요소**:
    - 문제 정의 (Problem Statement) 및 대상 고객 (Persona) 정의.
    - 가치 제안 (Value Proposition Canvas) 및 핵심 가설 (Hypothesis) 설정.
    - 경쟁/대안 분석.
    - Lean Canvas (아이디어의 핵심 요소 정립) 작성 지원.
- **MVP 범위 확정 도구**:
    - **기능 우선순위 설정**: MoSCoW (Must, Should, Could, Won't) 우선순위 태그 부여.
    - **MVP 범위 자동 추천**: 주어진 문제와 페르소나를 기반으로 적합한 MVP 기능 자동 제안 (AI 기반, 후속 버전).
- **검증 및 지표 정의**:
    - 검증 계획 (Validation Plan) 및 실험 설계 템플릿 제공.
    - 핵심 성과 지표(Metric, OMTM, AARRR) 입력 및 목표치 설정.
    - **검증 설문 자동 생성**: 기획 내용에 맞춰 AI가 피드백 설문지 자동 생성 (Grok).

### III. 사용자 경험 및 산출물 (UX/UI & Deliverables)

- **UI/UX 특징**: Step-by-step Wizard 형태의 단계별 입력 화면 강조.
- **가이드 기능**:
    - 각 입력 필드마다 짧고 명확한 질문 제공.
    - 예시, 힌트, 툴팁 제공 및 린 스타트업 원칙 설명.
    - **AI 보조 기능**: 입력 내용 기반으로 문구 초안 자동 생성 및 논리적 흐름에 대한 피드백 제공 (Claude, Grok, ChatGPT 공통).
- **프로젝트 관리 기능**:
    - 대시보드에서 프로젝트 목록, 진행률(완료율 %) 추적, 마지막 수정일 노출.
    - 자동 저장 기능 (10초마다 또는 Auto-save).
    - 로드맵 타임라인 빌더 또는 간단한 로드맵 UI (Gantt-like) 제공.
- **최종 산출물 생성**:
    - **자동 기획 문서 생성**: 작성한 내용을 정리하여 MVP PRD (Product Requirements Document), Lean Canvas, Feature Roadmap 등으로 자동 변환.
    - **내보내기 형식**: PDF 다운로드, Markdown 다운로드, Notion 템플릿 복사, 웹뷰 기획서 제공.

### IV. 기술 스택 및 구조 (Technical Stack & Architecture)

- **프론트엔드**:
    - **프레임워크**: Next.js v16.x (App Router 기반) 및 React v19.x.
    - **언어/스타일**: TypeScript, Tailwind CSS v4.x.
    - **상태 관리**: Zustand.
- **백엔드/런타임**:
    - **안정성 우선 옵션**: Node.js v24.x (LTS) + Express v5.x.
    - **성능/최신 옵션**: Bun v1.3.x + Hono v4.7+ (Claude 제안).
- **데이터베이스/ORM**:
    - **관계형(권장)**: PostgreSQL v18.x + Prisma v7.x (또는 Drizzle ORM).
    - **NoSQL 옵션**: MongoDB v8.2 + Mongoose (Grok 제안).
- **개발 환경**: 로컬 환경에 최적화된 경량 웹 앱, Docker/Docker Compose를 활용한 환경 통일.
- **보안**: 최신 안정 버전(예: Next.js 16.0.7+, React 19.2.1)을 사용하여 CVSS 10.0 보안 취약점(CVE)에 대한 패치를 적용하는 것을 강조 (Claude).

### V. 비즈니스 모델 및 로드맵 (Business Model & Roadmap)

- **비즈니스 모델**: Freemium 모델 채택.
    - **무료**: 기본 템플릿 사용, 1~3개 프로젝트 생성 가능.
    - **프리미엄**: 무제한 프로젝트 생성, AI 도우미 기능, 심화 템플릿, PDF 클린 Export, 버전 관리 기능 제공.
- **마케팅 전략**: LinkedIn, Reddit(r/solopreneur) 등 커뮤니티를 통한 초기 유입 및 SEO 블로그 콘텐츠 활용.
- **성공 지표 (MVP)**: 첫 방문 후 템플릿 50% 이상 완성률 60% 이상, 기획서 Export 실행률 30% 이상, 월간 활성 사용자(MAU) 2,000명 이상 목표.
- **로드맵**:
    - Phase 1 (MVP, 1~3개월): 기본 템플릿, 입력/자동 저장, Export 기능 구현.
    - Phase 2 (확장): AI 도우미, 기획서 공유/피드백, 커뮤니티 기능, 프리미엄 구독 도입.
