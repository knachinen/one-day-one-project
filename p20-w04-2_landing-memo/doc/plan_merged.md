# 메모앱 랜딩페이지 기획안

## 목적 및 목표

- **목적**: 메모앱의 핵심 가치를 직관적으로 전달하고, 체험 중심의 인터랙션으로 전환(다운로드/가입)을 유도
- **KPI**: CTA 클릭률, 체험 완료율, 스크롤 도달률, 전환율

---

## 타겟 사용자

- 빠르게 기록하고 정리하고 싶은 직장인/학생
- 복잡한 기능보다 **즉시성·간결함**을 선호하는 사용자

---

## 핵심 메시지

- "생각이 떠오르는 순간, 바로 메모"

---

## 전체 정보 구조 (IA)

1. 히어로 섹션 (첫 인상 + 즉시 체험)
2. 핵심 기능 소개 (문제 → 해결)
3. 사용 시나리오
4. 신뢰 요소 (후기/숫자)
5. CTA (다운로드/시작하기)

---

## 5. 섹션별 상세 기획

### 5.1 히어로 섹션


- **핵심 메시지**: "생각이 떠오르는 순간, 바로 메모"
- **인터랙티브 요소**:
    - 타이핑 애니메이션으로 다양한 사용 시나리오 표시 ("회의록 작성", "아이디어 정리", "일일 저널")
    - 마우스 커서를 따라 움직이는 떠다니는 메모 카드들
    - 실시간으로 작성되는 듯한 메모 데모 (텍스트가 자동으로 타이핑되며 나타남)
- **애니메이션**:
    - 페이지 로드 시 Hero 텍스트 페이드인 + 슬라이드업
    - 배경에 부드럽게 움직이는 그라데이션 효과
    - CTA 버튼 호버 시 펄스 효과 및 미묘한 그림자 변화

---

### 5.2 핵심 기능 소개 섹션

**구성 요소**

- 기능 3~4개 (빠른 기록, 자동 정리, 검색, 동기화)
- 아이콘 + 짧은 설명

**인터랙티브 요소**

- 스크롤 시 각 기능 카드가 순차적으로 나타남
- 기능 카드 호버 시 3D 틸트 효과
- 탭/버튼으로 기능 전환 시 실제 앱 UI 미리보기 전환 (페이드 + 슬라이드)
- 각 기능 설명에 마우스 오버 시 해당 기능의 마이크로 인터랙션 데모


**애니메이션**

- 아이콘이 그려지는 애니메이션 (SVG path animation)
- 기능 전환 시 부드러운 모핑 효과
- **스태거(stagger) 애니메이션**: 스크롤 트리거 애니메이션으로 요소들이 시차를 두고 등장 

---

### 5.3 사용 시나리오 섹션

**구성 요소**

- 상황별 탭 (회의 중 / 공부 중 / 아이디어 스케치)

**인터랙티브 요소**

- 수평 스크롤 또는 드래그로 다양한 사례 탐색
- 각 사례 카드 클릭 시 상세 모달 팝업
- 사용자 페르소나별 필터링 (학생, 직장인, 크리에이터 등)

**애니메이션**

- 카드 간 전환 시 parallax 효과
- 선택된 카드가 확대되며 전면에 나타나는 효과
- 배경 이미지/일러스트가 부드럽게 블러 처리되며 전환


---

### 5.4 신뢰 요소 섹션

**구성 요소**

- 사용자 후기 카드
- 사용 지표 (누적 메모 수, 활성 사용자 수)

**인터랙티브 요소**

- 자동 재생되는 캐러셀 (마우스 오버 시 일시정지)
- 좌우 네비게이션 화살표
- 하단 인디케이터 점으로 직접 이동

**애니메이션**

- 후기 카드 페이드 인/아웃 전환
- 별점이 순차적으로 채워지는 애니메이션
- 사용자 아바타가 부드럽게 등장



---

### 5.5 CTA 섹션

**구성 요소**

- 강력한 한 문장 메시지
- 다운로드 / 시작하기 버튼

**인터랙티브 요소**

- 이메일 입력 필드 포커스 시 확대 효과
- 실시간 입력 유효성 검사 피드백
- 제출 버튼 클릭 시 로딩 → 성공 애니메이션

**애니메이션**

- 배경에 떠다니는 파티클 효과
- 버튼 제출 시 체크마크 애니메이션
- 성공 메시지 confetti 효과

## 6. 공통 인터랙션 & 애니메이션 가이드

### 스크롤 기반

- **진행 표시 바**: 페이지 상단에 스크롤 진행도 표시
- **Parallax 스크롤링**: 배경 요소들이 다른 속도로 움직임
- **스크롤 스냅**: 각 섹션으로 부드럽게 스냅
- **요소 페이드/슬라이드**: 뷰포트 진입 시 요소들이 나타남

### 마우스 인터랙션

- **커스텀 커서**: 인터랙티브 요소 위에서 커서 변화
- **자기장 효과**: 버튼 근처로 마우스가 가면 버튼이 살짝 끌려옴
- **호버 효과**: 모든 클릭 가능한 요소에 부드러운 트랜지션

### 마이크로 인터랙션

- **버튼 클릭 리플 효과**: 클릭 지점에서 퍼지는 파장
- **토스트 알림**: 액션 완료 시 우아한 알림 메시지
- **로딩 스피너**: 데이터 로드 시 브랜드 컬러의 스피너

## 디자인 방향성

### 비주얼 스타일

- **모던 미니멀**: 깔끔하고 여백이 충분한 레이아웃
- **소프트 컬러**: 파스텔 톤의 그라데이션 (라벤더, 민트, 피치)
- **글래스모피즘**: 반투명 카드에 블러 효과
- **다크모드 지원**: 토글로 즉시 전환 가능

### 타이포그래피

- **헤드라인**: 대담하고 현대적인 산세리프 (예: Inter, Poppins)
- **본문**: 가독성 높은 시스템 폰트
- **애니메이션**: 텍스트 그라데이션 효과, 언더라인 애니메이션

### 아이콘 & 일러스트

- **3D 아이콘**: 입체감 있는 메모, 펜, 폴더 아이콘
- **애니메이션 일러스트**: Lottie 파일 활용
- **SVG 애니메이션**: 선이 그려지는 효과

### 기타 

- **Parallax Scrolling**: 배경과 foreground 요소가 다른 속도로 움직임 (깊이감 부여, e.g., Hero 배경 느리게 이동).
- **Fade-in / Slide-in**: 스크롤 시 텍스트나 이미지 순차 등장 (AOS 라이브러리 스타일).
- **Micro-animations**: 버튼 클릭 시 리플 효과, 아이콘 호버 시 살짝 회전 또는 bounce.
- **Lottie 애니메이션**: Hero에 메모 작성 과정 애니메이션 GIF (e.g., 펜으로 쓰는 듯한 handwriting 효과).
- **Scroll-triggered Animation**: 기능 섹션에서 스크롤하면 앱 UI가 "빌드업" 되는 애니메이션 (e.g., 빈 화면 → 노트 추가 → 태그 붙임).
