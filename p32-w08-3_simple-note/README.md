# Simple Note Project

이 저장소는 간단한 노트 관리 애플리케이션인 **Simple Note**의 소스 코드와 관련 문서를 포함하고 있습니다.

## 📂 프로젝트 구조

- **`simple-crud/`**: Next.js와 Supabase를 사용한 메인 애플리케이션 소스 코드.
- **`doc/`**: 프로젝트 개발 계획 및 단계별 구현 명세서.
- **`.github/`**: CI/CD를 위한 GitHub Actions 워크플로우.

## 🚀 빠른 시작

애플리케이션을 실행하거나 개발 환경을 설정하려면 `simple-crud` 디렉토리의 상세 가이드를 참조하세요.

👉 [**애플리케이션 README 바로가기 (simple-crud/README.md)**](./simple-crud/README.md)

## 📝 구현 단계

1. **환경 구축**: Next.js + Tailwind + Supabase 연동
2. **UI 반영**: 디자인 시스템 및 핵심 컴포넌트 구현
3. **CRUD 구현**: Supabase를 활용한 실시간 데이터 연동
4. **안정화**: 에러 핸들링, 테스트, CI/CD 구축 (현재 단계)
