디자인 업그레이드 명세서에 제시된 **인터랙티브 요소 강화** 및 **감각적인 디자인 요소 강화**를 구현하기 위한 상세 구현 계획 및 작업 목록입니다.

이 계획은 기존의 5단계 구조를 유지하면서, **2단계 (기반)**에 전역 디자인 설정을 추가하고, **4단계 (인터랙션)**를 업그레이드 요소의 핵심 구현 단계로 재구성하는 데 초점을 맞춥니다.

---

## 🚀 디자인 업그레이드 기반 구현 계획 및 작업 목록

### 1. 전역 디자인 시스템 및 커서 제어 (2단계 통합)

기존 2단계의 디자인 시스템 구축에 **고급 전역 미학 요소**를 선행 구축합니다.

| 작업 ID | 작업 내용 | 상세 구현 방안 | 적용 섹션 |
| :--- | :--- | :--- | :--- |
| **2.A.1** | **다이내믹 그라디언트 정의** | `tailwind.config.ts`에 브랜드 액센트 컬러를 기반으로 한 CSS 변수 기반의 **다이내믹 그라디언트 유틸리티**를 정의. | Global, Hero |
| **2.A.2** | **배경 노이즈/그리드 질감 구현** | `layout.tsx`에 `::before` 또는 별도 컴포넌트를 사용하여 낮은 `opacity`의 **유동적 노이즈(Noise)** 질감을 배경 위에 오버레이. | Global |
| **2.A.3** | **GSAP 커스텀 커서 컴포넌트 개발** | GSAP을 사용하여 마우스 위치를 추적하는 **`<CustomCursor />`** 컴포넌트 개발. | Global |
| **2.A.4** | **커서 인터랙션 로직 통합** | 버튼, 링크, 이미지 등 인터랙션 요소에 `data-cursor="magnetic"` 등 속성을 추가하고, 커스텀 커서가 이 속성을 감지하여 모양(크기/색상)을 동적으로 변경하는 로직 구현. | Global |
| **2.A.5** | **전역 페이지 전환 애니메이션** | Next.js 페이지 라우팅 시 `Framer Motion`의 **`AnimatePresence`**를 사용하여 페이지 간의 부드러운 **페이드/슬라이드 전환** 효과 구현. | Global |

### 2. 고급 인터랙션 및 애니메이션 코어 (4단계 집중)

기존 4단계를 **업그레이드된 명세**에 따라 완전히 대체하고, **Framer Motion의 고급 기능**과 **GSAP ScrollTrigger**를 활용합니다.

#### 2.1. 히어로 섹션 인터랙션 강화

| 작업 ID | 작업 내용 | 상세 구현 방안 | 핵심 기술 |
| :--- | :--- | :--- | :--- |
| **4.H.1** | **3D 텍스트 Parallax 및 왜곡** | Hero 텍스트를 글자 단위로 분리하고, 마우스 포지션에 따라 **미세한 3D 회전(Rotate)** 및 깊이감(`translateZ`) 변화 효과 구현. | `GSAP`, `Framer Motion` |
| **4.H.2** | **Magnetic Background 효과** | 배경 파티클/셰이프 컴포넌트 개발. 마우스 움직임에 따라 파티클이 끌어당겨지거나 밀어내는 듯한 **Magnetic Movement** 효과 구현. | `Framer Motion` (`useSpring`) |
| **4.H.3** | **스크롤 진행 표시줄 구현** | 화면 상단에 **스크롤 진행률**을 표시하는 얇은 Bar 컴포넌트 개발. `GSAP ScrollTrigger`의 **`progress`** 값을 활용하여 바의 너비를 동적으로 제어. | `GSAP ScrollTrigger` |

#### 2.2. 소개 섹션 인터랙션 강화

| 작업 ID | 작업 내용 | 상세 구현 방안 | 핵심 기술 |
| :--- | :--- | :--- | :--- |
| **4.A.1** | **이미지 마스크/Displacement 호버** | 프로필 이미지 호버 시, 이미지에 **셰이프 마스크** 또는 **Displacement 필터**를 적용하여 미세하게 왜곡/변형되는 시각적 효과 구현. | `CSS Filter`, `Framer Motion` |
| **4.A.2** | **Magnetic Movement 태그 구현** | 핵심 가치 태그 컴포넌트에 마우스 호버 시 **태그가 마우스 커서를 따라 부드럽게 이동**하거나 끌어당기는 듯한 효과 구현. | `Framer Motion` (`useMotionValue`) |
| **4.A.3** | **스크롤 연동 콘텐츠 전환** | About 섹션의 우측 **통계/스킬 영역**을 `position: sticky`로 고정. 스크롤 진행에 따라 고정된 영역 내에서 텍스트 콘텐츠가 부드럽게 전환되도록 연출. | `GSAP ScrollTrigger` |
| **4.A.4** | **3D 스킬 비주얼라이제이션** | 스킬 셋을 2D Bar 대신 **3D 큐브/도넛 형태**로 시각화. 각 스킬 값이 뷰포트에 들어올 때 3D 형태의 크기, 회전, 색상이 애니메이션 되도록 구현. | `Framer Motion`, `CSS 3D` |

#### 2.3. 프로젝트 섹션 인터랙션 강화

| 작업 ID | 작업 내용 | 상세 구현 방안 | 핵심 기술 |
| :--- | :--- | :--- | :--- |
| **4.P.1** | **Shared Layout 필터링 애니메이션** | 필터링 선택 시 프로젝트 카드의 등장, 퇴장, 재배치 애니메이션에 `Framer Motion`의 **`layout`** prop을 적용하여 끊김 없는 레이아웃 전환 구현. | `Framer Motion` (`layout`) |
| **4.P.2** | **카드 광원/줌 호버 효과** | 카드 호버 시 이미지 확대와 함께, 마우스 위치를 기반으로 움직이는 **radial-gradient**를 오버레이하여 동적인 **광원 효과** 구현. | `Framer Motion` (`whileHover`) |
| **4.P.3** | **상세 모달 Blur 배경 구현** | 프로젝트 상세 정보 **모달(Dialog)** 호출 시, 모달 외부의 배경 콘텐츠에 `backdrop-filter: blur()` 스타일을 적용하여 모달에 시선이 집중되도록 구현. | `shadcn/ui`, `Tailwind` (`backdrop-blur`) |
| **4.P.4** | **무한 스크롤 구현** | 프로젝트 목록 하단에 **`Intersection Observer`** API를 구현하여 목록 끝 감지. 감지 시 `TanStack Query`의 `fetchNextPage`를 호출하여 다음 데이터 자동 로드. | `TanStack Query`, `Intersection Observer` |

### 3. 최종 점검 및 운영 (5단계 통합)

업그레이드된 인터랙티브 요소에 대한 최종 안정성 및 성능 검증을 포함합니다.

| 작업 ID | 작업 내용 | 상세 구현 방안 | 검증 및 완료 기준 |
| :--- | :--- | :--- | :--- |
| **5.T.1** | **E2E 테스트 스크립트 업데이트** | Playwright/Cypress 스크립트에 **커스텀 커서 상호 작용**, **스크롤 연동 전환(4.A.3)**, **Magnetic 태그 반응(4.A.2)** 등 새로운 인터랙션을 검증하는 시나리오 추가. | 모든 인터랙티브 E2E 테스트 통과 확인. |
| **5.P.1** | **애니메이션 성능 최종 검증** | Chrome DevTools의 Performance 탭에서 애니메이션 실행 시 **GPU 활용률** 및 **메인 스레드 부하**를 모니터링하여 병목 현상 제거. | 애니메이션 중 CPU/GPU 사용률 목표치 이내 유지. |
| **5.L.1** | **Lighthouse CI 최종 점검** | 최종 코드를 Lighthouse CI에 통과시켜 **성능 및 접근성 점수**가 업그레이드 전보다 저하되지 않았는지 최종 검증. | Lighthouse **성능 90점 이상** 유지. |
