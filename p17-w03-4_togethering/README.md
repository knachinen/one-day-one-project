# 🚀 투게더링 (Togethering)

투게더링은 팀의 협업과 생산성을 극대화하기 위해 설계된 종합 프로젝트 및 일정 관리 서비스입니다. Next.js, Bun, SQLite, Prisma 기술 스택을 기반으로 강력하고 직관적인 사용자 경험을 제공합니다.

## ✨ 주요 기능

*   **인증 및 사용자 관리**: 안전한 회원가입 및 로그인 시스템.
*   **그룹 관리**: 그룹 생성, 멤버 초대/탈퇴, 그룹 정보 관리.
*   **프로젝트 관리**: 프로젝트 생성, 태스크 할당, 마감일 설정, 칸반 보드를 통한 시각적 진행 상황 추적.
*   **일정 관리**: 그룹 공유 캘린더를 통한 일정 등록 및 태스크 마감일 조회.
*   **대시보드**: 개인 할 일, 프로젝트 진행 상황, 캘린더 요약을 한눈에 확인.
*   **커뮤니케이션**: 태스크별 댓글 기능 및 그룹 노트 기능.

## 🛠️ 기술 스택

*   **프론트엔드**: Next.js
*   **런타임**: Bun
*   **데이터베이스**: SQLite
*   **ORM**: Prisma
*   **스타일링**: Tailwind CSS
*   **언어**: TypeScript

## 🚀 시작하기

이 프로젝트를 로컬 환경에서 실행하려면 다음 단계를 따르세요.

### 전제 조건

*   Bun이 설치되어 있어야 합니다. ([Bun 설치 가이드](https://bun.sh/docs/installation))

### 설치 및 실행

1.  **리포지토리 클론**:
    ```bash
    git clone [리포지토리_URL_여기에]
    cd p17-w03-4_togethering/togethering-app
    ```
2.  **의존성 설치**:
    ```bash
    bun install
    ```
3.  **데이터베이스 설정**:
    ```bash
    bun prisma migrate dev
    ```
    이 명령은 SQLite 데이터베이스를 설정하고 Prisma 스키마를 적용합니다.
4.  **애플리케이션 실행**:
    ```bash
    bun run dev
    ```
    애플리케이션이 `http://localhost:3000`에서 실행됩니다.
