## 🎨 캘린더 페이지 디자인 명세서: '투게더링'

제공해주신 목업 디자인(`image_7cf545.png`)을 바탕으로 '투게더링' 서비스의 **캘린더 페이지** 디자인 명세서를 작성합니다.

---

### 1. 화면 개요 및 디자인 원칙

| 항목 | 상세 내용 |
| :--- | :--- |
| **화면 명칭** | 캘린더 (Calendar) |
| **목표** | 그룹의 모든 공유 일정과 프로젝트의 마감일(Task Due Date)을 한눈에 파악하고, 직관적으로 일정을 추가 및 확인할 수 있는 공간을 제공합니다. |
| **디자인 원칙** | **Clarity & Functionality:** 복잡한 정보(여러 이벤트)를 명확한 색상과 그리드 시스템으로 분류하여, 기능적인 사용성을 최우선으로 합니다. |
| **대상 사용자** | 그룹 멤버 전체 |

### 2. 레이아웃 및 영역 구분

페이지는 **좌측 내비게이션 (고정)**, **상단 헤더 (전환/제목)**, **중앙 캘린더 뷰**의 3개 영역으로 구분됩니다.

#### 2.1. 좌측 내비게이션 (Side Navigation)

* **배치:** 화면 좌측에 고정 (대시보드 페이지(`image_7ece60.png`)와 레이아웃 일관성 유지).
* **그룹 전환:** 현재 그룹의 이름이 표시되며, 다른 그룹으로 전환 가능한 영역이 포함되어 있습니다 (예: '캡스톤 디자인 프로젝트').
* **메인 메뉴:** 대시보드, 프로젝트, **캘린더**, 설정.
* **활성화 상태:** 현재 보고 있는 '캘린더' 메뉴는 **밝은 하늘색 배경**과 **짙은 텍스트/아이콘**으로 하이라이트 되어 현재 위치를 명확히 보여줍니다.

#### 2.2. 상단 헤더 및 기능 버튼

* **그룹 전환/전체 제목:** 우측 상단에 현재 그룹명('캡스톤 디자인 프로젝트')이 표시됩니다.
* **월간 내비게이션:** 중앙에 현재 날짜("2023년 10월")와 함께 좌우 화살표 버튼(`<`, `>`)이 배치되어 월별 이동을 지원합니다.
* **오늘 버튼 (Today):** 현재 날짜로 즉시 이동하는 버튼입니다.
* **일정 추가 CTA:** 우측 상단에 **'+ 일정 추가'** 버튼이 배치되어, 신규 이벤트 생성 기능을 제공합니다.

### 3. 중앙 캘린더 뷰 디자인 명세

캘린더는 월간 뷰를 기본으로 하며, 7열의 그리드 형태로 구성됩니다.

| 요소 | 상세 디자인 및 역할 | UX/UI 반영 사항 |
| :--- | :--- | :--- |
| **요일 헤더** | SUN, MON, TUE, WED, THU, FRI, SAT. | **일요일(SUN)**은 붉은색 텍스트로 강조하여 주말 시작을 명시합니다. |
| **날짜 그리드** | 각 날짜 셀은 배경색이나 테두리 없이 깔끔하게 분리됩니다. | 날짜 숫자는 각 셀의 좌측 상단에 작게 배치됩니다. |
| **외부 날짜 표시** | 현재 달에 속하지 않는 날짜(예: 24, 25, 26)는 연한 회색으로 표시될 것으로 예상됩니다 (목업에서는 흰색). | 사용자의 집중을 현재 달에 유지하도록 합니다. |
| **특정 날짜 강조**| 5일에는 파란색 배경의 원형 안에 '5'가 표시되어 있으며, 이는 해당 날짜에 중요한 프로젝트 마감일이나 여러 개의 이벤트가 있음을 나타내는 마커일 수 있습니다. |

### 4. 일정/이벤트 카드 디자인 명세

이벤트 카드는 작은 직사각형 형태이며, 텍스트 내용과 함께 색상을 사용하여 이벤트 유형을 구분합니다.

| 이벤트 유형 | 색상 코드 (예상) | 표시 형식 | UX/UI 반영 사항 |
| :--- | :--- | :--- | :--- |
| **일반 회의/공유 일정** | 연한 녹색 배경 (Light Green Box) | **[Meeting]** 주간 스.... | 그룹 멤버들과의 일반적인 약속 및 회의를 나타냅니다. |
| **프로젝트/태스크** | 연한 파란색 배경 (Light Blue Box) | **[Project]** 기획서.... | 프로젝트 마감일 또는 프로젝트와 관련된 공식 일정을 나타냅니다. |
| **기념일/개인 일정** | 연한 핑크색 배경 (Light Pink Box) | **[Anniversary]** .... | 비정기적인 개인적인 기념일이나 중요 일정을 나타냅니다. |
| **표시 텍스트** | 이벤트 유형은 대괄호(`[]`) 안에 명시되어 내용의 성격을 바로 파악할 수 있도록 합니다. | 이벤트 내용이 길 경우 말줄임표(...)를 사용하여 공간 효율성을 확보합니다. |
