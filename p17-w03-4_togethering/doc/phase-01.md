## 🛠️ '스몰팀' 구현 계획서: 1단계 상세 명세 (환경 및 인프라 구축)

**목표:** Docker를 사용하지 않고, 모든 팀원이 **Bun 런타임**을 중심으로 Next.js, Redis, SQLite를 로컬 환경에 직접 설치하고 구동할 수 있도록 환경을 구축합니다. 이 단계에서는 실제 UI나 API 로직 구현은 하지 않습니다.

-----

### 1단계: 환경 및 인프라 구축 (Setup & Infrastructure)

#### 1.1. 로컬 런타임 및 프레임워크 설정

| 항목 | 기술 스택 | 버전 | 상세 내용 |
| :--- | :--- | :--- | :--- |
| **런타임** | Bun | v1.3.4 | 각 개발자의 OS에 Bun을 설치하고, 환경 변수 설정을 완료합니다. |
| **프레임워크** | Next.js | v16.0.8 | `bun create next-app` 명령어를 사용하여 Next.js 프로젝트를 생성합니다. TypeScript, ESLint, Prettier 등 기본 개발 도구를 설정합니다. |
| **타입스크립트** | TypeScript | v5.9.3 | 프로젝트의 타입 안정성을 확보하기 위해 초기 설정을 점검합니다. |
| **패키지 관리** | Bun CLI | v1.3.4 | 모든 의존성 설치 및 스크립트 실행은 Bun을 사용하도록 `package.json` 파일을 설정합니다. |

> 🔑 **주요 산출물:** Next.js 프로젝트 구조, `package.json`, `tsconfig.json` 파일, **Bun 및 Next.js 개발 서버 구동 확인**.

#### 1.2. Redis 서버 로컬 설치 및 구동

| 항목 | 기술 스택 | 버전 | 상세 내용 |
| :--- | :--- | :--- | :--- |
| **캐시 서버** | Redis | v8.2.3 | 각 개발자의 로컬 시스템에 Redis 서버를 설치하고, 서비스 시작 시 백그라운드에서 구동되도록 설정합니다. |
| **환경 설정** | 환경 변수 | N/A | `.env` 파일에 Redis 연결 정보(예: `REDIS_URL=redis://localhost:6379`)를 정의합니다. |

> 🔑 **주요 산출물:** Redis 서버가 로컬에서 정상적으로 구동되는 상태, `.env` 파일에 Redis 연결 정보 명시.

#### 1.3. Prisma ORM 초기 설정 및 SQLite 준비

| 항목 | 기술 스택 | 버전 | 상세 내용 |
| :--- | :--- | :--- | :--- |
| **ORM** | Prisma | v6.19.0 | Bun을 통해 Prisma CLI를 설치하고 초기화합니다. |
| **DB 설정** | SQLite | v3.51.1 | `schema.prisma` 파일 내 `datasource`를 다음과 같이 설정합니다. <br> `prisma<br>datasource db {<br>  provider = "sqlite"<br>  url      = env("DATABASE_URL")<br>}<br>` |
| **DB 경로 설정** | 환경 변수 | N/A | `.env` 파일에 `DATABASE_URL="file:./dev.db"`를 정의하여 로컬 파일 기반 DB 경로를 설정합니다. |

> 🔑 **주요 산출물:** Prisma 설치 완료, `schema.prisma` 파일 내 SQLite 설정 완료, `.env` 파일에 DB 경로 정의.

-----

### 2\. 1단계 구현에 따른 UI/UX 명세

1단계는 인프라 및 환경 설정에 집중하므로, 사용자에게 보이는 UI/UX 요소는 구현되지 않습니다.

| 구현 항목 | 상세 내용 | 비고 |
| :--- | :--- | :--- |
| **화면** | Next.js 기본 시작 페이지 (Welcome Page) | 서버 구동 확인용으로만 사용되며, 디자인 적용은 없습니다. |
| **디자인 시스템** | N/A | 색상, 폰트, 레이아웃 등 디자인 요소는 다음 단계부터 점진적으로 적용합니다. |
| **검증** | 로컬호스트 접속 및 콘솔 로그 | Bun 개발 서버 (`bun run dev`)가 에러 없이 구동되고, Redis 및 Prisma 연결 준비 상태를 콘솔에서 확인합니다. |

-----

다음 실행 단계는 **2단계: 데이터베이스 및 API 설계**입니다. 이 단계에서는 **데이터 모델을 정의**하고 **인증 및 그룹 관리 API**를 구현하여 서비스의 백엔드 기능을 완성하게 됩니다.
