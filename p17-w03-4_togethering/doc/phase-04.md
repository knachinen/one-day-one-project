## 🛠️ '스몰팀' 구현 계획서: 4단계 상세 명세 (일정 관리 및 기타 기능 구현)

**목표:** 그룹 공유 캘린더 기능을 완성하고, 사용자가 현재 그룹의 상태를 한눈에 파악할 수 있는 대시보드를 구축합니다. 사용자 간의 커뮤니케이션을 위한 댓글/노트 기능도 추가하여 핵심 기능을 마무리합니다.

---

### 4단계: 일정 관리 및 기타 기능 구현 (Calendar & Polish)

#### 4.1. 캘린더 및 이벤트 API 구현 (FR-C.1~C.3)

| 항목 | 기술 스택 | 버전 | 상세 내용 (API 엔드포인트) |
| :--- | :--- | :--- | :--- |
| **일정 CRUD** | Next.js API Routes (Bun) | v16.0.8, v1.3.4 | 그룹 공유 일정 등록, 조회, 수정, 삭제 API 구현. `/api/calendar` |
| **태스크 연동** | Prisma | v6.19.0 | 캘린더 조회 시, DB에서 프로젝트 **`Task`의 `dueDate`**를 조회하여 자동으로 캘린더 이벤트로 변환하여 함께 반환하는 로직 구현 (FR-C.2). |
| **알림 로직** | Redis | v8.2.3 | **마감일 알림 기능** 구현을 위한 기초 로직 작성 (FR-C.4). Task의 Due Date가 임박했을 때 알림을 Redis 큐에 적재하는 로직. |

> 🔑 **주요 산출물:** 캘린더 및 이벤트 관련 **API Route 파일들**, Redis를 활용한 알림 큐 적재 로직 (백엔드).
