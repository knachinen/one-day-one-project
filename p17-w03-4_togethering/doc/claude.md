# 소규모 그룹 프로젝트 및 일정 관리 서비스 기획

## 1. 서비스 개요

### 핵심 가치 제안

- **친밀한 관계 중심**: 대규모 협업 툴의 복잡함 없이, 가까운 사람들과의 간편한 협업
- **일상과 프로젝트의 통합**: 개인 일정과 공동 프로젝트를 하나의 공간에서 관리
- **직관적 사용성**: 별도 학습 없이 즉시 사용 가능한 인터페이스

### 차별화 포인트

- 기존 협업 툴(Notion, Asana)은 너무 무겁고 복잡함
- 일반 캘린더는 프로젝트 관리 기능 부족
- 커플/소규모 그룹에 최적화된 감성적 UX

## 2. 주요 기능

### 2.1 그룹 관리

- **그룹 생성 및 초대**: 간단한 링크/코드로 멤버 초대
- **다중 그룹 지원**: 여러 그룹 동시 참여 가능 (예: 커플 그룹, 프로젝트 팀 그룹)
- **멤버 역할**: 관리자/멤버 구분

### 2.2 프로젝트 관리

- **프로젝트 보드**:
    
    - 진행 중/완료된 프로젝트 구분
    - 프로젝트별 색상 테마 설정
    - 진행률 시각화
- **할 일 관리**:
    
    - 체크리스트 형태의 작업 목록
    - 담당자 지정
    - 마감일 설정
    - 우선순위 표시

### 2.3 캘린더 & 일정

- **통합 캘린더 뷰**:
    
    - 월간/주간/일간 뷰
    - 개인 일정 + 그룹 일정 통합 표시
    - 필터링 기능 (그룹별, 프로젝트별)
- **이벤트 관리**:
    
    - 일회성 이벤트
    - 반복 일정 (데이트 날, 정기 모임)
    - 리마인더 알림

### 2.4 소통 기능

- **댓글**: 각 프로젝트/할 일에 댓글 달기
- **반응 이모지**: 간단한 피드백
- **실시간 알림**:
    - 새로운 할 일 배정
    - 마감일 임박
    - 댓글 언급

### 2.5 추억 기록

- **타임라인**: 완료된 프로젝트와 이벤트 기록
- **사진 첨부**: 프로젝트/이벤트별 사진 저장
- **마일스톤**: 중요한 순간 하이라이트

## 3. 사용자 시나리오

### 시나리오 1: 커플

**상황**: 연애 중인 커플이 함께 여행 계획

1. "도쿄 여행" 프로젝트 생성
2. 할 일 추가:
    - 항공권 예약 (담당: A, 마감: 2주 후)
    - 숙소 찾기 (담당: B, 마감: 2주 후)
    - 관광지 리스트업 (담당: 공동)
3. 여행 날짜를 캘린더에 이벤트로 추가
4. 각 단계마다 댓글로 의견 교환
5. 여행 후 사진 업로드하여 추억 기록

### 시나리오 2: 스터디 그룹 (3명)

**상황**: 자격증 준비 스터디 그룹

1. "정보처리기사 스터디" 그룹 생성
2. 주차별 프로젝트 생성
    - "1주차: 소프트웨어 설계"
    - "2주차: 데이터베이스"
3. 주간 스터디 모임을 반복 일정으로 등록
4. 각 주차별 과제를 할 일로 배분
5. 완료된 내용을 체크하며 진행률 확인

## 4. 기술 스택 제안

### Frontend

- **React** + TypeScript
- **Tailwind CSS**: 빠른 UI 개발
- **Zustand/Recoil**: 상태 관리
- **React Calendar 라이브러리**: 캘린더 구현

### Backend

- **Node.js** + Express 또는 **Next.js** (풀스택)
- **PostgreSQL**: 관계형 데이터 저장
- **Prisma**: ORM
- **Socket.io**: 실시간 알림

### 인프라

- **Vercel/Netlify**: 프론트엔드 배포
- **Railway/Supabase**: 백엔드 + DB
- **Cloudinary**: 이미지 저장

## 5. MVP (최소 기능 제품) 우선순위

### Phase 1 (MVP)

1. ✅ 그룹 생성 및 멤버 초대
2. ✅ 프로젝트 생성 및 할 일 관리
3. ✅ 기본 캘린더 뷰
4. ✅ 간단한 알림 시스템

### Phase 2

1. 댓글 및 반응 기능
2. 파일/사진 첨부
3. 고급 캘린더 기능 (반복 일정)
4. 모바일 반응형

### Phase 3

1. 타임라인 및 추억 기록
2. 통계 및 분석 (완료율, 활동 내역)
3. 커스터마이징 (테마, 색상)
4. 모바일 앱 (React Native)

## 6. 수익화 방안

### Freemium 모델

- **무료**:
    
    - 그룹 2개까지
    - 프로젝트 5개까지
    - 저장 공간 100MB
- **프리미엄** (월 ₩5,000):
    
    - 무제한 그룹 및 프로젝트
    - 저장 공간 5GB
    - 고급 테마 및 커스터마이징
    - 우선 고객 지원

## 7. 디자인 방향

### 감성 키워드

- 따뜻함, 친밀함
- 미니멀, 직관적
- 부담 없는 협업

### 컬러 팔레트 예시

- 메인: 부드러운 파스텔 톤 (핑크, 블루, 민트)
- 그룹별 테마 색상 선택 가능
- 다크 모드 지원

### UI 특징

- 큰 터치 영역 (모바일 친화적)
- 애니메이션으로 생동감
- 이모지 적극 활용

## 1. 제품 개요

### 1.1 프로젝트 배경

- 기존 협업 툴(Notion, Asana, Trello)은 대규모 팀 협업에 최적화되어 있어 커플이나 소규모 그룹에게는 과도하게 복잡함
- 일반 캘린더 앱은 프로젝트 관리 기능이 부족하여 체계적인 협업이 어려움
- 친밀한 관계에서의 협업은 업무적 협업과 다른 감성적 접근이 필요함

### 1.2 제품 비전

**"가까운 사람들과 함께하는 모든 순간을 쉽고 즐겁게"**

커플, 가족, 친구 등 소규모 그룹이 프로젝트와 일정을 한 곳에서 편리하게 관리하며, 함께한 추억까지 기록할 수 있는 올인원 협업 공간

### 1.3 목표 사용자

**Primary 타겟**

- 연애 중인 커플 (20~30대)
- 공동 목표가 있는 소규모 스터디/프로젝트 그룹 (2~4명)

**Secondary 타겟**

- 가족 단위 사용자
- 소규모 동아리/취미 모임

### 1.4 핵심 가치 제안

1. **간편함**: 복잡한 설정 없이 5분 내 그룹 생성 및 사용 시작
2. **통합성**: 프로젝트 관리 + 일정 관리를 하나의 공간에서
3. **친밀감**: 소규모 그룹에 최적화된 감성적 UX/UI
4. **기록성**: 함께한 프로젝트와 이벤트를 추억으로 보관
