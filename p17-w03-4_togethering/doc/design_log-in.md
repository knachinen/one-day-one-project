* **제목:** "투게더링" (굵고 큰 산세리프체)
* **슬로건:** "함께하는 모든 일을 쉽게, 투게더링" (제목 아래 작은 글씨)
* **스타일:** 중앙 상단에 배치되어 서비스의 아이덴티티를 명확히 합니다.

#### 2.2. 이메일 기반 인증 영역 (폼)

사용자가 이메일 주소와 비밀번호를 직접 입력하는 표준 로그인 방식입니다.

| 구성 요소 | 역할 및 상세 디자인 | UX/UI 반영 사항 |
| :--- | :--- | :--- |

| **입력 필드 2** | 비밀번호 입력 | 둥근 모서리 입력창. 보안을 위해 입력 내용이 숨겨져야 합니다. |
| **메인 CTA** | "로그인 / 계속하기" | **하늘색 계열**의 배경색으로 채워져 있으며, 둥근 모서리가 적용된 메인 액션 버튼. |

* **Google 로그인 버튼:** Google의 브랜드 가이드라인에 따른 아이콘과 색상 (예상)을 사용합니다.

### 4. 주요 UX 명세

* **중앙 집중:** 모든 입력 필드와 버튼이 화면 중앙에 배치되어 사용자가 쉽게 정보를 입력할 수 있도록 합니다.
* **단일 CTA:** '로그인'과 '회원가입'을 구분하지 않고 "로그인 / 계속하기"로 통일하여, 사용자가 아이디가 있는지 여부에 관계없이 다음 단계로 이동하도록 유도합니다. (내부적으로는 이메일 존재 여부에 따라 로그인/회원가입 로직 분기)
* **간편 로그인 강조:** Kakao 등 국내 사용자에게 익숙한 소셜 로그인을 밝은 색상으로 강조하여 빠른 진입을 지원합니다.
