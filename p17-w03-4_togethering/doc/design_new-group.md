## 🎨 그룹 생성 페이지 디자인 명세서: 'Togethering'

제공해주신 목업 디자인(`image_7ebc58.png`)을 바탕으로 'Togethering' 서비스의 **그룹 생성 페이지** 디자인 명세서를 작성합니다.

-----

### 1\. 화면 개요 및 디자인 원칙

| 항목 | 상세 내용 |
| :--- | :--- |
| **화면 명칭** | 새 그룹 만들기 (New Group Creation) |
| **목표** | 사용자가 서비스를 시작하기 위해 필요한 기본 그룹 정보를 설정하고, 멤버를 쉽게 초대하여 즉시 협업을 시작할 수 있도록 합니다. |
| **디자인 원칙** | **Friendly & Guided:** 친근하고 부드러운 디자인을 적용하며, 필수 입력 요소를 단계적으로 안내하여 사용자의 이탈을 최소화합니다. |
| **사용자 흐름** | 로그인/회원가입 직후 온보딩 과정에서 필수적으로 진입하는 화면입니다. |

### 2\. 레이아웃 및 영역 구분

페이지는 중앙 정렬된 단일 모달/카드 형태로 구성되어 있으며, 이는 배경 화면과 분리되어 사용자의 집중을 유도합니다.

#### 2.1. 제목 및 안내

  * **제목:** "새 그룹 만들기"
  * **안내 문구:** "그룹을 만들고 멤버를 초대하여 프로젝트와 일정을 함께 관리하세요."
  * **스타일:** 제목은 굵고 큰 산세리프체로, 안내 문구는 그 아래에 작고 간결하게 배치되어 기능의 목적을 설명합니다.

#### 2.2. 입력 폼 영역 (Form Area)

폼 영역은 그룹의 기본 정보 설정과 멤버 초대 영역으로 나뉩니다.

| 구성 요소 | 역할 및 상세 디자인 | UX/UI 반영 사항 |
| :--- | :--- | :--- |
| **그룹 이름** | **라벨:** 그룹 이름 <br> **입력 필드:** 둥근 모서리, 흰색 배경. <br> **플레이스홀더:** "예: 제주도 여행 계획" | 사용자가 구체적인 목표를 이름에 담도록 예시를 제공합니다. |
| **그룹 유형** | **라벨:** 그룹 유형 <br> **선택 버튼:** '커플', '스터디', '여행', '기타'를 버튼 형태로 제공. | **토글 버튼 형태**로 디자인되어 시각적으로 즉각적인 선택이 가능합니다. (선택된 버튼은 밝은 민트색으로 하이라이트). |
| **멤버 초대** | **라벨:** 멤버 초대 (최대 3명) | 소규모 그룹(총 4인 이하) 서비스임을 명확히 안내합니다. |
| **멤버 초대 필드** | 이메일 입력 필드 ("친구의 이메일을 입력하세요"). | 엔터 키를 누르면 이메일이 추가되는 형태를 통해 빠른 멤버 추가를 지원합니다. |
| **초대 링크** | **대안:** "또는"을 기준으로 대시 선(Dashed Line) 영역 안에 **"초대 링크 복사하기"** 버튼 배치. | 이메일 외에 링크 공유를 통한 간편한 초대 경로를 제공합니다. |

### 3\. CTA (Call to Action) 버튼

하단에는 주요 액션 버튼이 배치되며, 긍정적인 액션이 강조됩니다.

| 구성 요소 | 역할 및 상세 디자인 | UX/UI 반영 사항 |
| :--- | :--- | :--- |
| **메인 CTA** | "그룹 만들기" | \*\*녹색 계열 (e.g., `#6CC644` 또는 유사)\*\*로 가장 밝게 강조되어, 이 단계의 주 목표임을 나타냅니다. |
| **보조 CTA** | "취소" | 연한 회색 배경의 버튼으로, 메인 액션보다 덜 강조됩니다. |

### 4\. 시각 디자인 및 컬러 팔레트

이 페이지는 친근하고 부드러운 느낌을 주기 위해 라운드 처리와 파스텔 톤을 사용했습니다.

| 요소 | 색상 (Hex Code 예상) | 역할 및 적용 예시 |
| :--- | :--- | :--- |
| **배경** | 연한 미색/흰색 (e.g., `#F4EFE7` 또는 유사) | 배경색은 따뜻한 느낌을 주며, 중앙의 폼 영역 카드와 약간의 대비를 이룹니다. |
| **카드 배경** | 흰색 | 중앙 폼 영역의 배경색. |
| **메인 CTA** | 녹색 계열 (e.g., `#6CC644` 또는 유사) | 그룹 생성 버튼. |
| **선택된 유형 버튼** | 민트/하늘색 (e.g., `#A8DADC` 또는 유사) | '커플', '여행' 등 현재 선택된 유형. |
| **테두리/모서리** | **매우 둥근 모서리 (High Radius)** | 전체적인 친밀하고 부드러운 서비스 이미지를 강화. |

### 5\. 주요 UX 명세

  * **유효성 검사:** 그룹 이름과 최소한 한 명의 멤버(혹은 본인만)가 포함되지 않으면 '그룹 만들기' 버튼이 비활성화되거나 오류 메시지가 표시되어야 합니다.
  * **직관적인 초대:** 이메일 입력과 초대 링크 복사라는 2가지 주요 초대 방식을 명확히 분리하여 제공합니다.
