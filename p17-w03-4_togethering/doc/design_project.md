## 🎨 프로젝트 상세 페이지 디자인 명세서: 'Togethering'

제공해주신 목업 디자인(`image_7ec742.png`)을 바탕으로 'Togethering' 서비스의 **프로젝트 상세 페이지 (칸반 보드)** 디자인 명세서를 작성합니다.

---

### 1. 화면 개요 및 디자인 원칙

| 항목 | 상세 내용 |
| :--- | :--- |
| **화면 명칭** | 프로젝트 상세 (Project Detail / Kanban Board) |
| **목표** | 프로젝트의 모든 태스크를 **상태별**로 명확하게 분류하고, 드래그 앤 드롭을 통해 직관적으로 상태를 변경할 수 있는 협업 환경을 제공합니다. |
| **디자인 원칙** | **Clarity & Interaction:** 각 태스크의 핵심 정보(마감일, 담당자)를 명확히 하고, 사용자의 조작(상태 변경)이 쉽게 느껴지도록 합니다. |
| **대상 사용자** | 해당 프로젝트에 참여하는 모든 그룹 멤버 |

### 2. 레이아웃 및 영역 구분

페이지는 **상단 헤더/프로젝트 정보**, **중앙 칸반 보드 (3개 열)**의 두 영역으로 명확히 구분됩니다.

#### 2.1. 상단 헤더 및 프로젝트 정보

* **글로벌 내비게이션:** 상단에 "Togedering" 로고와 함께 "Projects", "My Tasks", "Calendar", "Settings" 등 글로벌 메뉴가 배치되어 있습니다. (전체 서비스 메뉴 일관성 유지)
* **프로젝트 제목:** 페이지 중앙에 큰 글씨로 현재 프로젝트 이름("캡스톤 디자인 프로젝트")이 명시됩니다.
* **할 일 추가 CTA:** 우측 상단에 **'할 일 추가'** 버튼이 녹색으로 강조되어, 사용자가 언제든지 새 태스크를 쉽게 등록할 수 있도록 유도합니다.

#### 2.2. 중앙 칸반 보드 (핵심 협업 영역)

* **구조:** 태스크 상태를 나타내는 3개의 열(Column)로 구성되어 있습니다.
    * **할 일 (To Do):** 하늘색 배경
    * **진행 중 (In Progress):** 연한 노란색 배경
    * **완료 (Done):** 연한 녹색 배경
* **제목:** 각 열의 제목은 굵은 산세리프체로 명시되어 가독성을 높입니다.

### 3. 태스크 카드 (Task Card) 디자인 명세

태스크 카드는 칸반 보드의 기본 단위로, 최소한의 핵심 정보를 담아 시인성을 높입니다.

| 요소 | 상세 디자인 및 역할 | UX/UI 반영 사항 |
| :--- | :--- | :--- |
| **제목** | 태스크의 핵심 내용 (예: "UI 디자인 시안 작업") | 한 줄로 간결하게 표시하며, 상세 내용은 모달에서 확인. |
| **마감일 (Due Date)** | 태스크 마감일 (`Nov 28`, `Dec 02` 등) | 카드 제목 아래에 작게 표시하여 긴급성 인지 유도. |
| **담당자** | **프로필 아바타** 형태로 카드 우측 하단에 표시. | 태스크의 책임 소재를 시각적으로 즉각 파악 가능. |
| **색상/태그** | 마감일 근접 태스크는 작은 색상 원형 태그를 추가하여 강조 (예: `Dec 02` 옆의 주황색 원). | 시각적으로 우선순위를 높임. |
| **완료 상태** | '완료 (Done)' 열의 카드는 일반 카드보다 흐릿하게 보이거나 그림자가 강조되어 완료 상태를 시각적으로 분리함. | '모든 작업을 완료했어요! 🎉' 메시지를 포함한 카드를 통해 심리적 성취감을 제공. |

### 4. 시각 디자인 및 컬러 팔레트

이 페이지는 3가지 주요 상태(To Do, In Progress, Done)를 배경색으로 구분하여 시각적 명확성을 제공합니다.

| 요소 | 색상 (Hex Code 예상) | 역할 및 적용 예시 |
| :--- | :--- | :--- |
| **To Do Column** | 연한 하늘색 계열 (e.g., `#E6F5FF`) | 아직 시작하지 않은 업무를 나타내며, 시원하고 차분한 느낌. |
| **In Progress Column** | 연한 노란색 계열 (e.g., `#FFFFE0`) | 현재 진행 중임을 나타내며, 주의 집중을 유도하는 밝은 색상. |
| **Done Column** | 연한 녹색 계열 (e.g., `#F0FFF0`) | 완료 및 성공을 나타내며, 안정감과 성취감을 부여. |
| **버튼 (CTA)** | 녹색 계열 (e.g., `#6CC644`) | '할 일 추가' 등 긍정적인 행동을 유도하는 버튼. |
| **배경** | 흰색 | 전체 페이지의 깨끗한 배경. |

### 5. 주요 UX 명세

* **드래그 앤 드롭:** 카드를 클릭하고 끌어서 '할 일', '진행 중', '완료' 열 사이를 자유롭게 이동시킬 수 있도록 구현 (FR-P.4).
* **빠른 편집:** 태스크 카드를 클릭하면 **모달 창**이 열려 상세 설명, 댓글, 첨부 파일 추가, 담당자 변경 등 모든 편집 작업을 할 수 있도록 합니다.
* **반응형 디자인:** 데스크톱에서는 3개 열이 나란히 보이지만, 모바일 환경에서는 열이 수직으로 쌓이거나 수평 스크롤이 가능하도록 설계되어야 합니다 (NFR-U.2).
