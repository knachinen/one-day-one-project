## 🎨 프로젝트 생성 페이지 디자인 명세서: 'Togethering'

제공해주신 목업 디자인(`image_7ec326.png`)을 바탕으로 'Togethering' 서비스의 **프로젝트 생성 페이지** 디자인 명세서를 작성합니다.

-----

### 1\. 화면 개요 및 디자인 원칙

| 항목 | 상세 내용 |
| :--- | :--- |
| **화면 명칭** | 프로젝트 생성 (Project Creation) |
| **목표** | 사용자가 그룹 내에서 새로운 프로젝트를 시작할 때, 가장 필수적인 정보(프로젝트명, 마감일)를 입력받아 빠르게 생성을 완료하도록 유도합니다. |
| **디자인 원칙** | **Focus & Minimal:** 화면 중앙에 핵심 입력 요소만 배치하여 사용자의 집중도를 높이고 불필요한 선택지를 배제합니다. |
| **사용자 흐름** | 그룹 생성 직후 온보딩 과정의 일부로 사용되거나, 기존 그룹에서 'New Project' 버튼 클릭 시 진입됩니다. |

### 2\. 레이아웃 및 영역 구분

페이지는 중앙 정렬된 단일 입력 영역으로 구성되어 있습니다.

#### 2.1. 상단 안내 및 제목

  * **제목:** "첫 프로젝트를 만들어 보세요"
  * **안내 문구:** "그룹의 첫 목표를 설정하고 함께 시작해봐요."
  * **스타일:** 제목은 굵고 큰 산세리프체로 화면 상단에 명확하게 배치되어 사용자의 다음 행동을 유도합니다. 안내 문구는 제목보다 작은 일반 폰트로 목표를 설명합니다.

#### 2.2. 입력 폼 영역 (Form Area)

입력 폼은 수직으로 정렬되어 있으며, 각 필드는 직관적인 라벨과 입력 영역으로 구성됩니다.

| 구성 요소 | 역할 및 상세 디자인 | UX/UI 반영 사항 |
| :--- | :--- | :--- |
| **프로젝트 이름** | **라벨:** 프로젝트 이름 <br> **입력 필드:** 둥근 모서리, 흰색 배경의 깔끔한 입력창. <br> **플레이스홀더:** "예: D-100 결혼 준비" | 사용자가 프로젝트의 목적을 명확히 설정하도록 구체적인 예시를 제공합니다. |
| **마감일** | **라벨:** 마감일 <br> **입력 필드:** 둥근 모서리 입력창. | 날짜 선택을 위한 **캘린더 아이콘**이 입력 필드 우측에 위치하여, 클릭 시 캘린더 피커가 활성화됨을 암시합니다. |

#### 2.3. CTA (Call to Action) 버튼

  * **버튼:** "프로젝트 생성"
  * **디자인:** 버튼은 화면 너비에 맞춰 확장되어 있으며, 메인 액션을 나타내는 \*\*연한 민트/하늘색 계열 (e.g., `#A8DADC` 또는 유사)\*\*의 배경색으로 채워져 있습니다.
  * **UX:** 버튼 위아래에 충분한 여백을 두어 사용자가 명확하게 최종 단계를 인지하고 클릭할 수 있도록 합니다.

### 3\. 시각 디자인 및 컬러 팔레트

이 페이지는 배경과 폼 영역의 색상 대비를 최소화하여 깔끔함과 집중도를 높였습니다.

| 요소 | 색상 (Hex Code 예상) | 역할 및 적용 예시 |
| :--- | :--- | :--- |
| **배경** | 연한 회색/미색 (e.g., `#F8F8F8` 또는 유사) | 전체 화면의 배경색으로, 눈의 피로를 덜고 중앙 폼 영역에 집중하도록 돕습니다. |
| **CTA 버튼** | 민트/하늘색 (e.g., `#A8DADC` 또는 유사) | 메인 액션 버튼 색상 (디자인 명세서의 Primary 색상과 일치 예상). |
| **텍스트** | 짙은 회색/블랙 | 제목 및 라벨 텍스트. |
| **입력 필드** | 흰색 배경, 얇은 회색 테두리 | 폼 요소의 깔끔함과 가독성 유지. |

### 4\. 주요 UX 명세

  * **중앙 집중:** 모든 요소가 화면 중앙에 배치되어 모바일 환경에서도 손쉽게 입력이 가능합니다.
  * **직관성:** 마감일 입력 필드 옆의 캘린더 아이콘을 통해 입력 방식(날짜 피커)을 즉시 인지할 수 있습니다.
  * **유효성 검사:** 프로젝트 이름이 입력되지 않은 상태에서는 '프로젝트 생성' 버튼이 비활성화되거나 (또는 클릭 시 오류 메시지 표시) 유효성 검사를 수행하여 사용자가 필수 정보를 입력하도록 안내합니다.
