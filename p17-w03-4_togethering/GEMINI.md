## 🚀 '투게더링' 구현 계획서 (Next.js + Bun + SQLite)

이 구현 계획서는 앞서 정의된 **기술 스택(Next.js, Bun, SQLite, Prisma)**과 **와이어프레임**을 기반으로, 서비스를 실제 개발하고 배포하는 데 필요한 주요 단계를 명확히 제시합니다. 각 단계는 독립적으로 실행 가능하도록 구성되었으며, 이전 단계의 결과를 바탕으로 다음 단계를 진행합니다.

---

### 1단계: 환경 및 인프라 구축 (Setup & Infrastructure) - ✅ 완료

**목표:** 모든 팀원이 일관된 개발 환경에서 작업을 시작할 수 있도록 Bun 및 Docker 환경을 설정합니다.

|**실행 항목**|**상세 내용**|**예상 결과물**|
|---|---|---|
|**1.1. Bun 기반 프로젝트 생성**|`Bun create next-app` 명령어를 사용하여 Next.js 프로젝트를 생성하고, TypeScript, ESLint, Prettier 등 기본 개발 도구를 설정합니다.|Next.js 프로젝트 구조 및 `.gitignore` 파일|
|**1.2. Docker 환경 구성**|`Dockerfile` 및 `docker-compose.yml` 파일을 작성하여 Next.js 앱, Redis, SQLite를 포함한 Bun 런타임 환경을 컨테이너화합니다.|Bun/Next.js 서버, Redis, SQLite가 Docker로 구동되는 환경|
|**1.3. Prisma ORM 초기 설정**|Prisma를 설치하고, 데이터베이스 프로바이더를 **SQLite**로 설정합니다. 초기 `schema.prisma` 파일을 생성하고, SQLite 파일 경로를 설정합니다.|`schema.prisma` 파일 및 Prisma 초기 설정 완료|

---

### 2단계: 데이터베이스 및 API 설계 (Data & API Layer) - ✅ 완료

**목표:** 서비스의 핵심 데이터를 저장할 스키마를 정의하고, 인증 및 그룹 관리를 위한 백엔드 API를 구현합니다.

|**실행 항목**|**상세 내용**|**예상 결과물**|
|---|---|---|
|**2.1. 데이터베이스 스키마 정의**|사용자(User), 그룹(Group), 프로젝트(Project), 태스크(Task), 일정(Calendar Event) 등 핵심 엔티티를 포함하는 `schema.prisma`를 작성합니다.|완성된 **`schema.prisma`** 파일|
|**2.2. 마이그레이션 실행**|`bun prisma migrate dev` 명령을 사용하여 SQLite 데이터베이스 파일(예: `dev.db`)을 생성하고 스키마를 적용합니다.|SQLite DB 파일 생성 및 DB 테이블 구조 확정|
|**2.3. 인증 API 구현 (FR-U.1)**|Next.js API Routes를 사용하여 회원가입, 로그인, JWT 토큰 발급 및 검증 로직을 구현합니다.|`/api/auth/register`, `/api/auth/login` 엔드포인트 구현 완료|
|**2.4. 그룹 관리 API 구현 (FR-G.1, G.2)**|그룹 생성, 멤버 초대/탈퇴, 그룹 정보 조회/수정을 위한 CRUD(Create, Read, Update, Delete) API를 구현합니다.|`/api/groups`, `/api/groups/[id]/members` 엔드포인트 구현 완료|

---

### 3단계: 핵심 UI 및 프로젝트 기능 구현 (Core Feature Development) - ✅ 완료

**목표:** 와이어프레임에 정의된 주요 화면과 프로젝트 관리의 핵심 기능(칸반 보드)을 구현합니다.

|**실행 항목**|**상세 내용**|**예상 결과물**|
|---|---|---|
|**3.1. 기본 레이아웃 및 내비게이션 구현**|Next.js의 레이아웃 기능을 활용하여 헤더, 좌측 내비게이션, 모바일 하단 탭 바 등 전역 UI 컴포넌트를 구현합니다.|일관된 디자인 시스템이 적용된 쉘(Shell) 구조|
|**3.2. 로그인/회원가입 화면 구현**|2.3단계에서 구현된 API와 연동하여 사용자가 실제로 로그인 및 회원가입을 할 수 있는 화면을 구현합니다. (화면 1.1)|동작하는 로그인 및 회원가입 페이지|
|**3.3. 프로젝트/태스크 API 구현 (FR-P.1~P.4)**|프로젝트 생성 및 태스크 생성, 담당자 지정, 마감일 설정 API를 구현합니다.|`/api/projects`, `/api/tasks` 엔드포인트 구현 완료| ✅ 완료
|**3.4. 칸반 보드 UI 구현**|프로젝트 상세 화면(화면 3)의 3단계(To Do, In Progress, Done) 칸반 보드 UI 및 **드래그 앤 드롭** 기능을 구현합니다.|태스크 카드가 상태 변경에 따라 이동하는 프로젝트 상세 페이지| ✅ 완료

---

### 4단계: 일정 관리 및 기타 기능 구현 (Calendar & Polish) - 🚧 진행 중

**목표:** 공유 캘린더 기능과 사용자 경험(UX) 개선을 위한 보조 기능들을 추가합니다.

|**실행 항목**|**상세 내용**|**예상 결과물**|
|---|---|---|
|**4.1. 캘린더 API 구현 (FR-C.1~C.3)**|그룹 공유 일정 등록, 태스크 마감일 조회, 일정 CRUD API를 구현합니다.|`/api/calendar` 엔드포인트 구현 완료|
|**4.2. 캘린더 뷰 UI 구현**|월간/주간 캘린더 뷰를 구현하고, 4.1단계의 API와 연동하여 그룹 일정을 표시합니다.|데이터가 연동되는 그룹 공유 캘린더 페이지|
|**4.3. 대시보드 구현 (화면 2.3)**|'나의 할 일' 위젯, 프로젝트 진척도(원형 그래프), 캘린더 요약 등을 구현하여 대시보드 구성을 완료합니다.|기능이 동작하는 메인 대시보드 화면| ✅ 완료
|**4.4. 커뮤니케이션 기능 구현**|태스크 상세 모달 내의 댓글 기능(FR-T.1) 및 간단한 그룹 노트 기능(FR-T.2)을 구현합니다.|댓글 및 노트 CRUD 기능 구현 완료|

### 5단계: 배포 및 안정화 (Deployment & Stabilization)

**목표:** 최종 테스트를 거쳐 서비스를 배포할 수 있는 상태로 만들고, 안정화 작업을 진행합니다.

|**실행 항목**|**상세 내용**|**예상 결과물**|
|---|---|---|
|**5.1. 최종 기능 및 UX 테스트**|PRD 및 UI/UX 명세서를 기준으로 모든 기능과 사용자 흐름을 테스트하고 버그를 수정합니다.|주요 버그가 해결된 안정적인 베타 버전|
|**5.2. Docker 기반 배포 설정**|Next.js 빌드 최적화(`bun run build`)를 포함하여 배포 환경에서 Docker 컨테이너가 안정적으로 구동되도록 설정합니다.|클라우드 서비스(예: AWS, Azure)에 배포 가능한 빌드 파일 및 설정|
|**5.3. 성능 최적화**|Bun 런타임 및 Next.js의 캐싱 전략을 활용하여 로딩 속도 및 API 응답 시간을 최적화합니다 (NFR-P.1).|최적화된 성능 보고서|
