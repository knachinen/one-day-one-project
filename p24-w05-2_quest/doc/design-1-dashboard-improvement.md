현재 구현된 대시보드 화면은 MVP(최소 기능 제품)의 핵심 기능을 잘 담고 있으나, 제공된 목업 디자인과 비교했을 때 시각적 완성도와 사용자 경험(UX) 측면에서 몇 가지 중요한 차이점이 존재합니다.

---

## 1. 목업 디자인과 현재 구현 화면의 상세 차이점

현재 구현된 화면(`image_c9a76c.png`)과 목업(`image_af4a2b.jpg`)을 비교한 분석 결과입니다.

| 구분 | 목업 디자인 (Target) | 현재 구현 화면 (Current) | 차이점 상세 |
| --- | --- | --- | --- |
| **상단 헤더** | 사용자 아바타, 닉네임, 알림 아이콘 포함 | '홈' 텍스트 타이틀과 앱 이름/슬로건 위주 | 개인화된 환영 메시지와 사용자 프로필 요소가 누락됨. |
| **타이머 서체** | 굵고 모던한 산세리프 계열 (Extra-Bold) | 일반적인 산세리프 (Bold 추정) | 타이머 숫자의 시각적 임팩트가 약하며 가독성이 다소 낮음. |
| **타이머 단위** | 숫자 옆에 작고 연하게 배치 () | 숫자와 동일한 크기와 색상의 하첨자 형태 | 단위()가 숫자와 대비되지 않아 데이터 가독성이 떨어짐. |
| **진행 바** | 채도가 높은 초록색 및 부드러운 라운드 처리 | 연한 회색 바 (진행 표시 없음) | 현재 학습 진행 상태가 시각적으로 전혀 표현되지 않음. |
| **카드 컴포넌트** | 상단 여백이 넉넉하고 부드러운 그림자 적용 | 여백이 좁고 단순한 선 위주의 카드 | 전반적인 레이아웃의 깊이감(Depth)과 여백의 미가 부족함. |
| **내비게이션** | 플로팅 시작 버튼(▶)이 중앙에 크게 강조됨 | 단순한 4탭 아이콘 구성 (시작 버튼 누락) | 핵심 액션인 '공부 시작' 버튼의 접근성과 강조가 매우 부족함. |

## 2. 디자인 개선 상세 명세서

목업 디자인의 완성도를 재현하기 위한 구체적인 수정 가이드입니다.

### [A] 대시보드 카드 고도화

* **타이머 고도화:**
* 숫자 폰트를 **Pretendard Extra-Bold**로 변경하고 자간을 소폭 좁힙니다.
* 시간 단위()의 색상을 `#999999`로 변경하고 크기를 숫자의 50% 수준으로 축소합니다.


* **상태 지표 추가:**
* 우측 상단 증감률 배지를 단순 텍스트가 아닌, 연한 초록색 배경의 라운드 칩 형태로 구현합니다.
* 프로그레스 바의 배경은 `#E0E0E0`, 활성 바는 `#66CC66` 컬러를 적용하고 높이를 8px로 설정합니다.



### [B] 레이아웃 및 여백 재설계

* **헤더 리디자인:**
* 텍스트 '홈'을 제거하고, 좌측 상단에 사용자 프로필 이미지와 "안녕하세요, 김알렉스님" 문구를 배치합니다.
* 우측 상단에 알림 배지 기능이 포함된 종 아이콘을 추가합니다.


* **섹션 추가:**
* 구현 화면 하단의 'Connected' 카드를 제거하고, 목업과 같이 **[내 스쿼드]**와 **[공지사항]** 섹션을 추가합니다.
* 각 섹션 사이의 수직 여백을 최소 24px 이상 확보하여 시각적 답답함을 해소합니다.



### [C] 하단 탭바 및 메인 액션 버튼

* **시작 버튼(FAB) 구현:**
* 탭바 중앙에 지름 64dp 규모의 정원형 버튼을 배치합니다.
* 배경색은 `#66CC66`, 내부 아이콘은 흰색 재생(▶) 표시를 사용합니다.
* 버튼 뒤에 부드러운 그림자(`Shadow Offset: 0, 4`, `Blur: 10`, `Opacity: 0.2`)를 추가하여 플로팅 효과를 줍니다.


* **아이콘 정렬:**
* 내비게이션 아이콘들을 목업의 라인 아트 스타일로 교체하고, 활성 탭에만 색상을 부여합니다.
