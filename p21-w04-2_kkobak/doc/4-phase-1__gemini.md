## 📝 Phase 1 상세 구현 명세서: 핵심 인터랙션 프로토타입

**목표:** 회원가입 없이 '꼬박'의 핵심 동기 부여 요소인 **습관 생성, 데일리 체크, 즉각적인 애니메이션 피드백, 꼬바기 마스코트의 감성적 연결**을 구현하고 검증합니다.

**기술 스택:** Next.js, Zustand, Tailwind CSS, Framer Motion, LocalStorage/IndexedDB

---

### 🟢 세부 단계 1.1: 습관 생성 및 기본 데이터 영속성

|**세부 단계 목표**|**사용자가 습관을 생성하고, 브라우저를 닫아도 기록이 유지되도록 합니다.**|
|---|---|
|**구현 항목**|**습관 생성 폼 (FR-004)**, **Zustand 스토어 설정**, **LocalStorage 연동**|
|**세부 명세**|1. **습관 생성 모달/페이지:** 습관 이름(최대 30자), 아이콘 선택(15종 이상), 반복 요일(다중 선택)을 입력받는 UI 구현.|
||2. **Zustand 상태 관리:** `Habit` 엔티티 ()의 상태를 관리하는 스토어 설정.|
||3. **데이터 영속성:** Zustand 스토어와 **LocalStorage/IndexedDB**를 연동하여 습관 생성/수정/삭제 시 실시간으로 데이터를 저장하고, 페이지 로드 시 데이터를 불러옵니다 (FR-015).|
||4. **유효성 검증:** 습관 이름 필수 입력 확인 및 텍스트 길이 제한 검증 (UX Writing: "앗, 잠깐! 습관 이름을 입력해 줘야 꼬바기가 기억할 수 있어요!").|
|**검증 방법**|1. 습관을 생성한 후, 브라우저를 새로고침하거나 닫았다 열어도 생성된 습관 목록이 그대로 유지되는지 확인합니다.|
||2. 필수 입력값을 누락했을 때 에러 메시지가 올바르게 출력되는지 확인합니다.|

---

### 🟡 세부 단계 1.2: 메인 대시보드 및 기본 체크 기능

|**세부 단계 목표**|**등록된 습관을 메인 화면에 표시하고, 사용자가 원터치로 습관을 체크할 수 있게 합니다.**|
|---|---|
|**구현 항목**|**메인 대시보드 UI (FR-010)**, **습관 카드 리스트**, **데일리 체크 로직 (FR-007)**|
|**세부 명세**|1. **대시보드 구성:** 상단 헤더, 꼬바기 영역, 오늘의 습관 체크 영역의 기본 레이아웃 구현 (FR-010).|
||2. **습관 카드 렌더링:** LocalStorage에서 불러온 `Habit` 데이터를 바탕으로 습관명, 아이콘, 체크 버튼이 포함된 카드 리스트를 표시 (FR-010). (카드 모서리: 16px 라운드)|
||3. **데일리 체크 로직:** 체크 버튼 클릭 시, 당일 날짜에 대한 `HabitRecord` (is_completed: True)를 생성하고 LocalStorage에 저장합니다.|
||4. **체크 상태 표시:** 완료된 습관은 시각적으로 구분하여 표시 (희미하게 또는 하단 이동) (FR-010).|
||5. **체크 취소:** 당일 한정 체크 취소 기능 구현 (FR-007).|
|**검증 방법**|1. 오늘 반복 요일로 설정된 습관만 대시보드에 표시되는지 확인합니다.|
||2. 체크 버튼 클릭 시 기록이 `HabitRecord`에 올바르게 저장되고 체크 취소 시 기록이 삭제되는지 확인합니다.|

---

### 🟠 세부 단계 1.3: 핵심 애니메이션 및 인터랙션 피드백

|**세부 단계 목표**|**체크 시 약속된 즉각적인 애니메이션 피드백을 제공하여 사용자에게 강력한 성취감을 부여합니다.**|
|---|---|
|**구현 항목**|**체크 애니메이션 (FR-007)**, **꼬바기 애니메이션 (FR-010)**, **성능 최적화 (NFR-002)**|
|**세부 명세**|1. **체크 피드백:** 체크 완료 시, **Framer Motion**을 사용하여 **체크마크 스프링 효과** 애니메이션 구현 (FR-007).|
||2. **사운드 효과:** 체크 완료 시 밝고 경쾌한 사운드 효과 재생 (선택적 재생 기능 포함) (FR-007).|
||3. **꼬바기 박수 애니메이션:** 체크 완료 시 꼬바기 마스코트가 **환호/점프 애니메이션** 또는 **박수 애니메이션**을 재생 (FR-007, FR-010). (강조 효과 모션 타이밍: 500ms, 탄력 이징 사용)|
||4. **성능 검증:** 체크 액션 후 애니메이션이 **100ms 이내**로 즉시 반응하는지 확인 (NFR-002).|
|**검증 방법**|1. 체크 버튼 클릭 시 스프링 애니메이션, 사운드, 꼬바기 박수가 모두 즉각적이고 동기화되어 재생되는지 확인합니다.|
||2. 저사양 환경에서 체크 시 반응 속도가 100ms를 초과하지 않는지 프레임 드롭 테스트를 통해 검증합니다.|

### 🔴 세부 단계 1.4: 꼬바기 감성 연결 및 스트릭 추적 기반

|**세부 단계 목표**|**사용자의 현재 달성률과 연속 기록을 계산하고, 꼬바기의 표정/메시지를 통해 감성적 동기 부여를 제공합니다.**|
|---|---|
|**구현 항목**|**꼬바기 모션 (FR-010)**, **스트릭 추적 로직 (FR-009)**|
|**세부 명세**|1. **달성률 계산:** 오늘 반복 요일로 설정된 습관 대비 현재 완료된 습관의 비율을 계산합니다.|
||2. **꼬바기 표정/메시지 동적 변경:** 계산된 달성률에 따라 꼬바기의 표정 및 격려 메시지를 동적으로 변경합니다 (FR-010).|
|||
|||
||3. **기본 스트릭 로직:** `HabitRecord`를 기반으로 각 습관의 **현재 스트릭 (연속 기록 일수)**을 계산하여 표시합니다 (FR-009). (최장 스트릭 저장은 Phase 2에서 시각화와 함께 완성)|
|**검증 방법**|1. 습관을 하나씩 체크할 때마다 꼬바기의 표정과 메시지가 설정된 달성률 임계치(예: 30%, 70%, 100%)에 따라 정확하게 바뀌는지 확인합니다.|
||2. 습관을 이틀 연속 체크했을 때 스트릭이 '2일'로 정확히 표시되고, 하루를 건너뛰면 스트릭이 초기화되는지 확인합니다.|
