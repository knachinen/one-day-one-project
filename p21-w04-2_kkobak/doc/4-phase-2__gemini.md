## 🌲 Phase 2 상세 구현 명세서: 시각적 성장 및 추적 기능 강화

**목표:** 사용자가 자신의 습관 형성 과정을 **습관 나무**와 **캘린더**를 통해 시각적으로 확인하며 장기적인 동기부여를 얻도록 합니다. 모든 데이터는 Phase 1과 동일하게 **LocalStorage** 기반으로 관리하여 가입 없이 이용 가능합니다.

**기술 스택:** Next.js, Framer Motion (나무 애니메이션), Recharts (통계), Lucide React (아이콘)

---

### 🟢 세부 단계 2.1: 스트릭(Streak) 시스템 및 시각 효과 고도화

| 세부 단계 목표 | 연속 달성 기록을 정교하게 관리하고 스트릭 갱신 시 시각적 보상을 강화합니다. |
| :--- | :--- |
| **구현 항목** | **스트릭 계산 로직 (FR-009)**, **불꽃 애니메이션**, **최장 스트릭 기록 (Streak 엔티티)** |
| **세부 명세** | 1. **연속 기록 엔진:** 사용자의 `HabitRecord`를 분석하여 중단 없는 연속 달성 일수를 실시간 계산합니다. |
| | 2. **불꽃 피드백:** 스트릭이 갱신될 때마다 습관 카드 옆 불꽃 아이콘이 흔들리거나 반짝이는 **Framer Motion** 효과를 적용합니다. |
| | 3. **데이터 저장:** 현재 스트릭과 역대 최장 스트릭(Longest Streak) 정보를 `Streak` 엔티티 구조로 LocalStorage에 업데이트합니다. |
| **검증 방법** | 1. 오늘 체크 시 스트릭 숫자가 1 증가하고 불꽃 애니메이션이 작동하는지 확인합니다. |
| | 2. 어제 기록이 없는 습관을 오늘 체크했을 때 스트릭이 1부터 다시 시작되는지 확인합니다. |

---

### 🟡 세부 단계 2.2: 습관 나무(Habit Tree) 시각화

| 세부 단계 목표 | 추상적인 진척도를 **습관 나무**라는 구체적 메타포로 표현하여 성장을 시각화합니다. |
| :--- | :--- |
| **구현 항목** | **습관 나무 그래픽 (FR-010)**, **잎사귀/꽃 애니메이션** |
| **세부 명세** | 1. **성장 알고리즘:** 당일 전체 습관 달성률에 따라 나무의 풍성함(잎사귀 수)이 결정되는 로직을 구현합니다. |
| | 2. **잎사귀 생성:** 습관 하나를 체크할 때마다 나무에 새로운 잎사귀가 돋아나는 애니메이션을 추가합니다. |
| | 3. **개화 효과:** 7일 연속 모든 습관을 달성했을 경우, 나무에 꽃이 피는 시각적 보상을 제공합니다. |
| **검증 방법** | 1. 메인 대시보드에서 습관을 체크할 때마다 나무의 잎사귀 수가 실시간으로 변화하는지 확인합니다. |
| | 2. 7일 연속 달성 로직을 강제로 트리거했을 때 꽃 개화 애니메이션이 노출되는지 확인합니다. |

---

### 🟠 세부 단계 2.3: 히스토리 캘린더 및 기록 수정

| 세부 단계 목표 | 과거의 기록을 월간 단위로 한눈에 파악하고, 놓친 기록을 소급 수정할 수 있게 합니다. |
| :--- | :--- |
| **구현 항목** | **캘린더 뷰 (FR-011)**, **과거 기록 수정 (FR-008)** |
| **세부 명세** | 1. **월간 캘린더:** 녹색 원(성공), 빨간 X(실패), 회색(미정) 아이콘으로 한 달의 기록을 시각화합니다. |
| | 2. **기록 소급:** 캘린더의 특정 날짜를 클릭하여 **최대 30일 이내**의 과거 체크 여부를 수정할 수 있는 기능을 구현합니다. |
| | 3. **데이터 동기화:** 과거 기록 수정 시 해당 습관의 현재 스트릭과 나무 성장 상태가 재계산되어 반영되어야 합니다. |
| **검증 방법** | 1. 캘린더에서 이전 날짜를 클릭해 체크 상태를 변경했을 때, 대시보드의 스트릭 숫자가 즉시 갱신되는지 확인합니다. |
| | 2. 31일 이전의 기록은 수정이 불가능하도록 제한되는지 확인합니다. |

---

### 🔴 세부 단계 2.4: 주간 달성률 차트 및 습관 편집

| 세부 단계 목표 | 정량적인 수치로 자신의 달성 상태를 파악하고 기존 습관 설정을 변경합니다. |
| :--- | :--- |
| **구현 항목** | **주간 도넛 차트 (FR-010)**, **습관 수정/삭제 (FR-005, 006)** |
| **세부 명세** | 1. **통계 위젯:** **Recharts**를 활용하여 이번 주 전체 달성률을 보여주는 도넛 차트를 대시보드 하단에 배치합니다. |
| | 2. **습관 관리:** 기존 습관의 이름, 아이콘, 알림 시간 등을 수정하는 기능을 구현합니다. |
| | 3. **안전한 삭제:** 삭제 버튼 클릭 시 확인 팝업을 띄우고, 기록은 보관하되 목록에서만 비활성화 처리합니다. |
| **검증 방법** | 1. 습관을 체크하거나 취소할 때 도넛 차트의 퍼센티지가 실시간으로 연동되는지 확인합니다. |
| | 2. 습관 삭제 시 확인 팝업이 노출되며, 삭제 후 대시보드 리스트에서 사라지는지 확인합니다. |
