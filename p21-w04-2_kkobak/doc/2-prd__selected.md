# 꼬박(Kkobak) 제품 요구사항 명세서 (PRD)

**버전:** 1.0  
**작성일:** 2025-12-17  
**문서 소유자:** Product Team

---

## 1. 제품 개요

### 1.1 제품명 및 비전

- **제품명:** 꼬박 (Kkobak)
- **비전:** 친근한 인터랙션과 재미 요소를 통해 사용자의 습관 형성 동기를 지속적으로 부여하고, 긍정적인 행동 변화를 유도하는 웹 플랫폼

### 1.2 목표 사용자

- **주 타겟:** 20-40대 성인으로 자기계발과 습관 형성에 관심이 있는 사용자
- **부 타겟:** 목표 달성과 루틴 관리가 필요한 모든 연령대

### 1.3 핵심 가치 제안

- 인터랙티브 애니메이션을 통한 즉각적인 성취감 제공
- 꼬바기 마스코트를 통한 감성적 연결과 지속적 동기부여
- 습관 나무 메타포를 활용한 성장의 시각화
- 친근하고 격려하는 톤앤매너로 심리적 부담 감소

---

## 2. 제품 철학 및 디자인 원칙

### 2.1 톤앤매너

- **친근함:** 명령조 대신 격려하고 공감하는 언어 사용
- **긍정적:** 실패에도 위로하고 재도전을 유도
- **활기참:** 경쾌한 애니메이션과 밝은 색상
- **미니멀:** 복잡하지 않은 직관적 인터페이스

### 2.2 디자인 원칙

1. **즉각적 피드백:** 모든 사용자 액션에 시각적/청각적 반응 제공
2. **성장의 시각화:** 추상적 진척도를 구체적 메타포로 표현
3. **감성적 연결:** 마스코트를 통한 정서적 유대감 형성
4. **접근성 우선:** 모바일 최적화 및 한 손 조작 지원

## 3. 기능 요구사항

### 3.1 필수 기능 (MVP)

#### 3.1.1 회원 관리

**FR-001: 회원가입**

- 이메일 기반 회원가입
- 소셜 로그인 (구글, 카카오) 지원
- 닉네임 설정 (2-10자)
- 이용약관 및 개인정보 처리방침 동의

**FR-002: 로그인/로그아웃**

- 이메일/비밀번호 로그인
- 소셜 계정 로그인
- 자동 로그인 (옵션)
- 비밀번호 찾기

**FR-003: 프로필 관리**

- 닉네임 수정
- 프로필 이미지 변경
- 비밀번호 변경
- 회원 탈퇴

#### 3.1.2 습관 생성 및 관리

**FR-004: 습관 생성**

- 습관 이름 입력 (필수, 최대 30자)
- 습관 아이콘 선택 (15종 이상 제공)
- 반복 요일 설정 (일~토 중 다중 선택)
- 알림 시간 설정 (시/분 선택)
- 목표 기간 설정 (선택: 30일/66일/무제한)
- 빈도 설정 (하루 1회/복수회, 시간 목표 등)

**FR-005: 습관 수정**

- 기존 습관의 모든 속성 수정 가능
- 수정 이력은 통계에 영향 없음

**FR-006: 습관 삭제**

- 습관 삭제 시 확인 팝업 표시
- 삭제된 습관의 기록은 히스토리에 보관 (비활성화)

#### 3.1.3 습관 추적 및 체크

**FR-007: 데일리 체크**

- 대시보드에서 원터치 체크 (버튼/체크박스)
- 체크 완료 시 애니메이션 피드백
    - 체크마크 스프링 효과
    - 밝은 사운드 효과 (선택적 재생)
    - 꼬바기 박수 애니메이션
- 체크 취소 기능 (당일 한정)

**FR-008: 과거 기록 수정**

- 히스토리 화면에서 과거 날짜 기록 수정 가능
- 최대 30일 이내 기록 소급 가능
- 수정 사유 입력 (선택)

**FR-009: 스트릭(연속 기록) 관리**

- 각 습관별 현재 연속 기록 일수 표시
- 스트릭 갱신 시 불꽃 아이콘 반짝임 효과
- 최장 스트릭 기록 저장

#### 3.1.4 대시보드

**FR-010: 메인 대시보드 구성**

**상단 헤더:**

- 로고 및 플랫폼명 '꼬박'
- 프로필 아이콘 (클릭 시 설정 메뉴)
- 알림 아이콘 (뱃지 표시)

**꼬바기 영역:**

- 꼬바기 마스코트 표시
- 오늘의 달성률에 따른 표정/모션 변화
    - 0-30%: 걱정/응원 표정
    - 31-70%: 부드러운 미소
    - 71-99%: 기쁜 표정
    - 100%: 환호/점프 애니메이션
- 격려 메시지 텍스트 (달성률 기반 동적 변경)

**오늘의 습관 체크 영역:**

- 등록된 습관 리스트 (카드 형태)
- 각 습관별 정보 표시
    - 습관명
    - 아이콘
    - 현재 스트릭 (불꽃 아이콘 + 숫자)
    - 체크 버튼
- 완료된 습관은 시각적으로 구분 (희미하게 또는 하단 이동)

**전체 진행률 시각화:**

- 습관 나무 그래픽
    - 체크 시마다 잎사귀 생성 애니메이션
    - 7일 연속 달성 시 꽃 개화 효과
- 주간 달성률 도넛 차트 또는 퍼센트 표시
- 총 누적 체크 수

**빠른 메뉴:**

- '+ 습관 추가' 버튼 (FAB 스타일)
- '히스토리' 버튼
- '커뮤니티' 버튼 (차후 개발)

#### 3.1.5 히스토리 및 통계

**FR-011: 캘린더 뷰**

- 월간 캘린더 형태로 과거 기록 표시
- 성공(녹색 원), 실패(빨간 X), 미정(회색) 아이콘 표시
- 날짜 클릭 시 해당일의 습관 상세 보기
- 월 단위 좌우 스와이프/버튼으로 탐색

**FR-012: 습관별 상세 통계**

- 습관 선택 시 개별 통계 표시
    - 총 성공 횟수
    - 평균 달성률
    - 최장 스트릭 기록
    - 최근 7일/30일 트렌드 라인 차트
- 월말 또는 주간 회고 메시지 (꼬바기의 목소리)

#### 3.1.6 알림

**FR-013: 습관 알림**

- 설정된 시간에 푸시 알림 발송
- 알림 내용
    - 습관명
    - 꼬바기의 격려 메시지 (사용자 커스터마이징 가능)
- 알림 스누즈 기능 (10분/30분/1시간)
- 알림 켜기/끄기 토글

**FR-014: 성취 알림**

- 스트릭 갱신 시 축하 알림
- 목표 기간 달성 시 축하 알림
- 레벨업 시 알림

#### 3.1.7 데이터 관리

**FR-015: 데이터 백업 및 동기화**

- 모든 사용자 데이터 클라우드 저장
- 실시간 동기화 (변경 사항 즉시 반영)
- 여러 기기에서 동일 계정 접근 가능

**FR-016: 데이터 내보내기**

- CSV 형태로 습관 기록 다운로드
- 이메일로 전송 또는 파일 저장

## 6. 데이터 모델

### 6.1 주요 엔티티

#### User (사용자)

```
- id: UUID (PK)
- email: String (Unique)
- nickname: String
- profile_image_url: String (Nullable)
- created_at: Timestamp
- updated_at: Timestamp
```

#### Habit (습관)

```
- id: UUID (PK)
- user_id: UUID (FK)
- name: String
- icon: String
- repeat_days: Array<Int> (0=일요일, 6=토요일)
- notification_time: Time (Nullable)
- notification_message: String (Nullable)
- target_period: Int (Nullable, 일 단위)
- frequency: Int (Default: 1)
- is_active: Boolean
- created_at: Timestamp
- updated_at: Timestamp
```

#### HabitRecord (습관 기록)

```
- id: UUID (PK)
- habit_id: UUID (FK)
- check_date: Date
- is_completed: Boolean
- completed_at: Timestamp (Nullable)
- created_at: Timestamp
- updated_at: Timestamp
```

#### Streak (스트릭)

```
- id: UUID (PK)
- habit_id: UUID (FK)
- current_streak: Int
- longest_streak: Int
- last_check_date: Date
- updated_at: Timestamp
```

## 9. 성공 지표 (KPI)

### 9.1 사용자 참여

- **일일 활성 사용자(DAU):** 목표 1,000명 (3개월 내)
- **주간 활성 사용자(WAU):** 목표 3,000명
- **평균 세션 시간:** 3분 이상
- **재방문율:** 60% 이상

### 9.2 습관 형성

- **평균 습관 개수:** 사용자당 3-5개
- **체크 완료율:** 주간 평균 70% 이상
- **30일 지속률:** 40% 이상
- **평균 스트릭:** 7일 이상

### 9.3 사용자 만족

- **NPS (순추천지수):** 50 이상
- **앱스토어 평점:** 4.5/5.0 이상
- **고객 지원 응답 시간:** 24시간 이내

- **완화:** 온보딩 강화, 알림 최적화, 꼬바기의 지속적 격려

### 10.2 기술적 리스크

- **리스크:** 애니메이션 과다로 인한 성능 저하
- **리스크:** 완화: 애니메이션 최적화, 저사양 기기 대응 모드

### 10.3 경쟁 리스크

- **리스크:** 유사 서비스와의 차별화 부족
- **완화:** 꼬바기 캐릭터의 독창성 강화, 인터랙티브 경험 차별화

### 11.1 UX Writing 가이드

#### 격려 메시지 예시

- **0% 달성:** "오늘도 새로운 시작! 꼬바기가 응원할게요."
- **50% 달성:** "절반이나 해냈어요! 조금만 더 힘내요!"
- **100% 달성:** "오늘 할 일을 몽땅 해냈어요! 정말 대단해요!"
- **실패 시:** "잠깐 쉬어도 괜찮아요. 내일 다시 시작해요!"
