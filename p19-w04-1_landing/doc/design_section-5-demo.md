## 🛠️ Section 5: Live Demo (라이브 데모) 상세 명세서

### 1. 섹션 개요 (Overview)

- **목적:** 방문자가 바이브코딩 인터페이스를 미니 체험하며, 코딩 없이 앱을 만드는 과정의 **쉬움**과 **즉각적인 반영**을 체감하게 합니다.
    
- **핵심 메시지:** "클릭만으로 앱이 완성되는 마법".
    
- **타겟 감성:** 기대감, 호기심, '내가 통제하고 있다'는 성취감.
    

---

### 2. 레이아웃 및 구조 (Layout & Structure)

- **구조:** 2-Column Grid (좌측 컨트롤 패널 4 : 우측 실시간 프리뷰 6 비율).
    
- **배경:** Pure White (`#FFFFFF`) 또는 Light Grey (`#F7F9FC`). (목업 이미지는 White 배경)
    
- **여백:** 상하 `PY: 120px` (Desktop 기준).

### 3. 디자인 및 스타일 상세 (Design Specs)

#### 3.1 섹션 헤드라인

- **메인 헤드라인 (H2):**
    
    - **텍스트:** "이렇게 만들어집니다" (목업 이미지와 일치)
        
    - **폰트:** Pretendard Bold (700), `36px` (Desktop)
        
    - **색상:** Dark Grey (`#2D3748`)
        
    - **서브 라벨:** 상단에 "LIVE SANDBOX" 라벨 (목업 이미지 참조)

    - **텍스트:** "코딩 없이 클릭만으로 앱을 완성해보세요. 드래그 앤 드롭조차 필요 없습니다. 원하는 기능을 선택하기만 하면 실시간으로 앱이 완성됩니다." (목업 이미지 기반)

    - **색상:** Medium Grey (`#4A5568`)

    2. **텍스트 변경**
        
    3. **테마 설정** (목업 이미지 참조)

    - **스타일:** 각 옵션은 사각형의 작은 카드 형태 (`120x64px` 권장)로 배치 (목업 이미지 참조).

### 4. 인터랙션 및 모션 (Interaction & Motion)

#### 4.1 실시간 동기화 (Real-Time Sync)

- **타이핑:** 좌측 **제목 편집기**에 입력되는 텍스트는 우측 프리뷰 화면의 상단 타이틀 바에 **100ms 이내**로 지연 없이 즉시 반영됩니다.
    
- **색상:** 컬러 칩 클릭 시, 프리뷰 화면의 주요 UI 요소(버튼 배경, 탭 바 아이콘, 강조 색상)가 `0.3s ease` 애니메이션으로 부드럽게 전환됩니다.
    

#### 4.2 버튼 생성/삭제

- **생성:** 좌측에서 버튼 추가 옵션을 클릭하면, 우측 프리뷰에 버튼이 **Scale Up** 효과와 함께 빠르게 나타납니다.
    
- **삭제:** 프리뷰에 추가된 버튼 옆의 [X] 클릭 시, 해당 버튼이 **Fade Out** 효과로 사라집니다.
    

#### 4.3 섹션 진입 애니메이션

- **좌/우 분리:**
    
    - 좌측 컨트롤 패널: 왼쪽에서 **Slide-in Right**
        
    - 우측 실시간 프리뷰 목업: 오른쪽에서 **Slide-in Left**
        

#### 4.4 마이크로 인터랙션

- **컨트롤 옵션 호버:** 좌측의 작은 옵션 카드(헤더 추가, 버튼 생성 등)에 호버 시 그림자가 강화되고 살짝 부양(Elevation)됩니다.
    
- **프리뷰 버튼 클릭:** 프리뷰 화면의 버튼을 클릭하면, 실제 앱처럼 가벼운 탭 애니메이션(Ripple Effect)이 발생합니다.

### 5. 퍼블리싱 가이드 (Development Guide)

- **상태 관리 (필수):**
    
    - React의 `useState` 또는 전역 상태 관리 라이브러리(Zustand, Redux)를 사용하여 좌측 컨트롤러의 사용자 입력 상태와 우측 프리뷰의 렌더링 상태를 **실시간으로 양방향 동기화**해야 합니다.
        
- **프리뷰 구성:**
    
    - 우측 프리뷰는 iframe 대신 CSS/HTML로 직접 구성하여 프론트엔드 상태와 완벽하게 연결하고, 애니메이션 성능을 확보합니다.
        
- **반응형 요구사항:**
    
    - **Desktop:** 좌/우 4:6 그리드 유지.
        
    - **Mobile:** 상단 섹션 제목 → **중앙 프리뷰** (화면 너비 90%) → **하단 컨트롤 패널** 순서로 세로 스택. 컨트롤 패널은 아코디언 또는 탭 형태로 축소하여 배치합니다.
