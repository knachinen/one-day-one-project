## 1. 와이어프레임 개요
본 와이어프레임은 이전 기획안을 기반으로 한 저충실도(low-fidelity) 설계입니다. 색상, 세부 이미지, 폰트는 생략하고 구조와 레이아웃, 주요 요소 배치에 초점을 맞췄습니다.  
- **목적**: 방문자가 친근하게 느껴지도록 간단하고 직관적인 흐름 설계, 인터랙티브 요소 위치 표시.
- **주요 흐름**: 히어로 섹션 → 인터랙티브 데모 → 차별점 → 후기 → CTA (커뮤니티 가입).
- **반응형 고려**: 데스크톱 기준으로 설계, 모바일에서는 스택 형태로 변환 (햄버거 메뉴 등).
- **인터랙티브 표시**: [인터랙티브]로 표기 (e.g., 퀴즈, 드래그 블록).

아래는 텍스트 기반 ASCII 아트와 섹션별 설명으로 표현한 와이어프레임입니다. 실제 구현 시 Figma나 Miro 등의 도구로 고충실도 변환 추천.

## 3. 섹션별 상세 설명
- **헤더**: 페이지 상단 고정. 로고 좌측, 메뉴 중앙, CTA 우측. 모바일에서 접힘.
- **히어로 섹션**: 풀스크린 높이. 큰 텍스트와 CTA로 즉시 관심 유발. 배경에 친근한 일러스트나 워크숍 사진 플레이스홀더.
- **인터랙티브 데모**: 핵심 차별화 요소. 퀴즈나 드래그 블록으로 "코딩 없이 MVP 빌드" 체험. 결과 공유 버튼 추가.
- **차별점**: 3열 그리드 (모바일 1열). 각 카드에 아이콘 + 제목 + 간단 설명. 클릭 시 모달 팝업.
- **테스티모니얼**: 캐러셀 슬라이더. 친근한 톤의 실제 후기 텍스트 플레이스홀더.
- **CTA 섹션**: 페이지 중간/하단 반복 배치. 간단 폼으로 가입 장벽 최소화.
- **푸터**: 간단 정보 + 링크.
