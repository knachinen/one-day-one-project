# 제품 인터랙티브 랜딩페이지 기획안

## 1. 프로젝트 개요
### 배경 및 목적
본 기획안은 '바이브코딩 교육 워크숍'의 인터랙티브 랜딩페이지를 대상으로 합니다. 이 워크숍은 코딩 지식이 전혀 없는 일반인을 위한 교육 프로그램으로, 코딩 없이 MVP(최소 실행 가능 제품)를 완성할 수 있는 핵심 가치를 제공합니다. 경쟁사 대비 3시간 오프라인 교육, 디버깅 후속 지원, 그리고 1인 창업자 맞춤 커리큘럼으로 차별화됩니다.  랜딩페이지는 친근한 톤으로 방문자를 끌어들이며, 인터랙티브 요소를 통해 워크숍의 가치를 즉시 체험하게 합니다. 주요 목적은 커뮤니티 가입 유도, 브랜드 친근함 강조, 그리고 잠재 고객의 참여율 제고입니다.

### 타겟 오디언스
- **주요 대상**: 코딩 지식 없는 일반인 (연령 25~50세, 직장인, 예비 창업자 등). 1인 창업자 포함, 디지털 도구에 관심 있지만 코딩에 부담 느끼는 층.
- **페르소나 예시**:
  - A: 30세 직장인, 아이디어는 있지만 코딩 때문에 MVP 제작 포기.
  - B: 40세 예비 창업자, 오프라인 교육으로 실전 스킬 습득 희망.
- **특징**: 모바일 접근 비중 높음, 친근한 언어와 간단한 인터랙션으로 신뢰 유도 필요.

## 2. 전략 및 목표
### 전략 방향
- **인터랙티브 중심**: 방문자가 퀴즈나 시뮬레이션을 통해 '코딩 없이 MVP 만들기'를 미리 체험. 예: 드래그 앤 드롭으로 간단한 앱 프로토타입 빌드 시연. 
- **친근함 강조**: 캐주얼한 일러스트, 대화체 카피라이팅, 유머러스한 애니메이션으로 접근성 높임.
- **전환 최적화**: 커뮤니티 가입 CTA(Call to Action)를 다중 배치, 무료 미니 워크숍 테이저 제공.
- **영감 소스**: 온라인 코스 랜딩페이지 예시처럼 (e.g., Unbounce 사례) 참여형 요소 도입. 

### 목표 (SMART 기준)
- **Specific**: 인터랙티브 요소로 워크숍 기능 3개 이상 데모, 커뮤니티 가입 폼 제출 유도.
- **Measurable**: 월 방문자 800명, 가입 전환율 20% 달성.
- **Achievable**: 노코드 도구 활용으로 저비용 구현.
- **Relevant**: 타겟의 코딩 장벽 해소와 커뮤니티 빌딩.
- **Time-bound**: 1.5개월 내 개발 완료, 3개월 내 성과 측정.

## 3. 기능 요구사항
### 핵심 기능
- **헤더/히어로 섹션**: 애니메이션 인트로 (e.g., "코딩 없이 MVP? 여기서 시작해요!" 텍스트 페이드인), 배경 비디오 루프 (워크숍 하이라이트).
- **인터랙티브 데모 섹션**: 퀴즈 형식 ("당신의 아이디어는?") – 답변에 따라 맞춤 MVP 시뮬레이션 제공. 드래그 가능한 블록으로 앱 빌드 체험. 
- **차별점 소개**: 스크롤 기반 카드 플립 – 3시간 오프라인, 디버깅 지원, 1인 창업자 맞춤 클릭 시 상세 설명 팝업.
- **테스티모니얼**: 슬라이더, 호버 시 참가자 스토리 확장 (친근한 사진과 후기).
- **CTA 섹션**: 커뮤니티 가입 폼 (이메일 입력만), 실시간 채팅 위젯으로 문의 유도.
- **푸터**: FAQ 아코디언, SNS 링크, 뉴스레터 구독.

### 인터랙티브 요소 상세
- 애니메이션: 패럴랙스 스크롤, 마우스 호버 효과.
- 사용자 참여: MVP 빌더 미니 게임, 결과 공유 버튼 (SNS 연동).
- 접근성: 키보드 지원, 화면 판독기 호환.

## 4. 디자인 컨셉
### 비주얼 스타일
- **컬러 팔레트**: 밝고 친근한 톤 (메인 옐로우 #FFD700, 서브 블루 #00BFFF) – 에너지와 접근성 강조.
- **타이포그래피**: 둥근 sans-serif (e.g., Nunito 폰트), 대화체 헤드라인.
- **레이아웃**: 미니멀 풀스크린, 일러스트 중심 – 모바일 반응형.
- **영감 예시**: FreshLearn의 코스 랜딩페이지처럼 간단한 구조와 참여 요소 적용. 

### 사용자 경험 (UX)
- **여정 맵**: 방문 → 히어로 흥미 유발 → 데모 참여 → 차별점 이해 → 가입 CTA.
- **원칙**: 친근성 (캐주얼 언어), 직관성 (단계별 가이드), 매력성 (인터랙션).

## 5. 기술 스택
- **프론트엔드**: React.js 또는 Next.js (인터랙티브 구현 용이).
- **인터랙션 라이브러리**: Framer Motion, GSAP (애니메이션).
- **노코드 옵션**: Webflow 또는 Carrd (코딩 없이 빌드 가능). 
- **호스팅**: Vercel 또는 Netlify (무료 티어).
- **분석**: Google Analytics, Hotjar (사용자 행동 추적).

## 6. 콘텐츠 전략
- **콘텐츠 유형**: 히어로 슬로건 ("코딩 모르셔도 괜찮아요! 함께 MVP 만들어요~"), 데모 설명, 참가자 스토리.
- **업데이트 계획**: 월 1회 후기 추가, A/B 테스트로 CTA 최적화.
- **SEO**: 키워드 ("코딩 초보 워크숍", "MVP 만들기 교육"), 메타 태그 설정.

## 7. 마케팅 및 유지보수 계획
### 마케팅
- **채널**: SNS (Instagram, LinkedIn), Google Ads 타겟팅 (코딩 초보 키워드).
- **프로모션**: 랜딩페이지 방문 시 무료 미니 퀴즈 결과로 커뮤니티 초대.
- **측정**: 가입율, 체류 시간 분석.

### 유지보수
- **일정**: 분기별 콘텐츠 리프레시.
- **백업**: 자동 백업 시스템.
- **확장성**: 워크숍 신청 모듈 추가 가능.
