# GitHub README 파서 및 추출기

## 소개
이 프로젝트는 GitHub 저장소의 `README.md` 파일 콘텐츠를 가져오고 파싱하여 구조화된 정보를 추출하는 도구입니다. 이를 통해 개발 패턴, 모듈 또는 라이브러리에 대한 중요한 정보를 자동으로 분석하고 활용할 수 있습니다.

## 기능
*   **GitHub README 콘텐츠 가져오기**: 특정 경로의 `README.md` 파일을 GitHub에서 직접 비동기적으로 가져옵니다.
*   **README 콘텐츠 파싱**: `README.md` 마크다운 텍스트에서 다음 정보를 추출합니다:
    *   짧은 설명 (Short Description)
    *   속성 (Properties) 및 속성 마크다운 (Props Markdown)
    *   기본 설정 (Default Settings)
    *   코드 예시 (Code Examples)
    *   사용 사례 (Use Cases)
    *   서비스 (예: AWS 서비스)
    *   모듈 출력 (Module Outputs)
*   **캐싱 메커니즘**: 이전에 가져온 README 콘텐츠를 캐싱하여 불필요한 GitHub API 호출을 줄이고 성능을 향상시킵니다.
*   **오류 처리**: GitHub에서 README를 가져오는 중 발생하는 네트워크 오류나 HTTP 상태 코드 오류를 처리합니다.
