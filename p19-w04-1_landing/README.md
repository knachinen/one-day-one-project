# VibeCoding 워크숍 인터랙티브 랜딩 페이지 (기획 및 설계)

이 저장소는 "VibeCoding 워크숍"을 위한 인터랙티브 랜딩 페이지의 포괄적인 기획 및 설계 문서를 담고 있습니다. 이 랜딩 페이지의 주요 목표는 코딩 경험이 없는 사람들도 광범위한 코딩 없이 MVP(최소 기능 제품)를 달성할 수 있음을 보여주고, 궁극적으로 커뮤니티 가입을 유도하는 것입니다.

## 프로젝트 개요

이 디렉토리(`p19-w04-1_landing`)는 VibeCoding 워크숍 랜딩 페이지와 관련된 모든 문서, 디자인 사양 및 전략적 기획 문서를 포함합니다. 초기 개발 단계 이전에 기획 및 설계에 중점을 둔 비코드 프로젝트입니다. `landing-page/` 하위 디렉토리에는 이미 초기화된 Next.js 프로젝트가 포함되어 있어, 기획 단계를 넘어 개발 단계로 진입했음을 알 수 있습니다.

## 디렉토리 구조

*   `doc/`: 랜딩 페이지의 디자인 요구 사항, 구현 계획, 기술 스택 및 아이디어 문서를 포함한 모든 기획 및 설계 문서가 여기에 있습니다.
*   `landing-page/`: Next.js 기반의 프론트엔드 프로젝트 코드를 포함합니다. TypeScript, Tailwind CSS, shadcn/ui 등을 사용하여 초기화되었습니다.

## 주요 기획 문서

*   **`doc/design_requirements.md`**: 랜딩 페이지의 시각적 디자인에 대한 상세 사양 (개념, 시각적 아이덴티티, UI 구성 요소, 인터랙션, 접근성 등).
*   **`doc/plan_implementation.md`**: 랜딩 페이지 구축을 위한 단계별 구현 계획 (핵심 구조, 인터랙티브 기능, 최적화, 검증 체크포인트).
*   **`doc/plan_tech-stack.md`**: 랜딩 페이지를 위한 계획된 기술 스택 (핵심 기술, UX/UI 및 인터랙션 도구, 디자인 및 사용자 정의 전략).
*   **`doc/plan_idea.md`**: VibeCoding 워크숍 랜딩 페이지의 핵심 개념, 대상 고객, 가치 제안 및 주요 전환 목표.

## 계획된 기술 스택

기획 문서에 따라 VibeCoding 워크숍 인터랙티브 랜딩 페이지는 다음 기술을 사용하여 구축될 예정입니다:

*   **프론트엔드 프레임워크:** React with TypeScript
*   **메타 프레임워크:** Next.js (SSR/SSG, 성능 및 SEO 최적화)
*   **스타일링:** Tailwind CSS (유틸리티 우선 CSS 프레임워크)
*   **UI 컴포넌트:** shadcn/ui (Tailwind CSS 및 Radix UI 기반의 사용자 정의 가능한 컴포넌트)
*   **접근성:** Radix UI (shadcn/ui가 기반으로 하는 스타일 없는 접근성 높은 컴포넌트 제공)
*   **애니메이션/인터랙션:** Framer Motion (복잡하고 부드러운 애니메이션)
*   **폼 관리:** React Hook Form (효율적인 폼 상태 관리 및 유효성 검사)
*   **분석:** Google Analytics 4 (GA4) 및 Google Tag Manager (GTM)

## 빌드 및 실행 (개발 중)

현재 이 저장소는 기획 및 설계에 중점을 두고 있지만, `landing-page/` 디렉토리에 Next.js 프로젝트가 초기화되어 있습니다. 개발이 진행됨에 따라 다음 지침이 추가될 예정입니다:

*   **프로젝트 초기화:** Next.js with TypeScript, Tailwind CSS, shadcn/ui를 사용하여 이미 초기화되었습니다.
*   **로컬 개발:** Next.js 개발 서버 실행을 위한 명령어가 곧 확립될 것입니다.
*   **배포:** 최적화된 배포를 위해 Next.js 기능을 활용할 것입니다.

## 사용법

이 문서는 다음을 위해 작성되었습니다:

*   **프로젝트 관리자:** 랜딩 페이지 프로젝트의 범위, 단계 및 전반적인 진행 상황을 이해하기 위함.
