# ritual_code: 1일 1코딩 챌린지 기록 저장소

## 🚀 프로젝트 개요

이 저장소는 "1일 1코딩" 챌린지를 수행하며 생성되는 모든 코드, 계획, 회고록 등을 기록하고 관리하기 위한 공간입니다. 꾸준한 코딩 습관을 형성하고, 간단한 아이디어들을 실제 코드로 구현하며 성장하는 과정을 담아냅니다.

## 🎯 목표

-   **12주 동안 72개의 프로젝트 생산:** 매일 간단한 아이디어를 코드로 구현합니다.
-   **최종 프로덕트 개발:** 72개의 프로젝트 중 아이디어의 참신함과 잠재적 시장성을 기준으로 3개의 우수 프로젝트를 선정하여 실제 사용자 100명을 목표로 프로덕트(서비스)를 개발합니다.
-   **공개 공유 및 성장:** 모든 코드와 회고록은 GitHub 및 GitHub Pages를 통해 공개적으로 공유하여 학습 과정을 투명하게 공개하고 피드백을 통해 성장합니다.

## 📅 일일 루틴 (주 6일)

-   **계획 (30분):** 그날의 아이디어 구체화 및 구현 계획 수립
-   **구현 (1시간):** 바이브코딩 (Gemini CLI 또는 Antigravity 활용)을 통해 아이디어 코드로 구현 (핵심 기능 1가지만)
-   **회고 (30분):** 아이디어 구상 과정, 바이브코딩 구현 과정, 개선점 등을 기록

### 아이디어 선정

-   **평상시:** 그날그날 떠오르는 주제와 생각을 바탕으로 합니다.
-   **아이디어 고갈 시:** 미리 준비된 6개의 아이디어 목록 활용 또는 이전 프로젝트를 변형하여 구현합니다.
-   **구현 가능 판단 기준:** 1시간 안에 핵심 기능 1가지만 구현 가능한 수준의 심플한 아이디어를 선정합니다.

### 휴식 및 주간 회고

-   **주중:** 월요일부터 토요일까지 코딩을 진행합니다.
-   **일요일:** 완전 휴식 및 주간 회고를 통해 한 주간의 학습 및 구현 내용을 정리하고 다음 주 계획에 반영합니다.

## 🛠️ 작업 규칙

-   **모든 커뮤니케이션 및 문서 작성:** 한글로 진행합니다.
-   **Git 환경 설정:** 프로젝트 시작 시 Git 저장소 초기화 및 사용자 정보 설정 (이름: `knachinen`, 이메일: `knachinen@gmail.com`).
-   **계획 및 체크리스트:** 각 작업 전에 계획과 체크리스트를 제시하고 승인을 받습니다. 승인된 문서는 파일로 저장됩니다.
-   **Git 커밋:** 체크리스트의 작업 하나가 완료될 때마다 Git 커밋을 진행합니다.
-   **작업 완료 확인:** 계획에 따른 체크리스트의 모든 작업이 완료되면 확인을 요청합니다.
-   **프로젝트 디렉토리 구조:** 각 프로젝트는 `[프로젝트넘버]_[주차넘버]-[요일넘버]` 형식의 디렉토리 안에 작성됩니다. (예: `p01_w01-1`)
-   **문서 넘버링:** 프로젝트 디렉토리 내의 문서는 생성된 순서대로 넘버링됩니다. (예: `01_plan.md`, `02_checklist.md`)
