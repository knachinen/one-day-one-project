# 🗺️ Where I Was (어디갔었지) 제품 요구사항 명세서

프로젝트명: Where I Was ($\text{어디갔었지}$)
버전: 1.0 ($\text{MVP}$)
플랫폼: $\text{React Native / Expo}$ ($\text{iOS}$ 및 $\text{Android}$)
작성일: 2025년 12월 4일
핵심 기술: $\text{React Native Maps}$, $\text{Expo Location API}$, $\text{Local DB}$

## 1. 개요 및 목표

### 1.1. 제품 비전

사용자의 발자취를 **배터리 소모를 최소화**하며 기록하고, 의미 있는 장소와 순간을 지도 위에서 시각화하여 개인의 삶에 대한 새로운 통찰을 제공하는 **프라이버시 중심의 위치 일지 도구**.

### 1.2. $\text{MVP}$ 핵심 목표

1. **지속 가능한 추적 검증:** 배터리 효율성을 고려한 **백그라운드 스마트 위치 추적** 로직의 안정성 검증.
2. **의미 있는 기록:** $\text{GPS}$ 좌표를 **장소 이름**으로 변환하여 (역 지오코딩), "머문 곳"에 대한 의미 있는 아카이브 기록 생성.
3. **직관적 시각화:** 기록된 장소를 지도 위에 정확하게 표시하고 조회하는 기능 구현.

## 2. 핵심 기능 및 요구사항 (Core Features)

### 2.1. 위치 데이터 획득 및 기록 ($\text{Acquisition and Logging}$)

| **ID**        | **요구사항**         | **세부사항 (기술적 난이도 상)**                                                                                                 |
| ------------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| $\text{F1.1}$ | **위치 권한 확보**   | 사용자에게 백그라운드 상태의 **정밀한 위치 접근 권한**을 요청하는 명확한 $\text{UI}$ 제공. (권한 없이는 앱 기능 제한)           |
| $\text{F1.2}$ | **스마트 기록 로직** | 단순 $\text{GPS}$ 기록이 아닌, 특정 장소에 **최소 30분 이상 머물렀을 때만** 해당 위치를 단일 아카이브로 기록하는 로직 구현.     |
| $\text{F1.3}$ | **백그라운드 처리**  | $\text{Expo Background Task}$를 활용하여 $\text{OS}$의 저전력 모드에 의존하는 방식으로 위치 변화를 감지하여 배터리 소모 최소화. |
| $\text{F1.4}$ | **사용자 설정**      | 사용자가 위치 추적의 **빈도** ($\text{High/Medium/Low}$) 또는 **정확도**를 직접 조절할 수 있는 설정 $\text{UI}$ 제공.           |

### 2.2. 데이터 처리 및 아카이빙 ($\text{Processing and Archiving}$)

| **ID**        | **요구사항**       | **세부사항 (API 비용 발생 가능)**                                                                                                       |
| ------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| $\text{F2.1}$ | **역 지오코딩**    | 기록된 $\text{GPS}$ 좌표를 $\text{Google/Apple Maps Geocoding API}$ 등을 통해 **주소 또는 장소 이름** ($\text{POI}$)으로 변환하여 저장. |
| $\text{F2.2}$ | **기록 항목**      | 각 아카이브 기록은 **장소 이름, 위도/경도, 체류 시작/종료 시간, $\text{timestamp}$**를 필수로 포함해야 함.                              |
| $\text{F2.3}$ | **수동 메모 추가** | 기록된 장소 아카이브에 사용자가 **텍스트 메모** (예: "친구와 커피 마심")를 수동으로 추가할 수 있도록 허용.                              |

### 2.3. 지도 시각화 및 $\text{UI}$ ($\text{Map Visualization and UI}$)

| **ID**        | **요구사항**       | **세부사항 (React Native Maps 사용)**                                                                        |
| ------------- | ------------------ | ------------------------------------------------------------------------------------------------------------ |
| $\text{F3.1}$ | **메인 지도 화면** | $\text{react-native-maps}$ 컴포넌트를 사용하여 현재 위치와 아카이브된 모든 장소를 표시.                      |
| $\text{F3.2}$ | **마커 표시**      | 스마트 기록 로직에 의해 생성된 각 아카이브 장소에 고유한 **마커 (**$\text{Pin}$**)** 를 지도 위에 표시.      |
| $\text{F3.3}$ | **마커 상세 정보** | 마커를 탭하면 **장소 이름, 체류 시간, 사용자 메모**를 보여주는 오버레이 $\text{Card}$ 표시.                  |
| $\text{F3.4}$ | **기록 목록**      | 지도가 아닌 별도의 $\text{Tab}$ 또는 $\text{View}$에서 모든 기록을 최신순 목록 형태로 조회할 수 있도록 제공. |

## 3. 기술 스택 및 데이터 모델 (Tech Stack & Data Model)

### 3.1. 기술 스택

- **프론트엔드:** $\text{React Native}$
- **프레임워크:** $\text{Expo}$ (Managed Workflow)
- **지도:** $\text{react-native-maps}$
- **위치:** $\text{Expo Location API}$ 및 $\text{Expo Background Task}$
- **데이터베이스:** **Local Database (**$\text{Realm}$ **또는** $\text{SQLite}$ **기반)**

### 3.2. 로컬 DB 데이터 모델 ($\text{LOCATIONS}$ Table)

| **테이블**         | **필드**           | **데이터 타입**               | **설명**                                   |
| ------------------ | ------------------ | ----------------------------- | ------------------------------------------ |
| $\text{LOCATIONS}$ | $\text{id}$        | $\text{STRING}$ ($\text{PK}$) | $\text{UUID}$ 형태의 기록 고유 $\text{ID}$ |
|                    | $\text{name}$      | $\text{TEXT}$                 | 역 지오코딩된 장소 이름                    |
|                    | $\text{lat}$       | $\text{REAL}$                 | 장소의 위도                                |
|                    | $\text{lon}$       | $\text{REAL}$                 | 장소의 경도                                |
|                    | $\text{duration}$  | $\text{INTEGER}$              | 체류 시간 (초 단위)                        |
|                    | $\text{startTime}$ | $\text{REAL}$                 | 체류 시작 $\text{timestamp}$               |
|                    | $\text{userNote}$  | $\text{TEXT}$                 | 사용자가 추가한 수동 메모 (선택 사항)      |

## 4. $\text{MVP}$ 제외 기능 ($\text{Out of Scope for MVP - Phase 2}$)

- **경로 (**$\text{Polyline}$**) 시각화:** 이동 경로 자체를 라인으로 표시하는 기능. (오직 머문 장소 $\text{Pin}$만 표시)
- **클라우드 동기화:** $\text{iCloud}$ 또는 $\text{Firebase}$를 통한 백업/기기 간 동기화.
- **지오펜싱:** 특정 지역 진입/이탈 시 알림 기능.
- **장소별 통계:** 총 방문 횟수, 가장 오래 머문 장소 등 분석 기능.
- **사진 첨부:** 위치 기록에 사진을 첨부하는 기능.
