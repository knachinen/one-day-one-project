# Project Context: Personal Portfolio Website (Minimalist)

## Overview
This project is a personal portfolio website with a minimalist and simple design concept. The goal is to create a clean, content-focused site that effectively communicates the user's identity and skills. The project is currently in the **planning/initialization phase**.

## Tech Stack
*   **Framework:** Next.js (v13+, App Router)
*   **UI Library:** React (v18)
*   **Language:** TypeScript
*   **Styling:** CSS Modules
*   **Deployment:** Vercel
*   **Version Control:** Git / GitHub
