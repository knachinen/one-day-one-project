## 리마인더 앱 개발 계획 (p02_w01-2)

### 1. 프로젝트 초기 설정
- React Native 및 Expo 프로젝트 초기화.
- 필요한 종속성(dependency) 설치.
- 기본 폴더 구조 설정.

### 2. 핵심 기능 구현 (리마인더 생성/관리)
- 리마인더 제목 및 내용 입력 UI 구현.
- 사용자 친화적인 날짜/시간 선택기(Date/Time Picker) 컴포넌트 구현.
- 리마인더 목록 조회 화면 구현.
- 활성/완료 상태별 필터링 기능 구현.
- 리마인더 수정 및 삭제 기능 구현.

### 3. 알림 스케줄링 및 발송
- 시간 기반 단일 알림 및 반복 알림(일/주/월) 설정 로직 구현.
- 로컬 알림(Local Notification) 송출 기능 통합.
- 알림 스케줄링 및 취소 로직 구현.
- 스누즈(Snooze) 기능 구현 (5분, 10분, 30분 옵션).

### 4. 사용자 인터페이스 (UI/UX)
- 메인 화면(현재/예정 리마인더 목록) 구현.
- 완료 목록 화면(완료된 리마인더 확인) 구현.
- 새 리마인더 생성 UI(단계별/단일 화면) 설계 및 구현.
- 리마인더 완료 시 시각적 피드백(애니메이션 등) 추가.

### 5. 데이터 저장
- SQLite 또는 Realm 기반의 로컬 데이터베이스 구축.
- 리마인더 데이터 모델 정의 및 데이터베이스 연동.
