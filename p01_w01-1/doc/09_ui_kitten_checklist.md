# UI Kitten Integration Checklist

This checklist tracks the progress of integrating UI Kitten into the `p01_w01-1` Expo project.

- [ ] 1. Create documentation files (plan and checklist).
- [ ] 2. Install UI Kitten core dependencies: `@ui-kitten/components` and `@eva-design/eva`.
- [ ] 3. Install `react-native-svg`: `expo install react-native-svg@9.13.6`.
- [ ] 4. Configure `App.tsx` by importing `ApplicationProvider`, `IconRegistry`, `EvaIconsPack` and wrapping the root component.
- [ ] 5. Restart the Metro bundler with cache cleared: `npm start -- --reset-cache`.
