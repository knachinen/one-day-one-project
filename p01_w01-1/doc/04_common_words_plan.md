# 계획 (자주 쓰이는 단어 기능 추가)

1.  **자주 쓰이는 단어 문서 생성:**
    *   자주 쓰이는 단어 1,000개를 포함하는 텍스트 파일을 생성합니다. 파일명은 `commonWords.txt`로 하겠습니다.
2.  **`App.tsx` 수정:**
    *   `App.tsx`에서 `commonWords.txt` 파일의 내용을 불러와 단어 목록으로 사용합니다.
    *   `fetchRandomWord` 함수를 수정하여 `webAddress`가 비어 있을 경우 이 미리 정의된 단어 목록에서 무작위 단어를 선택하도록 합니다.
    *   웹 주소가 입력되었을 경우에는 기존 로직대로 웹 콘텐츠에서 단어를 가져옵니다.
    *   파일 읽기 오류에 대한 예외 처리를 추가합니다.
