# 프로젝트 p01_w01-1: 무작위 단어로 글쓰기 앱

## 🌟 프로젝트 소개

이 프로젝트는 "1일 1코딩" 계획의 첫 번째 단계로, 사용자가 웹 주소를 입력하면 해당 페이지에서 무작위 단어를 추출하여 제시하고, 그 단어를 바탕으로 글을 쓰고 마크다운 형식으로 저장할 수 있는 간단한 모바일 애플리케이션입니다. 작성된 글은 앱 내에서 다시 탐색하고 불러올 수 있습니다.

## ✨ 주요 기능

-   **웹 주소 입력:** 사용자가 특정 웹 페이지의 URL을 입력합니다.
-   **무작위 단어 제시:** 입력된 웹 페이지의 텍스트 콘텐츠에서 무작위로 하나의 단어를 추출하여 사용자에게 제시합니다.
-   **글쓰기 입력창:** 제시된 단어를 활용하여 자유롭게 글을 작성할 수 있는 에디터 기능을 제공합니다.
-   **마크다운 저장:** 작성된 글을 `.md` 형식의 파일로 저장합니다.
-   **이전 파일 탐색 및 불러오기:** 저장된 마크다운 파일 목록을 확인하고, 원하는 파일을 선택하여 내용을 다시 불러올 수 있습니다.

## 🛠 기술 스택

-   **프레임워크:** React Native
-   **개발 환경:** Expo
-   **언어:** TypeScript

## 🎨 디자인

-   **미니멀리즘 디자인 (Minimalistic Design):** 깔끔하고 직관적인 사용자 인터페이스를 지향하여 사용자가 콘텐츠 작성에 집중할 수 있도록 합니다.

## 🚀 시작하는 방법

### 1. 프로젝트 클론

```bash
git clone [프로젝트_저장소_URL]
cd p01_w01-1
```

### 2. 의존성 설치

```bash
npm install
# 또는
yarn install
```

### 3. Expo Go 앱 설치

스마트폰에 Expo Go 앱을 설치합니다. (iOS App Store 또는 Android Google Play에서 'Expo Go' 검색)

### 4. 앱 실행

프로젝트 디렉토리에서 다음 명령어를 실행합니다:

```bash
npx expo start
```

명령어 실행 후 터미널에 표시되는 QR 코드를 Expo Go 앱으로 스캔하면 스마트폰에서 앱을 실행할 수 있습니다.
