## 1. 그래픽 애셋: 실시간 자율 움직임 (Idle Animation)

마우스 입력이 없을 때에도 각 오브젝트가 고유의 물리 법칙을 가진 것처럼 움직이게 설정하여 생동감을 부여합니다.

### 1.1 부유 애니메이션 (Floating & Drifting)
* **찻잔 및 시계:** 단순한 정지가 아니라, 수중에서 떠다니는 것처럼 $y$축으로 미세하게 위아래로 움직이며($\pm10px$), 아주 느린 속도로 회전($2\sim3^\circ$)합니다.
* **물리 엔진 적용:** `Sin` 함수를 활용한 부드러운 파동형 움직임을 적용하여 기계적이지 않은 자연스러운 흐름을 연출합니다.
    * **공식 예시:** $y = \text{amplitude} \times \sin(\text{time} \times \text{frequency})$

### 1.2 발광 및 파티클 (Glow & Particles)
* **'MOVE' 버튼:** 중앙의 노란색 발광체가 심장 박동처럼 커졌다 작아졌다 하는 'Breathe' 효과를 상시 적용합니다.
* **배경 파티클:** 화면 전체에 아주 작은 먼지 같은 입자들이 무작위로 생성되어 천천히 상승하거나 하강하게 하여 공간의 깊이감을 더합니다.

**Three.js**를 기술 스택으로 선택하신 것은 매우 탁월한 결정입니다. 단순한 2D 레이어 이동을 넘어, 실제 3D 공간 내에서 \*\*카메라 앵글, 광원(Light), 그리고 재질(Material)\*\*을 제어할 수 있어 훨씬 깊이 있고 몰입감 있는 '원더랜드'를 구현할 수 있습니다.

## 1\. 3D 공간 구성 및 레이아웃

Three.js의 `Scene` 내부에 모든 요소를 배치하며, 마우스 움직임은 실제 카메라($Camera$)의 위치나 각도를 변경하는 방식으로 구현합니다.

  * **카메라(Perspective Camera):** 원근감이 느껴지는 카메라를 설정하여 오브젝트가 가까워질수록 커지는 효과를 극대화합니다.
  * **좌표계 배치:**
      * **Background (Z: -500):** 깊은 어둠과 그라데이션.
      * **Mid-ground (Z: -200):** 메인 타이틀 텍스트 및 본문.
      * **Foreground (Z: 0 \~ 100):** 회중시계, 찻잔 등 주요 에셋 (카메라와 가장 가까워 패럴랙스 효과가 가장 큼).

-----

## 2\. 실시간 자율 움직임 (Idle Motion) 구현법

Three.js의 메인 루프인 `requestAnimationFrame` 내에서 각 오브젝트의 변수값을 실시간으로 업데이트합니다.

  * **Floating 알고리즘:** \* 각 오브젝트에 고유한 `seed` 값을 부여하여 서로 다른 타이밍에 위아래로 흔들리게 합니다.
      * `mesh.position.y += Math.sin(state.clock.elapsedTime + seed) * 0.01;`
  * **Auto-Rotation:** \* 회중시계는 $Z$축을 중심으로 아주 천천히 회전하며, 찻잔은 $Y$축으로 미세하게 뒤틀리는 모션을 주어 무중력 상태를 표현합니다.

-----

## 3\. 핵심 기술 컴포넌트

### 3.1 광원 및 쉐이더 (Lighting & Shaders)

  * **Point Light (노란색):** 'MOVE' 버튼 위치에 점광원을 배치하여 주변 오브젝트(찻잔 등)에 노란색 반사광이 맺히게 합니다.
  * **Bloom Post-processing:** `UnrealBloomPass`를 사용하여 시계의 보라색 광택과 'MOVE' 버튼의 발광 효과가 화면 전체로 은은하게 퍼지게 처리합니다.

### 3.2 마우스 인터랙션 (Raycasting & Lerp)

  * **Smooth Follow (Lerp):** 마우스 위치를 즉각 반영하지 않고 `MathUtils.lerp`를 사용하여 부드럽게 따라오도록 설정합니다. 이는 Three.js 특유의 고급스러운 감도를 만들어냅니다.
  * **Raycaster:** 'MOVE' 버튼이나 'WOW' 태그에 마우스를 올렸을 때 정확히 감지하여 3D 오브젝트의 크기를 키우거나 색상을 변경합니다.

  return (

// 2. 마우스 추적 카메라 컨트롤러
function Rig() {

  const vec = new THREE.Vector3()

    camera.position.lerp(vec.set(mouse.x * 2, mouse.y * 2, camera.position.z), 0.05)
    camera.lookAt(0, 0, 0)

## 2\. 구현 포인트 설명

### 1\) 카메라 리깅 (Rigging)

`useFrame` 내부의 `camera.position.lerp` 함수가 핵심입니다. 마우스의 좌표($-1$ \~ $1$)를 카메라의 좌표계로 변환하여 부드럽게 따라가게 함으로써, 전경과 배경의 거리 차이에 따른 **자연스러운 3D 패럴랙스**를 완성합니다.

### 2\) 상시 움직임 (Float & Distort)

  * **`<Float />`**: Drei 라이브러리의 이 컴포넌트는 복잡한 수학 공식 없이도 오브젝트에 무중력 상태의 부유감을 즉시 부여합니다.
  * **`MeshDistortMaterial`**: 정적인 기하학적 형태가 아니라, 액체처럼 미세하게 일렁이는 효과를 주어 '초현실적인 원더랜드'의 질감을 표현합니다.

### 3\) 광원 및 효과 (Bloom)

  * **`PointLight`**: 특정 위치에서 뿜어져 나오는 노란 빛을 설정하여 사용자가 마우스를 움직일 때 오브젝트의 옆면이 밝아지는 입체감을 줍니다.
  * **`Bloom`**: 시계나 버튼처럼 스스로 빛나는 요소들에 '빛 번짐' 효과를 추가하여 몽환적인 분위기를 극대화합니다.
