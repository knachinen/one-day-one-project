## 📑 히어로 섹션(Hero Section) 상세 디자인 명세서

### 1. 시각적 요소 및 스타일 (Visual Style)

* **배경 (Background):** * 색상: `#FFFFFF` (Pure White) 지향.
* 상단 GNB와 콘텐츠 영역의 구분을 위해 미세한 그라데이션이나 그림자 없이 깔끔한 화이트 배경 유지.


* **컬러 시스템 (Primary Color):** * 브랜드 컬러: `#007BFF` (로고 아이콘, 메인 타이틀 강조색, CTA 버튼).
* 포인트 컬러: `#E7F1FF` (업데이트 태그 배경색).


* **타이포그래피 (Typography):**
* **메인 헤드라인:** `Pretendard`, `700(Bold)`, `48px~56px`, 행간 `1.2`. '가장 쉬운 방법' 부분에 브랜드 컬러 적용.
* **서브 카피:** `Pretendard`, `400(Regular)`, `18px`, 행간 `1.6`, 색상 `#666666`.
* **태그/레이블:** `14px`, `Medium`, 브랜드 컬러 텍스트.

### 2. 컴포넌트 및 인터렉션 (Components & Interaction)

#### ① 상단 배지 (Update Badge)

* **구성:** "● 새로운 v2.0 업데이트 출시"
* **스타일:** 배경 `#E7F1FF`, 텍스트 컬러 브랜드 컬러, `Border-radius: 20px`.
* **효과:** 페이지 진입 시 좌측에서 우측으로 부드럽게 나타남.

#### ② CTA 그룹 (Button Group)

* **주요 버튼 (Primary CTA):**
* 라벨: "지금 무료로 시작하기 →"
* 스타일: 배경 브랜드 컬러, 텍스트 화이트, `Shadow: 0 4px 14px rgba(0, 123, 255, 0.39)`.
* Interaction: Hover 시 배경색 약간 어두워짐, 클릭 시 Scale 0.97.


* **보조 버튼 (Secondary CTA):**
* 라벨: "▶ 데모 영상 보기"
* 스타일: 배경 화이트, 보더 `#E9ECEF` (1px), 텍스트 블랙.
* Interaction: Hover 시 배경색 `#F8F9FA`.



#### ③ 비주얼 목업 (Product Preview)

* **구성:** 대시보드 인터페이스가 포함된 브라우저 창 형태.
* **디테일:** * 왼쪽 하단 '주간 수익률' 팝업과 오른쪽 상단 '새로운 가입자' 알림 팝업을 별도 레이어로 배치하여 입체감 부여.
* 그림자(Drop Shadow): `0 20px 40px rgba(0, 0, 0, 0.1)`.


* **Interaction:** 마우스 움직임에 따라 이미지가 미세하게 기울어지는 틸트(Tilt) 효과 적용 가능.

### 3. 신뢰 지표 (Social Proof Section)

* **문구:** "전 세계 5,000+ 기업이 신뢰하는 솔루션" (`14px`, `#888888`).
* **로고 배치:** * `Acella`, `Vertex`, `Infinite`, `BoltShift` 등 파트너사 로고를 그레이스케일 처리.
* 간격: 로고 간 `40px` 이상 유지.
* 효과: 로고 리스트가 좌우로 천천히 무한 루프되는 애니메이션 적용 권장.



---

### 4. 반응형 레이아웃 가이드 (Responsive)

* **Desktop (1200px+):** 이미지와 텍스트가 1:1 비율로 좌우 배치.
* **Tablet (768px - 1024px):** 텍스트 영역 상단, 이미지 하단으로 배치 변경. 이미지 크기 80%로 조정.
* **Mobile (under 768px):** * 헤드라인 폰트 크기 `32px`로 축소.
* CTA 버튼을 가로 꽉 찬 너비(Full-width)로 변경.
* 파트너 로고는 2열 배정 또는 가로 스크롤 형태로 변경.
