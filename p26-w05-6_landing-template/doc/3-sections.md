앞서 작성한 UI/UX 디자인 명세서를 바탕으로, 실제 제작 단계에서 개발자와 디자이너가 바로 참고할 수 있는 **섹션별 상세 명세서**를 작성해 드립니다.

이 명세서는 페이지 상단부터 하단까지의 흐름을 시각적 요소와 기능적 로직으로 구분하여 설명합니다.

---

## 📑 섹션별 상세 디자인 명세서

### 1. 헤더 (Global Navigation Bar)

전체 페이지의 탐색을 돕는 고정 영역입니다.

* **좌측:** 브랜드 로고 (클릭 시 페이지 최상단 이동)
* **중앙:** 주요 메뉴 (서비스 소개, 특징, 후기, FAQ) - 클릭 시 해당 섹션으로 앵커 스크롤
* **우측:** 핵심 CTA 버튼 (예: '무료 시작하기') - 배경색 적용으로 시인성 확보
* **Interaction:** 스크롤 시 배경에 `Backdrop-filter: blur(10px)`와 미세한 그림자(Shadow) 적용

### 2. 히어로 섹션 (Hero Section)

사용자가 가장 처음 마주하는 핵심 가치 전달 구간입니다.

* **텍스트 배치:** 좌측 정렬 또는 중앙 정렬 (모바일은 중앙 권장)
* **애니메이션:** 메인 카피는 `y축 +20px`에서 위로 올라오며 `Opacity 0 → 1` 효과
* **이미지/그래픽:** 우측 또는 하단에 제품의 실제 대시보드 화면 배치 (Mockup 활용)
* **CTA:** 버튼은 마우스 호버 시 크기가 1.05배 커지는 마이크로 인터랙션 추가

### 3. 문제 제기 및 해결책 (Pain Point & Solution)

사용자의 공감을 유도하고 해결책을 제시하는 구간입니다.

* **레이아웃:** 3열 그리드 또는 카드 형태
* **아이콘:** 각 포인트별로 의미가 직관적인 라인 아이콘(Line Icon) 배치
* **디자인 디테일:** * 문제점 카드: 무채색 계열 사용 (어두운 느낌)
* 해결책 카드: 브랜드 메인 컬러 포인트 사용 (밝고 희망찬 느낌)



### 4. 핵심 기능 상세 (Feature Detail)

제품의 기능을 시각적으로 증명하는 구간입니다.

* **교차 배치 (Z-Pattern):** *  / [이미지 - 텍스트] 순서로 배치하여 시선의 지루함 방지


* **이미지:** 실제 기능 작동 화면이나 고품질 그래픽 소스 활용
* **텍스트:** 기능명(H3) + 상세 설명(Body) + 체크표시(Bullet points) 조합

### 5. 신뢰 지표 (Social Proof)

사용자의 불안감을 해소하는 구간입니다.

* **로고 클라우드:** 협력사/고객사 로고를 그레이스케일(Grayscale)로 배치, 호버 시 컬러로 변경
* **리뷰 카드:** * 사용자 프로필 이미지 + 이름 + 직책 + 별점(Star Rating) 포함
* 실제 인용구는 따옴표(`“ ”`) 디자인 요소를 사용하여 강조



### 6. FAQ (자주 묻는 질문)

이탈 방지를 위한 마지막 정보 제공 구간입니다.

* **UI 타입:** 아코디언(Accordion) 스타일
* **동작:** 질문 우측에 `+` 또는 `∨` 아이콘 배치. 클릭 시 답변 영역이 `Slide-down` 되며 아이콘이 `×` 또는 `∧`로 회전(Rotation 180deg)
* **스타일:** 질문 영역 배경색을 미세하게 다르게(`F8F9FA`) 설정하여 클릭 영역임을 인지시킴

### 7. 푸터 (Footer)

법적 정보와 추가 탐색을 돕는 구간입니다.

* **정보 구성:** 회사명, 대표자, 사업자번호, 주소, 개인정보처리방침(Bold), 서비스 이용약관
* **SNS 아이콘:** 인스타그램, 블로그, 유튜브 등 링크 연결 아이콘
* **디자인:** 배경색을 어두운 톤(`#333333`)으로 설정하여 본문과 명확히 구분

## 🛠 공통 가이드라인 (Dev Note)

* **반응형 스택:** 768px(태블릿) 이하에서는 가로 배치를 모두 세로(Column) 배치로 전환
* **이미지 최적화:** 모든 이미지는 `Lazy-loading` 적용하여 초기 로딩 속도 개선
* **웹 접근성:** 이미지마다 `alt` 태그 필수 작성, 버튼과 배경의 대비비(Contrast Ratio) 4.5:1 준수

**이제 이 명세서를 바탕으로 실제 "상담 신청 폼"의 입력 항목(성함, 연락처 등)과 유효성 검사 로직을 상세히 짜드릴까요?** 혹은 특정 섹션의 **카피라이팅**이 고민이신지 알려주세요!
